## 반영 결과

- 1025px 이상은 224px 사이드바와 76px 아이콘 레일을 전환하며 선택을 기억한다. 1024px 이하는 본문 offset 0과 64px 브랜드바·모달 메뉴를 함께 적용했다.
- 로고와 메뉴 아이콘 렌더링을 분리하고 같은 Lucide 아이콘·라벨 구조를 사용했다. 메뉴는 배경 클릭·Escape·링크 이동으로 닫히며 포커스 순환/복원, 배경 inert, 스크롤 잠금을 적용했다.
- 본문 15–17px, 카드 제목 17–21px, 보조 정보 12–14px의 유동 토큰을 적용했다. 최대 콘텐츠 폭은 1360px, 읽기 폭은 840px이다. 카드 수를 가용 폭에 맞추고 소개 영역을 압축했다.
- 대표 사진 위의 중복 제목을 제거했다. 사진이 없거나 실패하면 새 로컬 편집 이미지를 쓰고 ‘편집 이미지’로 표시한다. 실제 장소의 사진이라는 오해를 피하기 위한 공통 폴백이다.
- 상세 주소 줄바꿈, 사전 빈 검색 섹션 숨김과 날짜 위치를 수정했다. 필터와 보기 전환은 일반 버튼의 aria-pressed 상태로 통일했다.

캡처는 데스크톱 브라우저의 viewport를 변경한 결과이며 실제 iOS/Android 기기, 모바일 User-Agent, 로그인 서버 연동, 외부 배포 완료를 검증한 것은 아니다. 이미지 폴백 로직은 공유 렌더러에 반영했으나 모든 외부 이미지 URL의 영구 가용성을 보장하지 않는다. 캡처는 gitignore된 로컬 작업 산출물이다.

### 최종 전문가 검토

GPT 6 Luna가 최종27개 캡처를 직접 열어 재검토했고 필수 수정 시각 결함 없음으로 승인했다. 모바일 트렌드 필터의 가로 스크롤과 펄스 보기 버튼의 두 줄 배치는 현재 의도된 반응형 탐색으로 확인했다.

### 후속 사용자 피드백 반영

공통 편집 사진은 카테고리별 기본 SVG 7종과 공통 기본 이미지로 교체했다. 로고 옆 접기 아이콘은 사이드바 하단 제어로 분리했다. 사전·홈 트렌드·광고 분석·트렌드 목록·펄스의 같은 행 카드에서 내용별 subgrid 트랙을 공유해 제목·설명·예문/태그·우리말·날짜/버튼/점수를 정렬했다. 데스크톱 캡처와 768/390px 화면을 확인했다. 현재 구현 기준은 DESIGN.md를 따른다.
