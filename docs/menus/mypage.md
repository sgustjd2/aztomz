# 내 보관함 (제거)
- 목적: 개인 보관함을 제공하지 않는 현재 범위와 기존 주소 처리를 기록한다.
- 진입/화면: `frontend/me.html`은 삭제했다. Vercel의 `/me.html` 요청은 홈(`/`)으로 영구 리다이렉트하며 공통 메뉴에도 보관함은 없다.
- 표시 데이터: 없음. 개인 저장·방문자 후기·개인 펄스 아이디어 저장소와 렌더 코드를 제거했다.
- 현재 상태: 제거됨. 상세 저장 버튼·방문자 후기·펄스 저장/다운로드/삭제·저장 아이디어 탭을 제공하지 않는다. 공개 아이디어 펼침과 검색, 공유는 유지한다.
- 관련 코드: `vercel.json`의 `/me.html` 리다이렉트, `frontend/assets/app.js`, `frontend/trend.html`, `frontend/assets/pulse.js`.
- 비고: 기존 브라우저 localStorage 데이터에 대한 삭제 명령은 실행하지 않는다. 현재 코드는 개인 데이터를 읽거나 갱신하지 않고 테마·메뉴 접기 설정만 사용한다.
