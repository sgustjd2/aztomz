AI 비서는 이렇게 일한다

디스코드 말과 저녁 크론이 로컬 PC의 Hermes를 깨운다. 에이전트는 조사·판단만 하고, 트렌드 데이터에 쓰는 일과 배포는 결정적 검증 스크립트가 맡는다.

Headline

에이전트는 쓰지 않고, 게이트가 쓴다

AI 비서는 조사한 후보를 .pipeline/curate.json에 내기만 한다. 출처 생존·본문 관련성·근거 대조를 통과한 항목만 auto-build.mjs가 trends.json에 반영하고 git push → Vercel 재배포까지 한다. 걸린 후보는 디스코드 [게시/버리기/나중에] 버튼으로 사람이 정한다.
