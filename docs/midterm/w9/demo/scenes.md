## 슬라이드에 적을 때 주의

- **트렌드 키워드 검색창은 MZ 사전(`dictionary.html`)에만 있다.** 홈·요즘 트렌드 목록에는 검색창이 없고 분류 칩만 있다. 영상도 검색은 MZ 사전에서 보여 준다.
- **'갱신 필요'라는 문구는 화면에 안 나온다.** 14일 경과 시 실제 표시는 ① 상세 페이지의 "오래된 분석이에요…" 경고 배너, ② MZ 사전의 '지난 유행어' 분리 두 가지다. 카드·상세에는 분석 날짜만 표시된다(`app.js`의 `freshChip`에 "N일 전 · 갱신 필요" 문구가 있지만 어느 화면도 쓰지 않음).
- 출처 링크는 실제로 **새 탭**으로 열린다. 녹화는 한 탭만 찍히므로, 클릭으로 새 탭이 열리는 것을 확인한 뒤 같은 기사 URL을 녹화 탭에 띄워 보여 줬다(자막에 명시).
- 홈 카드 목록은 수집일 최신순이라, 녹화 시점(10-28) 신조어 칩의 카드 8개는 모두 분석 14일이 지난 항목이다. 영상의 '오래된 분석' 장면은 그중 첫 카드다. 녹화 날짜가 바뀌면 '오늘의 한끗' 카드와 칩 목록 내용이 달라질 수 있다.
