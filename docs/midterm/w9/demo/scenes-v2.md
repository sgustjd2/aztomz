## 슬라이드에 적을 때 주의

- **트렌드 키워드 검색창은 MZ 사전에만 있다.** 홈과 목록에는 분류 칩만 있다.
- **'갱신 필요'라는 문구는 화면에 나오지 않는다.** 14일이 지나면 두 가지로 드러난다.
  - 상세 페이지의 "오래된 분석이에요…" 배너
  - MZ 사전의 '지난 유행어' 분리
- **출처 링크는 새 탭으로 열린다.** 녹화는 한 탭만 찍히므로, 클릭해 새 탭이 열린 것을 확인한 뒤 같은 기사 URL을 녹화 탭에 띄웠다. 자막에도 이 점을 밝혔다.
- **'하찮은 그림 프롬프트'로 가는 길:** 사이드 카테고리 → 목록 2쪽 → 카드 순서로 실제 화면을 거쳐 들어갔다. 주소를 직접 입력하지 않았다.
- **1:06~1:18의 약 12초는 하단 자막이 없다.** 홈으로 이동하고 칩을 고르는 구간이며, 기능 배지는 계속 보인다.
- **녹화 날짜가 바뀌면 화면 내용도 바뀔 수 있다.**
  - '오늘의 한끗'과 칩 목록이 달라진다.
  - '할로윈' 경고는 분석일이 갱신되면 사라진다.
  - 다시 찍을 땐 위 예시 id가 여전히 같은 상태인지 먼저 확인한다.
