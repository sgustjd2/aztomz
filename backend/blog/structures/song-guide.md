# 구조 — song-guide (곡 해설 · 숨은 신곡 추천)

검색의도: 새 노래를 만나고 싶거나, 들은 곡이 무슨 이야기인지 알고 싶은 독자.

## 절대 규칙 — 가사

**가사를 옮기지 않는다. 한 줄도. 번역도 하지 않는다.**

- 가사 전문 게재 = 복제권 침해. 한 줄씩 번역 = 거기에 2차적저작물작성권 침해까지.
- 멜론·Genius·우타넷 같은 공식/라이선스 가사 페이지로 **링크**만 건다.
- 가사 이야기를 하려면 **내용을 자기 문장으로 설명**한다.
  - ✕ "가사: 君のことが好きだ / 해석: 너를 좋아해"
  - ○ "화자는 고백을 미루다 계절이 바뀐 걸 깨닫는다. 후렴에서 처음으로 상대를 직접 부르는데,
       그 전까지 한 번도 이름을 부르지 않았다는 게 이 곡의 장치다."
- 이 규칙은 협상 대상이 아니다. 지킬 수 없는 항목이면 그 곡을 뺀다.

## 뼈대

1. **왜 이 묶음인가 (3문장)** — 어떤 기분·상황에 맞는 곡들인지. 도입은 짧게.
2. **고른 기준** — 발굴형은 기준이 곧 취향이다. 명시한다.
   (예: "2025년 이후 발매 · 국내 스트리밍 차트 밖 · 유튜브 조회수 100만 미만")
3. **곡마다 (H2: `아티스트 - 곡명`)** — 아래 A/B 중 **주어진 자료에 맞는 쪽만** 쓴다.

### A. 발굴 모드 — 유튜브 검색으로 찾아온 곡 (최신곡)

너는 이 곡을 **들어본 적이 없다.** 그러니 소리·가사·정서를 서술하지 마라. 그건 전부 환각이 된다.
쓸 수 있는 건 주어진 자료뿐이고, 그것만으로도 충분한 글이 된다.

   - **왜 추천하는가** — `hiddenRatio` 와 댓글 반응에 근거한 한 문장.
     ✕ "감성적이라 추천"(근거 없음) · ✕ "2분 40초에 드럼이 빠진다"(안 들어봤으면 환각)
     ○ "구독자 254만인데 이 곡만 48만회. 규모에 비해 유독 안 알려졌다"
   - **얼마나 안 알려졌나** — 조회수 · 구독자 수 · 비율. **주어진 숫자를 그대로** 쓴다.
   - **듣는 사람들은 이렇게 말한다** — `topComments` 의 **공통된 반응을 요약**. 2~3문장.
     **원문 인용 금지**(댓글에 가사가 통째로 달린다). "어느 대목이 좋았다는 말이 반복된다" 식으로.
     반응이 빈약하면 이 항목을 통째로 뺀다.
   - **어떤 순간에 어울리는지** — 댓글에서 사람들이 실제로 언제 듣는다고 하는지에 근거.
     근거가 없으면 쓰지 않는다.
   - **공식 링크** — 주어진 유튜브 URL 을 그대로. 가사는 **공식 가사 페이지 링크**로 넘긴다.

   ⚠ **연도는 "유튜브 업로드 연도"로만 쓴다.** 발매 연도는 알 수 없다 —
   "2026년 발매" 라고 쓰지 말고 "2026년 유튜브 공개" 라고 쓴다.

### B. 지식 모드 — 실제로 알려진 곡 (레트로 등)

   - **한 줄 소개** · **왜 추천하는가** · **어떤 이야기인가**(가사 인용 없이 자기 문장으로)
     · **소리**(편성·템포·인상적인 구간) · **어떤 순간에 어울리는지** · **공식 링크**
   - 확실히 아는 곡에만 쓴다. 조금이라도 헷갈리면 A 모드로 내려가라.

   - 두 모드 공통: `[IMG: 곡 분위기를 나타낼 자체 제작 이미지 설명 — 앨범아트 아님]`
4. **한 곡만 듣는다면** — 하나 고르고 이유 한 문단.
5. **비슷한 결의 다른 묶음** — 내부링크 2개.

## 추천이 진화하는 방식

이 카테고리는 **한 번 쓰고 끝이 아니다.** 발행된 곡은 전부 `backend/blog/feedback/song-log.json`
에 남고, 사람이 좋았다/별로였다를 표시하면 그 교훈이 `music-lessons.md` 에 쌓인다.

- **이미 추천한 곡은 다시 추천하지 않는다.** 로그에 있는 곡은 후보에서 제외된다(자동).
- 누적된 교훈이 다음 글의 아웃라인 단계에 주입된다. 취향·기준이 시간이 갈수록 뾰족해진다.
- 교훈은 "무엇이 좋았다" 보다 **"어떤 기준이 틀렸다"** 를 남길 때 쓸모 있다.
  (예: "조회수 상한만 보면 신인 홍보곡이 섞인다 — 채널 구독자 수도 같이 본다")

## 실재 확인 (필수)

LLM 은 **없는 곡·없는 앨범·틀린 연도를 그럴듯하게 지어낸다.** 특히 "덜 알려진 최신곡"에서 심하다.

- 각 곡은 **유튜브 데이터 API 로 실제 존재를 확인**한 것만 넣는다.
- 확인 항목: 아티스트명 · 곡명 · 공식 채널 업로드 여부 · 발매(업로드) 연도.
- 확인 실패한 곡은 **조용히 뺀다.** 개수를 채우려고 남기지 않는다.
- 5곡을 목표로 했는데 3곡만 확인되면 3곡으로 낸다.

## 그 외 저작권

- 앨범아트·아티스트 사진 **재업로드 금지.** 공식 페이지 링크만. 대표 이미지는 자체 생성 카드.
- 음원 파일 업로드·직링크 금지. 공식 스트리밍/유튜브 공식 채널만.
- 뮤직비디오는 공식 채널 임베드만.
