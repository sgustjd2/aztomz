# 구조 — review (제품·도구 리뷰)

검색의도: 쓸지 말지 고민 중인 독자. **단점을 안 쓰면 리뷰가 아니라 광고다.**

## 뼈대

1. **한 줄 결론 + 누구에게 맞는지** — 맨 위에. "○○인 사람에겐 추천, △△면 비추천."
2. **써본 조건** — 얼마나, 어떤 환경에서, 무슨 용도로. 이게 없으면 신뢰가 0이다.
3. **좋았던 점 (H2)** — 항목마다 구체적 근거. "빠르다" ✕ / "빌드가 12초 → 4초" ○
4. **아쉬운 점 (H2)** — **최소 2개.** 억지로 만든 단점 말고 실제로 걸린 것.
5. **대안과 비교** — 경쟁 제품 1~2개와 한 문단씩. 표로 정리.
6. **가격 / 무료 범위** — 있는 경우. 시점을 명시(가격은 바뀐다).
7. **결론 — 이런 사람에게 추천 / 비추천** — 각 2~3개 항목.

## 이 구조에서 특히 지킬 것

- 안 써본 걸 써본 척하지 않는다. 공식 문서만 보고 쓴 거면 "문서 기준"이라고 밝힌다.
- 수치는 출처나 측정 조건을 붙인다.
- 제휴 링크가 있으면 글 첫머리에 고지한다.
- 제조사/공식 이미지는 재업로드하지 않는다. 커버는 자체 생성 카드를 쓴다.
