# 구조 — howto (방법 안내)

> 공통 편집 양식(콜아웃 💡⚠️📌·코드블록 파일명·비교표·정리·참고 — goddaehee·inpa 참고)은 [_format.md](_format.md) 를 함께 따른다.

검색의도: "어떻게 하는지" 를 찾아온 독자. 답을 빨리 주고, 막히는 지점을 미리 치워준다.

## 뼈대

1. **도입 (3문장 이내)** — 이 글을 끝까지 읽으면 무엇을 할 수 있게 되는지. 인사말·서론 금지.
2. **준비물 / 전제** — 버전, 설치물, 권한. 버전은 반드시 명시(`Spring Boot 3.x`, `Node 20+`).
3. **본 단계 (H2로 Step 1..N)** — 한 단계 = 한 가지 일. 각 단계마다:
   - 무엇을 하는지 한 줄
   - 실행할 명령 또는 코드 블록
   - 결과가 어떻게 보여야 하는지 (확인 방법)
   - `[IMG: 이 단계에서 보여야 할 화면 설명]`
4. **막히면 — 자주 나는 에러** — 에러 메시지 원문 + 원인 + 해결. 최소 2개.
5. **정리** — 3줄 요약 + 다음에 읽을 관련글 내부링크.

## 이 구조에서 특히 지킬 것

- 단계 번호를 건너뛰지 않는다. 독자는 그대로 따라 한다.
- "간단히", "쉽게" 같은 말로 단계를 생략하지 않는다. 생략할 거면 아예 쓰지 않는다.
- 코드 블록에는 언어를 명시한다(```java, ```bash).
- 실행해보지 않은 코드는 쓰지 않는다. 확신이 없으면 그 단계를 빼고 "여기서는 공식 문서 참고"로 남긴다.
