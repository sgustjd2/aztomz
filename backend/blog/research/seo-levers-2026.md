# 티스토리(burning-go9me/AZTOMZ) 조회수 SEO 레버 — 조사 결과 (2026-09-08)

> 목적: 우리 블로그 파이프라인(주제선정→집필→발행)에 규칙으로 박아 넣을 실행 가능한 체크리스트.
> 표기 원칙: 실제 WebFetch로 본문을 읽고 확인한 내용만 "확인"으로 쓴다. 스니펫만 본 것·업계 통념은 "추정"으로 명시.

## 1. 검색수요 큰 주제/키워드 찾는 법

### ① 주제 선정 규칙 (파이프라인에 박을 것)

1. **후보 키워드를 정하면 최소 2개 도구로 교차 검증한다.**
   - 네이버 데이터랩 검색어트렌드(datalab.naver.com) — 네이버 검색 비중이 절대적인 한국에서 필수.
   - 네이버 검색광고 키워드도구(searchad.naver.com) — 이 두 곳 중 **오직 여기서만 "월간 검색수(PC/모바일) 절대값"** 을 준다. 데이터랩은 상대지수(0~100)만 준다는 점을 혼동하지 말 것.
   - 구글 트렌드(trends.google.com) — 국내 대비 글로벌/영어권 반응이나 시계열 급상승 여부 확인용.
2. **"검색량은 있지만 경쟁이 약한" 롱테일을 우선한다.** 키워드도구에서 월간검색수는 있는데 문서수(블로그 개수)가 적은 조합을 찾는다 — 신규/저권위 블로그가 바로 붙을 수 있는 유일한 틈새.
3. **데이터랩 검색어트렌드는 절대량이 아니라 상대지수(0~100)** 임을 기억한다. 서로 다른 키워드 세트를 두 번 조회해서 절대량을 비교하면 안 된다(같은 조회 내 최대값이 100으로 재정규화됨). 정량 비교가 필요하면 반드시 같은 조회 화면에 최대 5개 키워드를 함께 넣는다.
4. **시즌 키워드는 캘린더로 미리 예약한다.** 명절·연말정산 같은 시즌성 주제는 "고정 질문(매년 반복되는 정보)" + "그 해 시의성(유행 밈·정책 변경)" 두 겹으로 구성 — 매년 재활용 가능한 골격에 그 해 이슈만 갈아 끼운다. **선발행 원칙**: 시즌 정점 1~2주 전에 색인이 끝나 있어야 하므로, 신규/저권위 블로그는 최소 3~4주 전 발행(아래 "기대치"의 색인 소요기간 참고).

### 근거

- 네이버 데이터랩 검색어트렌드: 최대 5개 키워드까지 기간별·성별·기기별·연령별 **상대 데이터**만 제공. "설정한 기간에서 가장 많은 검색량을 가진 값이 100이 되고 나머지 기간은 상대적인 값" — 절대값 비제공. [네이버 데이터랩 활용 가이드](https://www.ascentkorea.com/naver-datalab-guide/) *(스니펫 확인, 상대지수 방식 자체는 네이버 공식 데이터랩 페이지에서도 동일하게 안내되는 공지사항 — 도구 화면 자체가 1차 출처)*
- 네이버 검색광고 키워드도구: 검색키워드·연관키워드·**월간검색수(PC/모바일)**·월평균클릭수·클릭률·월평균노출광고수·경쟁정도를 제공. "검색량은 높지만 경쟁률이 치열하지 않은 키워드"를 찾는 것이 틈새 전략. [네이버 검색광고 키워드 도구 제대로 알고쓰자](https://inside.ampm.co.kr/insight/4626) *(WebFetch 확인, 마케팅 대행사 블로그·tier: blog)*
- Google Trends 공식 도움말: Top Charts 페이지에서 국가·기간·카테고리 지정해 인기 주제 확인 가능. 계절성·연관 검색어 파악 용도. [Google 트렌드 시작하기](https://support.google.com/trends/answer/6248105?hl=ko) *(WebFetch 확인 — 단, 관심도 지수 0-100 해석의 세부 설명은 이 도움말 페이지 자체엔 없었음 — unknown 처리)*

## 2. 제목(title) SEO

### ② 제목 규칙 (파이프라인에 박을 것)

1. **핵심 키워드를 제목 맨 앞부분에 배치한다.** 네이버·구글 공통 원칙. (확인: 구글 공식 — "구체적이고 간결한" 제목 요구, 페이지 콘텐츠와 정확히 일치해야 함 / 확인: 실무 가이드 — "핵심 키워드를 제목의 앞부분에 넣으면 검색엔진이 더 중요하게 인식")
2. **실제 사람이 검색창에 치는 표현 그대로 매칭시킨다.** 키워드도구에서 뽑은 "연관 키워드"가 실제 검색어 형태 — 우리가 임의로 축약·의역한 표현(예: "먹밤" 대신 "티라미수" 풀네임)보다 실사용 검색어 표현을 우선한다.
3. **시의성 신호(연도/시즌)를 넣을 근거가 있을 때만 넣는다.** "2026" 같은 연도 태그는 정보가 실제로 그 해 기준일 때만 — 근거 없이 매 글 기계적으로 붙이면 "양산글" 신호가 된다(우리 CLAUDE.md 철칙과 동일 방향). *(추정 — 이 인과관계를 직접 검증한 출처는 못 찾음. 저품질 판정 원인 중 "반복되는 상용구/키워드 과다"와 논리적으로 연결되는 부분만 확인됨)*
4. **제목에 핵심 키워드는 1개, 자연스럽게 1회만.** 반복 삽입은 구글이 "스팸으로 오인"할 수 있다고 공식 명시 — 상용구 반복도 금지 대상.
5. **각 글의 제목은 고유해야 한다.** 사이트 전체에서 같은 제목/거의 같은 제목 패턴 반복 금지 — 구글 공식 가이드가 "고유한 텍스트" 요구.
6. **길이는 공식 상한이 없다.** 다만 기기 너비를 넘으면 검색결과에서 잘린다 — 구글 공식 문구. 실무 가이드 하나는 "띄어쓰기 포함 25자 이내"를 제시하나 이건 업계 경험칙(tier: blog)이며 구글 공식 수치는 아니다. **핵심 정보(주제어+핵심어)는 앞 25~30자 안에 다 들어가게** 쓰는 걸 실무 기준으로 채택.
7. **숫자·질문형은 클릭률에 도움된다는 통념이 있으나, 이는 마케팅 블로그 주장이며 공식 검증 자료는 못 찾음.** *(추정)*

### 근거

- Google 공식 title 가이드: 구체적·간결, 페이지별 고유 텍스트 필수, 키워드 반복/상용구 반복 금지, 콘텐츠와 불일치 금지, 브랜드명은 구분자로 분리. [제목 링크가 검색결과에 표시되는 방식](https://developers.google.com/search/docs/appearance/title-link?hl=ko) — **공식(official), WebFetch 확인**

## 3. 색인 등록·노출

### ③ 색인 등록 체크리스트 (사람이 최초 1회 할 일)

**A. 네이버 서치어드바이저 (searchadvisor.naver.com)**
1. 네이버 계정으로 로그인 → 웹마스터 도구 → 사이트 등록(대표 도메인 입력).
2. 소유 확인: HTML meta 태그 방식이 가장 간편 — 발급받은 태그를 사이트 `<head>`에 삽입 후 "소유확인" 클릭. (티스토리는 관리자 페이지 → 꾸미기 → 스킨 편집에서 `<head>`에 삽입 가능)
3. RSS 제출: 관리자 페이지 → 환경설정 → SEO(검색엔진최적화) → 고급 설정에서 RSS 주소 확인(보통 `사이트주소/rss`) → 서치어드바이저 → 요청 → RSS 제출 → 붙여넣기 → 보안문자 입력 → 확인.
4. 사이트맵 제출: 같은 화면에서 사이트맵 파일명(`sitemap.xml`) 입력 후 제출.
5. "간단체크" 메뉴로 robots.txt·meta robots·정상 응답(200) 등 기본 상태를 초록색 체크로 확인.
6. 이후 신규 발행 시 별도 수동 요청 없이도 RSS가 등록돼 있으면 네이버 봇이 주기적으로 재방문 — 단, 급하면 서치어드바이저 "웹페이지 수집요청"으로 개별 URL 수동 제출 가능(사이트당 일일 한도 있음, 정확한 한도 수치는 못 찾음 → unknown).

**B. 구글 서치콘솔 (search.google.com/search-console)**
1. Google 계정으로 로그인 → 속성 추가(도메인 또는 URL 접두어 방식 — 티스토리는 URL 접두어 방식이 소유확인 쉬움: HTML 태그를 `<head>`에 삽입).
2. 좌측 메뉴 Sitemaps → 사이트맵 URL 입력(`sitemap.xml`) → 제출.
3. 사이트맵은 UTF-8 인코딩, URL 5만 개/50MB 이하 — 티스토리 규모에서는 문제 없음(공식 제한 수치, 우리는 훨씬 못 미침).
4. 신규 글 개별 색인을 서두르고 싶으면 "URL 검사" 도구에 해당 URL 입력 → "색인 생성 요청" 클릭(수동, 건별).
5. 사이트맵 제출은 필수는 아니고 "힌트" 역할 — 구글이 "다운로드하거나 사용한다고 보장하지 않는다"고 공식 명시. 그래도 내부링크가 부족한 신규 사이트일수록 크롤러 발견 속도에 도움.

### 티스토리 특유의 저품질·색인제외 유발 요인 (사람이 피해야 할 것 — 확인된 것만)

- 제목·본문에서 **같은 키워드 과다 반복** → 스팸 판정 위험 (구글 공식 title 가이드에서도 "키워드 반복"을 명시적으로 금지).
- **자동생성/중복 콘텐츠, 타 사이트 복사** — 저품질 전환의 대표 원인으로 여러 실무 가이드가 공통 지목.
- **매크로·자동 방문/자동 공감 등 트래픽 조작** — 인위적 상단노출 시도로 간주돼 페널티.
- **과도한 상업적 링크·광고 중심 구성** — 정보성 대비 광고 비율이 높을수록 저품질 위험 신호로 여러 출처가 공통 지목(구체적 임계 비율 수치는 출처마다 달라 신뢰 못 함 → 구체 %는 unknown).
- H1 중복(페이지당 H1이 2개 이상) — 네이버 웹마스터 도구 진단에서 오류로 잡힘.
- 이미지 alt 속성 누락 — 네이버 웹마스터 도구 진단 항목.

## 4. 현실적 기대치

### ④ 기대치 (파이프라인/사람 기대 관리용)

- **신규 티스토리 블로그의 구글 색인 소요 기간**: "짧게는 3일, 길게는 3개월"이라는 폭넓은 범위가 실무 커뮤니티에서 공통적으로 언급됨. 첫 포스팅 기준 **약 2주 후 색인**되는 사례가 다수 보고됨. *(tier: blog/커뮤니티 스니펫 종합, 공식 수치 아님 — 구글은 색인 소요 기간을 공식적으로 확정 발표하지 않는다)*
- **네이버는 RSS 제출 시 상대적으로 빠르게(수집 로봇 재방문 전에도) 신규 콘텐츠가 반영될 수 있다**고 서치어드바이저 도움말이 명시(RSS 제출 권장 사유) — 정확한 시간(분/시간 단위) 수치는 공식 문서에서 확인 못함 → unknown.
- **도메인 권위(Domain Authority)는 즉시 오르지 않는다.** DA는 0~100 상대지표이며, 소수의 최상위 도메인만 90점대, 나머지는 그보다 낮은 분포. 저권위 사이트는 **경쟁이 적은 롱테일 키워드부터** 순위를 쌓아 올려야 하고, 이 과정이 사이트 전체 신뢰도 축적 → 상위 키워드 진입의 발판이 되는 **누적형 과정**이다. 오래된 도메인일수록 백링크 축적 기회가 많아 유리 — 즉, **시간 자체가 요인** *(tier: blog, 여러 SEO 대행사 공통 설명, 구글이 "Domain Authority"라는 지표를 공식 인정한 적은 없음 — DA는 Moz 등 제3자 지표라는 점을 명시해야 함. 이 부분 unknown 처리: 구글이 실제로 도메인 단위 신뢰도를 랭킹에 반영하는지 여부는 공식적으로 확인 안 됨, 다만 실무적으로는 신규/저권위 사이트가 경쟁 키워드에서 밀리는 현상 자체는 폭넓게 관찰됨)*
- **결론(실행 규칙으로 채택)**: 우리 블로그(burning-go9me)처럼 신규·저권위인 경우 (1) 시즌 키워드는 최소 3~4주 전 발행, (2) 처음부터 대형 키워드를 겨냥하지 말고 검색량 있는 롱테일부터, (3) 색인 등록 체크리스트(위 ③)를 발행 즉시 1회라도 완료해 두면 자연 크롤링보다 빠르게 반영 가능.

## unknowns (못 찾은 것 — 추측으로 채우지 않음)

- 네이버 서치어드바이저 "웹페이지 수집요청"(개별 URL 수동 색인)의 일일 한도 정확한 수치
- 네이버 RSS 제출 후 실제 반영까지 걸리는 시간(분/시간 단위 공식 수치)
- 구글이 "도메인 권위(Domain Authority)"라는 개념을 랭킹 신호로 공식 인정하는지 여부(DA는 Moz 등 제3자 지표 — 구글 랭킹 알고리즘에 직접 반영된다는 공식 확인 없음)
- 네이버 검색 알고리즘(구 다이아 로직 계열)의 최신(2026) 공식 상세 — 네이버는 알고리즘을 공식 문서로 공개하지 않음. 모든 관련 내용은 실무자 역추정(tier: blog)에 의존할 수밖에 없음
- 티스토리 자체의 "저품질" 판정을 티스토리(카카오)가 공식적으로 정의한 문서 — 못 찾음. 전부 사용자 커뮤니티 경험담
