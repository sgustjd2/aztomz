# 블로그차트 상위 카테고리 공략 플랜 (10편)

출처: [blogchart.co.kr/chart/week](https://www.blogchart.co.kr/chart/week) 주간 블로그 순위(2026-08-31 스냅샷).
상위 20 블로그의 카테고리 분포에서 **트래픽 큰 카테고리** + **우리가 정직하게(실출처로) 쓸 수 있는 것**의 교집합으로 10편을 정했다.

## 원칙 (반드시)
- **정직 가능 카테고리만.** 인테리어·부동산·금융재테크·의학·교육은 실경험·전문 데이터·E-E-A-T가 필요해 정직하게 못 쓴다 → **제외**(철칙: 모르는 영역 LLM 단독 = 환각).
- 전부 **WebSearch 실출처 기반**(blog-researcher → curator). trends.json 얇은 풀에 기대지 않는다.
- **하루 4편 이하** 카덴스 유지 → 10편은 약 3일에 나눠. 각 편은 **쓰는 날 그날 조사**(미리 다 조사하면 상한다).
- 표준 흐름: 조사 → 집필(_format.md 양식) → **blog-selfreview** → blog-verify → 발행.
- 새 레인(여행·미용·가전·반려·건강)은 tistory 카테고리 **AZTOMZ**(라이프)로. 필요하면 나중에 세분.

## 운영 메모
- 각 편은 write 워크플로에서 `_format.md` 양식(콜아웃·비교표·정리·참고) + selfreview를 태운다.
- 새 카테고리라 category 프로파일이 없으면 write 프롬프트에서 구조(listicle 등)·tistory 카테고리(AZTOMZ)·해요체를 직접 지시한다.
- 정보성(9)·건강(10)은 실출처 3건+ 확보 못 하면 그 편을 스킵하고 다른 writable 카테고리로 대체(정직 우선).
- 이 플랜은 소진되면 갱신: blogchart를 다시 열어 writable 상위 카테고리로 다음 10편을 짠다.
