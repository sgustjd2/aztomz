# 05 자가검수

완성된 글을 **다른 사람이 쓴 것처럼** 냉정하게 채점한다. 후하게 주지 마라.
여기서 통과시킨 글이 그대로 공개 발행된다.

## 채점 (각 10점, 총 40점)

| 항목 | 10점의 기준 | 감점 |
|---|---|---|
| **가독성** | 첫 3문장에 독자 문제 적중, 문단 3줄 이내, 소제목만 훑어도 흐름이 보임 | 서론이 길다 / 문단이 벽 / 소제목이 내용을 안 알려줌 |
| **독창성** | 검색 상위 글에 없는 각도·경험·수치가 있음 | 어디서 본 내용의 재배열 / 일반론만 |
| **키워드** | 메인 키워드가 제목·첫 문단·H2에 자연스럽게, 밀도 1.5~2% | 억지 반복 / 아예 없음 |
| **신뢰성** | 수치·버전·날짜에 근거, 추측은 추측이라 표시, 출처 링크 | **지어낸 사실** / 근거 없는 단정 |
| **카테고리 적합성** | 구조 템플릿·`mustInclude` 를 다 지킴, `banned` 표현 0개 | 필수 항목 누락 / 금지어 사용 |

**5항목이지만 총점은 40점 만점**으로 계산한다(카테고리 적합성은 다른 항목에 녹여 채점하지 말고
독립으로 매기되, 총점은 가독성+독창성+키워드+신뢰성 4항목 합으로 낸다).
카테고리 적합성이 7점 미만이면 총점과 무관하게 **불합격**이다.

## 반드시 잡아야 할 것 (하나라도 있으면 신뢰성 5점 이하)

- 확인 안 된 수치·버전·날짜를 사실처럼 쓴 곳
- 존재하지 않을 수 있는 고유명사(라이브러리·API·곡·인물)
- 가사 인용 또는 번역
- 남의 이미지 URL
- 프로파일 `banned` 표현

## 출력 (JSON만)

```json
{
  "scores": { "readability": 8, "originality": 7, "keyword": 8, "credibility": 9, "categoryFit": 9 },
  "total": 32,
  "pass": true,
  "problems": [{ "where": "어느 섹션", "what": "무엇이 문제", "why": "왜 문제" }],
  "fixInstructions": ["03단계에 넘길 구체적 수정 지시 — pass 면 빈 배열"]
}
```

`total` 은 readability + originality + keyword + credibility 의 합.
`pass` 는 `total >= 32 && categoryFit >= 7`.
