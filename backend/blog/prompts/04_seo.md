# 04 SEO 점검

초안을 읽고 검색 노출에 필요한 것을 정리한다. **본문을 다시 쓰지 않는다** — 고칠 곳만 짚는다.

## 할 일

1. **검색 의도** — 조사 자료에서 메인 검색어 하나와 독자가 해결하려는 질문 하나를 확인한다. 검색량 자료가 없으면 수요를 숫자로 추정하지 않는다.
2. **키워드 배치** — 메인 검색어가 제목 앞쪽과 첫 문단에 자연스럽게 한 번씩 들어가고, 제목·첫 문단·본문이 같은 질문에 답하는지 확인한다. 고정 밀도나 반복 횟수를 맞추지 않는다.
3. **연관 키워드** — 조사와 본문에 근거한 관련 질문·표현 3~5개를 적고, 이미 본문에 있는 것과 없는 것을 나눈다. 근거가 없는 인기어를 보태지 않는다.
4. **메타 설명** — 80~155자. 첫 문장에 결론. 본문 첫 문단 복사 금지.
5. **태그 10개 이하** — 검색어 형태로. 붙임(`성수디저트`)과 띄움(`성수 디저트`)을 섞어도 된다.
   브랜드어 남발·무관한 인기어 금지.
6. **최종 제목 1개** — 아웃라인 후보 중 검색 의도와 본문이 가장 잘 맞는 제목을 고르거나 다듬는다.
   - 핵심 검색어를 앞 15자 안에 자연스럽게 넣고, 제목만 읽어도 독자가 찾는 답의 범위가 보이게 한다.
   - 28~42자와 후보 간 패턴 다양성을 기준으로 삼되, 억지로 늘리거나 줄이지 않는다.
   - 같은 키워드 반복, 무관한 인기어, 근거 없는 숫자·최상급·확정 표현, 내용과 다른 클릭 유도는 금지한다.
   - `titleReason`에는 핵심 검색어와 검색 의도에 맞춘 이유를 한 줄로 쓴다.
6. **슬러그** — 영문 소문자·하이픈.

## 출력 (JSON만)

```json
{
  "title": "...",
  "titleReason": "...",
  "description": "...",
  "tags": ["...", "..."],
  "slug": "...",
  "relatedKeywords": { "present": ["..."], "missing": ["..."] },
  "fixes": ["본문에서 고칠 것 — 없으면 빈 배열"]
}
```
