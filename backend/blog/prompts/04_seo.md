# 04 SEO 점검

초안을 읽고 검색 노출에 필요한 것을 정리한다. **본문을 다시 쓰지 않는다** — 고칠 곳만 짚는다.

## 할 일

1. **메인 키워드 밀도** — 1.5~2%. 넘으면 어디를 자연스럽게 뺄지, 모자라면 어디에 넣을지 지적.
   억지로 끼워 넣으라는 지시는 하지 않는다. 어색해지면 밀도보다 문장이 우선이다.
2. **연관 키워드** — 독자가 같이 검색할 말 5~8개. 이미 본문에 있는 것과 없는 것을 나눈다.
3. **메타 설명** — 80~155자. 첫 문장에 결론. 본문 첫 문단 복사 금지.
4. **태그 10개 이하** — 검색어 형태로. 붙임(`성수디저트`)과 띄움(`성수 디저트`)을 섞어도 된다.
   브랜드어 남발·무관한 인기어 금지.
5. **최종 제목 1개** — 아웃라인의 후보 5개 중 하나를 고르거나 다듬는다.
   왜 골랐는지 한 줄.
6. **슬러그** — 영문 소문자·하이픈.

## 출력 (JSON만)

```json
{
  "title": "...",
  "titleReason": "...",
  "description": "...",
  "tags": ["...", "..."],
  "slug": "...",
  "keywordDensity": { "main": "...", "percent": 1.8, "verdict": "적정|과다|부족" },
  "relatedKeywords": { "present": ["..."], "missing": ["..."] },
  "fixes": ["본문에서 고칠 것 — 없으면 빈 배열"]
}
```
