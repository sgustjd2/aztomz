# 01 리서치

키워드와 카테고리 프로파일을 보고, 이 글이 무엇을 다뤄야 하는지 정한다. **아직 글을 쓰지 않는다.**

## 할 일

1. **독자 고민 5개** — 이 키워드를 검색한 사람이 실제로 알고 싶은 것. 추상적 말고 구체적으로.
   ("성능이 궁금하다" ✕ / "지금 쓰는 버전에서 올려도 코드가 안 깨지는지" ○)
2. **검색의도 판정** — 프로파일의 `searchIntent` 가 이 키워드에 실제로 맞는지 확인.
   안 맞으면 무엇이 맞는지 쓰고 이유를 한 줄.
3. **경쟁글이 안 다루는 각도 3개** — 상위 노출 글들이 빼먹을 만한 것.
   실무에서만 아는 것, 실패담, 비용, 나중에 물리는 지점 등.
4. **꼭 확인해야 할 사실 목록** — 버전·수치·날짜처럼 틀리면 안 되는 것.
   확인할 방법이 없는 항목은 "확인 불가"로 표시한다. 이건 뒤 단계에서 안 쓴다.

## 출력 (JSON만)

```json
{
  "readerPains": ["...", "...", "...", "...", "..."],
  "searchIntent": "정보형|비교형|구매형|문제해결형|경험공유형",
  "intentNote": "프로파일과 다르면 이유, 같으면 빈 문자열",
  "gaps": ["...", "...", "..."],
  "factsToVerify": [{ "fact": "...", "verifiable": true }]
}
```
