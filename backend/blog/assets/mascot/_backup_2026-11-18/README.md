# 불타는 고구마 마스코트

## 이미지 에셋

- 2026-11-16에 GPT Image로 새로 만든 손그림 스티커 스타일 표정 8종이다. 보랏빛 고구마 껍질, 노릇한 속살, 세 갈래 불꽃을 공통 정체성으로 유지했다.
- 기존 표정별 포즈와 소품을 유지하면서 첨부된 손그림 스티커의 선과 평면 색감으로 변환했다. 파일은 투명 배경 512×512 PNG다.
- 본문 발행은 표정별 PNG를 사용한다. `mascot.mjs`의 `renderMascot()`가 PNG를 말풍선과 합쳐 최종 본문 그림을 만든다.
- `node backend/scripts/lib/mascot.mjs`는 표정 미리보기 판 `expressions-sheet.png`만 갱신한다. 표정 원본은 이미지 생성 도구에서 새로 만든 뒤 직접 교체한다.
- `concepts/`와 표정별 SVG는 이전 디자인 기록으로 남겨 둔다. 현재 네이버 글 발행 경로에서는 사용하지 않는다.

## 표정 8종

| expr | 이름 | 쓰는 자리 |
|---|---|---|
| explain | 설명 | 핵심 정리, 개념 설명 앞 |
| surprise | 놀람 | 의외의 사실, 오해 바로잡기 |
| thumbs | 엄지척 | 꿀팁, 추천, 장점 |
| caution | 주의 | 주의사항, 흔한 실수, "가기 전 확인" |
| think | 생각 | 질문형 소제목, 고민, 비교 직전 |
| hello | 인사 | 글 맨 끝(참고 자료 바로 앞) |
| checklist | 체크리스트 | 준비물, 확인 목록, 단계 |
| yum | 맛있음 | 음식, 레시피, 맛집 |

## 글에 넣는 규칙 (네이버 글만)

1. **정의 방식:** 메타 `figures[]`에 `{ "id":"m-think", "kind":"mascot", "expr":"think", "say":"말풍선 한마디", "title":"대체텍스트" }`를 넣는다. 본문에는 `[FIG: m-think]`를 쓴다.
   - `title`을 비우면 표정별 기본 대체텍스트를 쓴다.
2. **장수:** 네이버 글은 0~2장이다. 조립 검사기는 최대 3장까지 허용하며, 마스코트 수는 정보 그림(사진·카드) 수 + 1을 넘지 않는다.
   - 정보 그림 최소 1개 규칙은 그대로 둔다. 마스코트는 그 개수에 넣지 않는다.
3. **위치:**
   - 소제목 바로 아래에 둔다. 마무리용 `hello`만 마지막 소제목 바로 위에 둔다.
   - 첫 문단(답) 앞에는 두지 않는다.
   - 다른 그림과 붙여 두지 않는다. 사이에 본문 문단이 하나 이상 있어야 한다.
4. **표정:** 위 표대로 소제목 내용에 맞는 표정을 고른다. 한 글 안에서 같은 표정을 반복하지 않고, 같은 날 바로 앞 글과 같은 조합도 피한다.
5. **말풍선(`say`):** 선택 사항이다. 40자 이하로 쓰고 숫자는 넣지 않는다. 본문 내용을 요약하거나 독자에게 말을 거는 문장만 쓴다. 새 사실이나 체험한 척하는 말은 금지한다.
6. **검사:** `checkMascots(md, figures)`가 규칙을 검사한다. `blog-assemble`에서 호출한다.

## 발행 경로

- 발행기 `blog-publish-naver.mjs`는 `[FIG]` 자리에서 붙여넣기를 끊고, `makeFigure()`가 만든 PNG를 [사진] 버튼으로 업로드한다.
- `makeFigure`의 `kind: 'mascot'` 분기가 `renderMascot()`을 호출한다. 마스코트는 `assets/mascot/<expr>.png`를 읽어 사용하므로 SVG·HTML 스타일 변경은 캐릭터 그림에 반영되지 않는다.
