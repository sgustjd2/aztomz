# 불타는 고구마 마스코트 (B안 반쪽 군고구마, 2026-11-10 확정)

- 원본: `backend/scripts/lib/mascot.mjs`. 몸 코드는 하나만 두고 눈·입·팔·소품만 바꾼다. 그래서 모든 표정이 같은 캐릭터로 보인다.
- 다시 만들기: `node backend/scripts/lib/mascot.mjs`를 실행한다. 표정별 `<expr>.svg`·`<expr>.png`와 `expressions-sheet.png`를 다시 만든다.
- `concepts/`: 처음 만든 시안 A·B·C다. 기록용으로 남긴다.
- 직접 그린 SVG라 외부 그림이나 라이선스를 쓰지 않는다.

## 표정 8종

| expr | 이름 | 쓰는 자리 |
|---|---|---|
| explain | 설명 | 핵심 정리, 개념 설명 앞 |
| surprise | 놀람 | 의외의 사실, 오해 바로잡기 |
| thumbs | 엄지척 | 꿀팁, 추천, 장점 |
| caution | 주의 | 주의사항, 흔한 실수, "가기 전 확인" |
| think | 생각 | 질문형 소제목, 고민, 비교 직전 |
| hello | 인사 | 글 맨 끝(참고 자료 바로 앞) |
| checklist | 체크리스트 | 준비물, 확인 목록, 단계 |
| yum | 맛있음 | 음식, 레시피, 맛집 |

## 글에 넣는 규칙 (네이버 글만)

1. **정의 방식:** 메타 `figures[]`에 `{ "id":"m-think", "kind":"mascot", "expr":"think", "say":"말풍선 한마디", "title":"대체텍스트" }`를 넣는다. 본문에는 `[FIG: m-think]`를 쓴다.
   - `title`을 비우면 표정별 기본 대체텍스트를 쓴다.
2. **장수:** 글당 1~3장을 넣는다. 다만 마스코트 수는 정보 그림(사진·카드) 수 + 1을 넘지 않는다.
   - 정보 그림 최소 1개 규칙은 그대로 둔다. 마스코트는 그 개수에 넣지 않는다.
3. **위치:**
   - 소제목 바로 아래에 둔다. 마무리용 `hello`만 마지막 소제목 바로 위에 둔다.
   - 첫 문단(답) 앞에는 두지 않는다.
   - 다른 그림과 붙여 두지 않는다. 사이에 본문 문단이 하나 이상 있어야 한다.
4. **표정:**
   - 위 표대로 그 소제목의 내용에 맞는 표정을 고른다.
   - 한 글 안에서 같은 표정을 반복하지 않는다.
   - 같은 날 바로 앞 글과 같은 조합도 피한다.
5. **말풍선(`say`):**
   - 선택 사항이다. 40자 이하로 쓰고 숫자는 넣지 않는다. 확인 안 된 수치가 이미지 속에 들어가는 것을 막기 위해서다.
   - 본문 내용을 요약하거나 독자에게 말을 거는 문장만 쓴다. 새 사실이나 체험한 척하는 말은 금지한다.
6. **검사:** `checkMascots(md, figures)`가 위 2~5의 규칙을 검사한다. `blog-assemble`에서 호출할 예정이다.

## 발행 경로
- 마스코트도 다른 그림처럼 `[FIG]` 마커를 쓴다. 발행기 `blog-publish-naver.mjs`는 마커 자리에서 붙여넣기를 끊고, `makeFigure()`가 돌려준 PNG를 [사진] 버튼으로 업로드한다.
- 그래서 `makeFigure`에 `kind:'mascot'` 분기 하나만 추가하면 된다. 이 분기는 `renderMascot`으로 `<id>.mascot-<figId>.png`를 만든다.
