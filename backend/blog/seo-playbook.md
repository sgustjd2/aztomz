# 블로그 조회수 SEO 플레이북 (burning-go9me / AZTOMZ)

> 조회수를 올리는 **실제 레버**를 파이프라인 규칙으로 박은 문서. 주제선정·집필·발행 때 이걸 따른다.
> 근거·출처 원문은 [research/seo-levers-2026.md](research/seo-levers-2026.md)(2026-09-08 조사). 여기엔 실행 규칙만 요약한다.
> ⚠ 조회수는 **글 개수의 문제가 아니다.** 색인·검색수요·제목·시간이 레버다. 양산은 오히려 저품질 신호(하루 4편 이하 철칙과 같은 방향).

---

## §1. 주제 선정 — 검색수요와 독자 질문 먼저

1. **후보가 정해지면 발행 전 검색수요를 확인한다 — 파이프라인 게이트.**
   - `node backend/scripts/keyword-demand.mjs "<주제어>"` → 네이버 검색광고 키워드도구 API 로 **월간 검색수 절대값**(PC+모바일)을 조회, `--min`(기본 100) 미달이면 **exit 1 로 그 주제를 막는다.** 여러 주제 한 번에: `keyword-demand.mjs "주제1" "주제2"`. 자격증명(`.env`: `NAVER_AD_API_KEY`·`NAVER_AD_SECRET`·`NAVER_AD_CUSTOMER`)은 searchad.naver.com → API 사용 관리(무료)에서 1회 발급. 미설정이면 스크립트가 안내 후 exit 2.
   - 위 도구가 못 도는 상황(자격증명 미설정 등)이면 수동으로: 네이버 **검색광고 키워드도구**(searchad.naver.com) — 한국에서 **유일하게 "월간 검색수 절대값"**을 준다.
   - 네이버 **데이터랩**(datalab.naver.com) — 상대지수(0~100)만. 절대량 비교용 아님. 정량 비교는 같은 조회창에 최대 5개 키워드 함께.
   - 구글 트렌드 — 시계열 급상승·글로벌 반응 보조.
2. **"검색량은 있는데 경쟁 약한" 롱테일을 우선한다.** 신규·저권위 블로그(우리)가 바로 붙을 수 있는 유일한 틈새. 대형 단일 키워드는 초반엔 밀린다.
3. **실제 검색 표현을 주제·제목에 그대로 쓴다.** 우리 식 축약·의역(예: 은어)보다 사람들이 검색창에 치는 말(연관 키워드)로.
4. **시즌 키워드는 정점 3~4주 전에 발행**한다(신규 블로그 색인 지연 감안 — §4). 명절·연말정산 등은 "매년 반복되는 고정 질문 골격 + 그 해 시의성"으로 구성해 골격을 재활용.
5. 정직하게 못 쓰는 고volume(의학 진단·부동산·금융재테크·인테리어 = E-E-A-T/환각 위험)은 여전히 **제외**(CLAUDE.md 철칙). 검색수요가 크다고 예외 아님.

### 네이버 블로그 적용 기준

- 후보마다 검색자가 해결하려는 **구체 질문 하나**를 적고, 글에서 그 질문에 바로 답한다. 검색어와 무관한 유행어·인기 키워드는 끼워 넣지 않는다.
- 같은 분야 글을 연속 발행할 때 검색 의도까지 겹치지 않게 한다. 예: `보관법`, `손질법`, `고르는 법`은 각각 다른 질문으로 다룬다.
- 정해진 편수를 채우려고 얇은 후보를 쓰지 않는다. 조사 근거, 검색 의도, 우리 글만의 설명을 갖춘 주제가 없으면 목표보다 적게 쓴다.
- 검색수요 API가 없으면 검색량을 지어내거나 추정치처럼 보고하지 않는다. 공개 검색에서 실제 질문 표현과 기존 글의 정보 공백을 살피고 `검색량 미측정`을 기록한다.

## §2. 제목(title) 규칙

1. **핵심 키워드를 제목 맨 앞에 배치**한다(네이버·구글 공통, 구글 공식). 앞 25~30자 안에 주제어+핵심어가 다 들어가게(모바일 검색결과에서 뒤가 잘림).
2. **핵심 키워드는 자연스럽게 1회만.** 반복 삽입은 구글이 스팸으로 오인(공식 명시).
3. **각 글 제목은 고유하게**(구글 공식 요구). 같은 템플릿을 매 글 찍지 마라(양산 신호 — CLAUDE.md 철칙).
4. **연도/시기 태그("2026", "10월")는 내용이 실제 그 기준일 때만.** 근거 없이 기계적으로 붙이면 양산 신호.
5. 제목은 본문 내용과 정확히 일치(낚시 금지, 구글 공식).
6. 숫자·질문형 클릭유도는 통념일 뿐 공식 검증 없음 — 남용 말 것.
> blog-seo 단계는 이 §2를 따른다. blog-run-today/blog-daily 가 SEO 에이전트를 부를 때 이 규칙을 프롬프트에 넣는다.

## §3. 색인 등록 체크리스트 — 사람이 최초 1회 (⚠ 이게 안 되면 아무리 써도 검색 노출 안 됨)

**A. 네이버 서치어드바이저** (searchadvisor.naver.com)
1. 로그인 → 웹마스터 도구 → 사이트 등록.
2. 소유확인: HTML meta 태그 발급 → 티스토리 관리자 → 꾸미기 → 스킨 편집 → `<head>`에 삽입 → 확인.
3. 요청 → RSS 제출(`https://burning-go9me.tistory.com/rss`) + 사이트맵 제출(`sitemap.xml`).
4. "간단체크"로 robots·응답200·H1중복·alt누락 등 초록 확인.
5. 급하면 "웹페이지 수집요청"으로 개별 URL 수동 제출(일일 한도 있음).

**B. 구글 서치콘솔** (search.google.com/search-console)
1. 속성 추가(URL 접두어) → HTML 태그 `<head>` 삽입으로 소유확인.
2. Sitemaps → `sitemap.xml` 제출.
3. 신규 글 급하면 "URL 검사" → "색인 생성 요청"(건별 수동).

**티스토리 저품질·색인제외 유발 요인(피할 것):** 키워드 과다반복 · 자동생성/중복·복사 콘텐츠 · 매크로·자동공감 등 트래픽 조작 · 정보 대비 과도한 광고/상업링크 · H1 중복 · 이미지 alt 누락.
> 우리 파이프라인은 대부분 이미 지킴(고유 원고·출처검증·해요체·양산 회피). **남은 건 A·B 등록뿐 — 사람이 해야 함.**

## §4. 기대치 (조바심 관리)

- 신규 티스토리 **구글 색인**: 짧게 3일, 보통 2주 내외, 길게 3개월(공식 확정 수치 아님). **오늘 쓴 글이 오늘 조회수를 올리지 않는다.**
- 네이버는 RSS 제출 시 상대적으로 빠르게 반영(정확 시간 미공개).
- **도메인 신뢰도는 누적형**: 저권위일수록 롱테일부터 쌓아 상위 키워드로. **시간 자체가 요인** — 꾸준함 > 하루 물량.
- ("도메인 권위"를 구글이 공식 랭킹신호로 인정하는지는 미확인 — 다만 신규 사이트가 경쟁 키워드에서 밀리는 현상은 널리 관찰됨.)

## §5. 네이버 글의 완성도와 애드포스트 측정

네이버는 고정된 "상위노출 공식"이나 특정 글자 수·사진 수·키워드 반복 횟수로 노출을 보장한다고 안내하지 않는다. 공식 콘텐츠 가이드를 다음처럼 적용한다.

1. 제목과 첫 문단에서 질문에 곧장 답한다. 제목은 실제 내용과 맞고, 검색어를 억지로 반복하지 않는다.
2. 확인한 사실과 운영자의 해석을 구분한다. AI 초안에는 비교, 선택 기준, 주의점, 적용 예시 중 하나 이상을 근거에 맞게 더한다. 직접 해보지 않은 일을 체험담처럼 쓰지 않는다.
3. 쓸모 있는 시각 자료만 쓴다. 직접 촬영·제작한 사진, 비교 카드, 단계 그림을 설명 가까이에 배치하고 장수 채우기용 이미지는 넣지 않는다. 자료가 없으면 명확한 소제목·체크리스트로 읽기 흐름을 만든다.
4. 결론·비교·주의점이 스크롤만으로도 보이게 한다. 글자 수, 문단 길이, 사진 수는 주제에 맞게 정하며 고정 숫자를 상위노출 공식처럼 강제하지 않는다.
5. 관련 없는 인기 키워드, 과장·낚시 제목, 광고 클릭 유도는 금지한다. 네이버는 무관한 인기 키워드 삽입을 경고하고, 애드포스트는 클릭·노출을 인위적으로 유도하는 행위를 금지한다.

### 애드포스트 목표 운영

- 현재 기준은 **네이버 최대 9편/일 + 티스토리 최대 1편/일**, 전체 최대 10편/일이다(2026-11-09 사용자 지시). 수익을 위해 품질 게이트를 낮추거나 같은 질문을 여러 글로 쪼개지 않는다.
- `1만원/일`은 추적 목표이지 보장치가 아니다. 수익은 광고 종류·단가·노출 시간대·클릭률·무효 판정 등 여러 요인의 영향을 받는다. 880원·88원 두 날만으로 원인이나 필요한 게시량을 계산할 수 없다.
- 매일 비공개 기록: 날짜, 애드포스트 발생 수입, 블로그 전체 조회수와 유입경로(가능한 범위), 발행 글 ID와 주제. 노출·클릭 관련 지표는 개인 분석용으로만 관리하고 공개 콘텐츠에 공유하지 않는다.
- 일별 변동보다 **7일 이동평균**과 글별 발행 후 7일 누적 조회를 본다. 당일 수입은 보통 다음 날 보고서에 반영되며, 블로그 페이지뷰와 광고 노출은 집계 기준이 다를 수 있다.
- 매주 상위 유입 글의 검색어·질문·조회 추이를 다음 주 주제에 반영한다. 같은 조건의 글을 최소 2주 관찰하기 전에는 편수나 주제를 급격히 바꾸지 않는다.
- 일 목표 수익에 필요한 조회량은 실제 기간 데이터가 쌓인 뒤 계산한다. 대략식 `10,000 ÷ (기간 수입 ÷ 해당 기간 조회수)`는 광고 노출과 페이지뷰 집계 차이 때문에 방향 확인용으로만 쓴다.
