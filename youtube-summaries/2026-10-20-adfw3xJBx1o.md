## 핵심 주장
- **강력한 내부 플랫폼이 AI 에이전트의 빠른 개발과 성공을 가능하게 했습니다.** Monzo는 기존에 구축된 모니터링, 알림, 서드파티 통합, 스테이징 환경, 큐잉 추상화, 쉬운 배포, 데이터베이스 추상화 등 다양한 플랫폼 기능을 활용하여 Agent Chip을 신속하게 개발하고 가치를 창출할 수 있었습니다.
- **Agent Chip은 기술 및 비즈니스 전반에 걸쳐 상당한 생산성 향상을 가져왔습니다.** 이 에이전트는 전체 병합된 PR의 10% 이상을 작성하고 매일 1,800개 이상의 작업을 수행하며, 기술팀뿐만 아니라 비즈니스 사용자들에게도 적극적으로 채택되어 데이터 쿼리 작성 및 비즈니스 질문 답변 등 다양한 용도로 활용되고 있습니다.
- **에이전트 오케스트레이션 시스템은 안전하고 통제된 환경에서 AI 에이전트를 실행합니다.** Monzo는 MCP 게이트웨이를 통해 내부 서비스 및 지식 기반에 대한 접근을 관리하고, 에이전트 샌드박스 내에서 원격 에이전트를 실행하여 엄격한 도구 및 권한 통제 하에 비결정론적 행동을 안전하게 관리합니다.
- **Agent Chip의 구성 가능한(composable) 특성은 새로운 사용 사례를 지속적으로 창출합니다.** Slack, GitHub, Linear, 내부 시스템 등 다양한 소스와 연결될 수 있는 빌딩 블록으로서, Agent Chip은 인시던트 대응, 스쿼드 간 질문 처리, 데이터 품질 알림 분류 등 복잡한 비즈니스 프로세스를 자동화하고 엔지니어들이 더 높은 가치의 문제에 집중할 수 있도록 돕습니다.

## 세부 내용
Monzo는 "모두를 위한 돈벌이"를 목표로 하는 디지털 은행으로, 3,000개 이상의 백엔드 서비스, 12,000개 이상의 데이터 웨어하우스 모델, 수십 개의 ML 예측기를 유지 관리하는 데 AI 코딩 어시스턴트가 필요했습니다. 2026년 1월, Monzo 내부에서 '#agent-chip'이라는 슬랙 채널이 바이럴이 되었는데, 이는 메시지에 특정 이모지를 반응하면 에이전트가 프롬프트를 받아 작업을 수행하는 방식이었습니다.

현재 Agent Chip은 Monzo의 항상 사용 가능한 팀원이 되었습니다. 코드 리뷰를 수행하고, "Looks good to me"와 같은 간단한 피드백을 제공하며, 리니어(Linear) 태스크를 할당받아 처리할 수 있습니다. 현재 Agent Chip은 기술 부문 전체 병합된 PR의 10% 이상을 작성하고 있으며, 매일 1,800개 이상의 작업을 실행합니다. 또한, 비즈니스 사용자들에게도 적극적으로 채택되어 코딩 외의 다양한 비즈니스 질문에 답하는 데 사용되고 있습니다.

발표자들은 Agent Chip의 성공 비결이 LLM(Large Language Models)뿐만 아니라 "Lots of Little Multipliers"라고 강조했습니다. 이는 Monzo의 강력한 내부 플랫폼 덕분입니다. Monzo는 이미 모니터링, 알림, 서드파티 통합, 스테이징 환경, 큐잉 추상화, 쉬운 배포, 데이터베이스 추상화 등 다양한 기능을 갖추고 있었습니다.

특히, Monzo의 MCP(Monzo Control Plane) 게이트웨이는 지식 소스와 내부 도구에 대한 쉬운 접근을 가능하게 했습니다. AI 에이전트는 이 MCP 서버에 연결되어 내부 인증 및 권한 부여를 거쳐 결정론적 행동을 수행하며, 내부 서비스 및 지식 기반과 상호작용합니다.

또한, Agent Orchestration System은 에이전트를 샌드박스 환경에서 원격으로 실행하며, 엄격한 도구와 권한을 적용합니다. 이 시스템은 격리된 네임스페이스 내에 에이전트 샌드박스를 생성하고, 그 안에 에이전트 이미지와 프록시를 포함합니다. 프록시는 GitHub와 같은 외부 서비스에 연결하며, MCP 서버와도 통신합니다. 이를 통해 에이전트의 비결정론적 행동을 통제하면서도 개발 및 테스트를 용이하게 합니다.

이러한 빌딩 블록들을 통해 Monzo는 구체적인 비즈니스 성과를 달성했습니다.
1.  **더 높은 작업 범위와 볼륨**: 엔지니어들이 더 많은 종류와 양의 작업을 수행할 수 있게 되었습니다.
2.  **루틴 프로세스 자동화**: 인간이 더 높은 가치의 문제에 집중할 수 있도록 루틴 작업을 자동화했습니다. 예를 들어, 인시던트 발생 시 Agent Chip이 슬랙 채널에 참여하여 로그, 메트릭, 트레이스 등을 조사하고 라이브 요약을 제공하며, 잠재적 수정사항에 대한 PR 초안을 작성하기도 합니다. 또한, #squad-ask 채널에서 다른 팀의 질문에 대한 답변 초안을 작성하여 인간 검토자가 참고할 수 있도록 합니다.
3.  **비전문가의 시스템 기여 장벽 완화**: 데이터 품질 알림을 분류하고 백엔드 변경 사항을 확인하는 등, 비전문가도 Agent Chip을 통해 시스템에 더 쉽게 기여할 수 있게 되었습니다. Agent Chip On Call은 DBT(Data Build Tool) 알림 실패를 감시하고 자동으로 조사를 시작하여 잠재적인 데이터 문제를 사전에 파악합니다.

Monzo는 Agent Chip이 플랫폼의 핵심 부분이 되었으며, 그 구성 가능한 특성이 새로운 사용 사례를 가능하게 한다고 믿습니다. 플랫폼은 특정 제공업체에 얽매이지 않아(provider-agnostic) 다양한 LLM 모델을 유연하게 선택할 수 있습니다. Monzo는 백엔드 및 앱 변경 사항 초안 작성, 스테이징 환경에서의 테스트, 데이터 테스트, 심지어 예측기까지 포함하는 더 큰 개발 윈도우를 포괄하기 위해 계속 발전하고 있습니다.

## 실무 적용 포인트
1.  **기존 플랫폼 역량 활용**: 새로운 AI 에이전트 개발 시, 모니터링, 알림, 배포, 데이터베이스 추상화 등 기존에 구축된 내부 툴링과 플랫폼 기능을 최대한 활용하여 개발 속도를 높이고 가치를 창 창출할 수 있습니다.
2.  **안전한 에이전트 실행 환경 구축**: AI 에이전트가 내부 시스템에 접근할 때는 샌드박스 환경, 엄격한 권한 관리, 인증/인가 시스템을 포함하는 '에이전트 오케스트레이션 시스템'을 구축하여 보안과 통제력을 확보해야 합니다.
3.  **다양한 입력 채널 및 사용 사례 발굴**: 슬랙 반응, GitHub 연동, 티켓 시스템 통합 등 다양한 방식으로 에이전트와 상호작용할 수 있도록 하고, 기술팀뿐만 아니라 비즈니스 팀의 루틴 작업 자동화에도 에이전트를 활용하여 전사적인 가치를 창출할 수 있습니다.
4.  **인간-AI 협업 모델 설계**: 에이전트가 모든 것을 자율적으로 처리하기보다는, 인시던트 대응 시 정보 제공 및 초안 작성, 질문 답변 시 인간 검토를 거치는 등 'Human-in-the-loop' 방식을 통해 AI의 강점과 인간의 전문성을 결합하는 것이 중요합니다.
