# Generative UI... in Python? — Jeremiah Lowin, Prefect

🔗 https://youtu.be/Krzs8GeiWTc · 📅 2026-09-10 · 🎙 AI Engineer

## 한 줄 요약
파이썬 개발자들이 HTML, CSS, JavaScript 없이도 파이썬 DSL(Domain Specific Language)을 사용하여 반응형 UI를 쉽게 구성하고, 이를 AI 에이전트를 통해 사용자에게 제공하거나 에이전트가 직접 UI를 생성하도록 하는 Prefab 프레임워크를 소개합니다.

## 발표자·소속
Jeremiah Lowin, Prefect

## 핵심 주장
- **파이썬 기반 UI 구성의 자연스러움**: Prefab은 파이썬 개발자들이 익숙한 파이썬 문법과 컨텍스트 매니저를 활용하여 UI 컴포넌트를 구성할 수 있도록 하여, 프론트엔드 개발의 진입 장벽을 낮춥니다.
- **AI 에이전트와 사용자 간의 직접적인 UI 상호작용**: MCP Apps 확장을 통해 AI 에이전트가 생성한 UI(HTML, CSS, JavaScript)가 사용자에게 직접 전달되어, 사용자가 에이전트를 거치지 않고도 앱과 상호작용할 수 있게 합니다.
- **효율적인 UI 생성 및 전달 아키텍처**: Prefab은 파이썬으로 UI를 정의하고 이를 JSON 프로토콜로 직렬화한 후 React 런타임으로 렌더링하는 파이프라인을 사용합니다. 특히 파이썬 표현이 JSON보다 70% 작아 토큰 효율성, 비용, 지연 시간 측면에서 큰 이점을 제공합니다.
- **다양한 활용 사례 지원**: Prefab은 단순한 대화형 도구, 백엔드를 가진 완전한 애플리케이션, 그리고 AI 에이전트가 실시간으로 UI를 생성하는 제너레이티브 UI 등 다양한 AI 엔지니어링 시나리오에서 활용될 수 있습니다.

## 세부 내용

발표는 AI 엔지니어링 컨퍼런스에서 제레미아 로윈이 "Generative UI... in Python?"이라는 제목으로 진행되었습니다. 그는 자신이 개발한 소프트웨어 중 가장 특이한 것 중 하나라고 소개하며, AI 에이전트와 MCP(Multi-Agent Communication Protocol)가 가능하게 한 새로운 접근 방식을 설명했습니다.

먼저, **MCP Apps**의 개념을 소개했습니다. 기존 MCP 툴은 사용자의 요청을 에이전트가 받아 서버의 툴을 호출하고, 그 결과를 다시 에이전트가 받아 사용자에게 응답하는 방식이었습니다. 하지만 MCP Apps는 에이전트가 툴을 호출했을 때, 서버가 HTML, CSS, JavaScript로 구성된 완전한 UI를 사용자에게 직접 전달할 수 있도록 합니다. 이를 통해 사용자는 에이전트를 거치지 않고 앱과 직접 상호작용할 수 있으며, 향후에는 에이전트도 앱과 상호작용할 수 있는 기능이 추가될 예정입니다. 이는 테이블 예약, 비행기 좌석 변경, 스케줄 관리 등 다양한 인터랙티브 경험을 가능하게 합니다.

발표자는 자신이 개발한 **FastMCP** 프레임워크가 MCP 서버 구축에 널리 사용된다고 언급하며, 파이썬 엔지니어들이 프론트엔드를 구축해야 하는 문제에 직면했다고 설명했습니다. 이들은 소비자 수준의 맞춤형 UI보다는 조직 내 정보 공유 및 수집을 위한 UI를 필요로 합니다. 이러한 제약 조건이 **Prefab**이라는 스코프가 지정된 UI 구축 프레임워크를 개발하는 데 도움이 되었습니다.

Prefab은 파이썬으로 UI를 구성할 수 있도록 합니다. 발표자는 "Hello, world!" 카드 예시를 통해 파이썬 코드가 UI의 구조를 직관적으로 보여주며, "파이썬으로 프론트엔드를 구성하는 것은 불경스럽지만 놀랍도록 자연스럽다"고 강조했습니다. Prefab의 DSL(Domain Specific Language)은 컴포넌트를 클래스로, 레이아웃을 컨텍스트 매니저로, 상태를 반응형 변수(Rx variables)로 표현하여 JavaScript 없이도 클라이언트 측 상호작용을 가능하게 합니다.

Prefab의 아키텍처는 **Python -> JSON -> React** 파이프라인으로 구성됩니다. 파이썬으로 UI를 작성하면, 이는 직렬화 가능한 JSON 프로토콜로 변환되고, 최종적으로 React 앱 런타임에 의해 브라우저에 렌더링됩니다. 이 JSON 프로토콜은 에이전트가 이해하고 조작할 수 있는 중간 표현 역할을 합니다.

Prefab의 활용 사례는 세 가지로 나뉩니다:
1.  **대화형 도구(Interactive tools)**: MCP 툴에서 UI를 반환하는 방식으로, 대부분의 사용 사례에 해당합니다. `@mcp.tool(app=True)` 데코레이터를 사용하여 Prefab 컴포넌트(예: `DataTable`)를 반환하면, FastMCP가 자동으로 필요한 프론트엔드 요소를 생성하여 사용자에게 제공합니다. 데이터 테이블은 검색, 필터링, 정렬, 페이지네이션 기능을 지원합니다.
2.  **FastMCP 앱(FastMCP Apps)**: MCP 서버를 앱의 백엔드로 사용하는 완전한 애플리케이션입니다. `@app.ui`로 기본 UI를 정의하고, `@app.tool`로 백엔드 메서드를 정의하여 UI에서 호출할 수 있습니다. 파일 업로드와 같은 기능은 에이전트를 거치지 않고 서버로 직접 전송되어 효율성을 높입니다.
3.  **제너레이티브 UI(Generative UI)**: 에이전트가 MCP 앱 표면을 직접 생성하도록 하는 것입니다. 발표자는 Claude 에이전트에게 가장 흥미로운 UI를 스트리밍해달라고 요청하는 데모를 보여주었습니다. 에이전트는 복잡한 대시보드 UI를 실시간으로 생성했으며, 여기서 중요한 점은 파이썬 표현이 JSON 표현보다 약 70% 더 작다는 것입니다. 이는 토큰 효율성, 비용, 지연 시간 측면에서 상당한 이점을 제공합니다. 에이전트가 파이썬 코드를 생성하고, 이 코드가 샌드박스에서 실행되어 JSON으로 변환된 후 렌더링됩니다.

발표자는 Prefab의 문서(prefab.prefect.io)와 GitHub 저장소(github.com/PrefectHQ/prefab)를 소개하며, FastMCP에 이미 통합되어 있어 쉽게 사용할 수 있다고 언급하며 발표를 마쳤습니다.

## 실무 적용 포인트
- **파이썬 개발자의 프론트엔드 개발 간소화**: 파이썬 백엔드 개발자가 HTML/CSS/JS 지식 없이도 Prefab을 사용하여 내부 도구나 대시보드 UI를 직접 구축하여 개발 효율성을 높일 수 있습니다.
- **AI 에이전트의 사용자 경험 확장**: AI 에이전트가 단순 텍스트 응답을 넘어, 직접 상호작용 가능한 UI를 사용자에게 제공함으로써 에이전트 기반 서비스의 활용성과 사용자 만족도를 향상시킬 수 있습니다.
- **토큰 효율성 및 비용 절감**: 제너레이티브 UI에서 파이썬 코드를 스트리밍하는 방식은 JSON보다 훨씬 효율적이므로, 대규모 언어 모델(LLM)을 사용하는 에이전트 기반 애플리케이션의 운영 비용과 지연 시간을 줄일 수 있습니다.
- **백엔드 로직과 UI의 통합 관리**: FastMCP 앱을 통해 백엔드 로직(데이터베이스 연동 등)과 프론트엔드 UI를 하나의 파이썬 코드베이스 내에서 관리할 수 있어, 개발 및 유지보수의 복잡성을 줄일 수 있습니다.
