# Build a Research Agent with Claude Managed Agents (Part 2 of 4) — Anthropic

🔗 https://youtu.be/FGftGOzfohc · 📅 2026-10-12 · 🎙 AI Engineer

## 한 줄 요약
Anthropic은 Claude Managed Agents를 사용하여 인프라 관리 부담 없이 맞춤형 도구, 다중 에이전트 협업, 영구 메모리를 통해 복잡한 작업을 수행하고 지속적으로 학습하는 AI 에이전트를 구축하는 방법을 시연합니다.

## 발표자·소속

- 프리얀카(Priyanka), Anthropic

## 핵심 주장
- Claude Managed Agents는 인프라 관리 부담 없이 AI 에이전트 개발을 간소화합니다. Anthropic이 호스팅, 샌드박스 관리, 스케일링 등 모든 인프라를 처리하므로 개발자는 제품 구축에 집중할 수 있습니다.
- 에이전트는 맞춤형 도구와 스킬로 확장되어 전문화된 작업을 수행할 수 있습니다. 이를 통해 에이전트는 외부 API를 호출하거나 특정 데이터 소스에 접근하는 등 복잡한 기능을 수행할 수 있습니다.
- 다중 에이전트 협업은 복잡하고 장기 실행되는 작업을 전문화된 하위 에이전트에 위임할 수 있도록 합니다. 메인 에이전트가 작업을 조정하고, 하위 에이전트가 특정 부분(예: 재무 데이터 추출, 위험 평가)을 처리합니다.
- 영구 메모리(Memory Stores)와 '드리밍(Dreaming)' 기능은 에이전트가 세션 전반에 걸쳐 지속적으로 학습하고 개선할 수 있도록 지원합니다. 에이전트는 과거 세션의 경험을 분석하여 지식을 업데이트하고 미래 성능을 향상시킵니다.

## 세부 내용
발표는 AI 에이전트 개발의 복잡성을 줄이는 Claude Managed Agents의 이점을 강조하며 시작됩니다. 발표자는 에이전트가 세션 간에 정보를 저장하는 방식의 변화에 대한 질문에 답하며, 향후 이벤트를 위해 저장 메커니즘을 추상화하고 구성 요소를 모듈화하여 유연성을 높였다고 설명합니다.

데모는 Claude Console의 '퀵스타트' 섹션에서 시작됩니다. 프리얀카는 "농담을 해주는 에이전트를 만들어줘"라는 프롬프트를 입력하여 'Joke Teller'라는 에이전트를 즉시 생성합니다. 이 에이전트는 `claude-sonnet-3-4` 모델을 사용하며, 시스템 프롬프트, 이름, 설명, `agent_toolkit_dispatch` 작업이 자동으로 구성됩니다. 환경 설정 단계에서는 에이전트가 인터넷에 무제한으로 접근하도록 설정하고, `networking: type: unrestricted`와 같은 YAML 구성을 보여줍니다. 세션을 시작하고 "고양이에 대한 농담을 해줘"라고 입력하자 에이전트는 즉시 농담을 생성합니다. 프리얀카는 Anthropic이 인프라, 호스팅, 샌드박스 관리, 스케일링, 이벤트 로그 저장 등 모든 것을 관리하므로 개발자는 제품 구축에만 집중할 수 있다고 강조합니다.

이후 게이브가 핸즈온 워크숍을 진행하며, 참가자들이 GitHub 리포지토리(`https://github.com/anthropics/cwc-workshops/`)를 클론하고 `bun run dev`로 로컬 서버를 실행하여 'The Research Desk' 웹 UI에 접속하도록 안내합니다. 이 웹 UI는 Anthropic API 키와 EDGAR 신원 정보(이메일 및 이름)를 설정하는 페이지를 제공합니다.

데모는 에이전트를 점진적으로 구축하는 과정을 보여줍니다.
1.  **에이전트 생성:** 'head of research'라는 기본 에이전트와 환경이 생성됩니다.
2.  **채팅 인터페이스 구현:** `src/lib/sessions.ts` 파일을 업데이트하여 사용자 메시지를 에이전트에 보내고 에이전트의 응답을 SSE 스트림을 통해 브라우저로 다시 라우팅하는 기능을 추가합니다. 이를 통해 사용자는 에이전트와 대화할 수 있습니다.
3.  **에이전트 강화 (하위 에이전트 및 도구):** `src/lib/provision.ts` 파일을 업데이트하여 `dispatch_analysis`라는 사용자 정의 도구를 정의하고, `financial_extractor` 및 `risk_analyst`와 같은 하위 에이전트를 메인 에이전트에 추가합니다. 이 하위 에이전트들은 각자의 프롬프트, 도구, 권한을 가집니다. `edgartools` 스킬이 추가되어 SEC EDGAR 데이터에 접근할 수 있게 됩니다.
4.  **스코어카드 분석:** 'Scorecards' 탭에서 'NVDA' 티커에 대한 분석을 시작합니다. 에이전트는 메모리를 확인하고, EDGAR에서 SEC 문서를 가져오고, 재무 추출 및 위험 분석을 위해 하위 에이전트에 작업을 위임합니다. 하위 에이전트들이 작업을 완료하면 메인 에이전트는 메모리 노트를 작성하고 스코어카드 JSON을 생성합니다. '그레이딩(Grading)' 프로세스를 통해 에이전트의 결과물이 정의된 기준을 충족하는지 평가합니다.
5.  **지속적인 학습 (드리밍):** '드리밍' 기능은 에이전트가 여러 세션의 트랜스크립트와 메모리를 분석하여 메모리 저장소를 업데이트하고, 미래 에이전트가 더 나은 결정을 내릴 수 있도록 지속적으로 학습합니다.
6.  **스킬 업데이트:** 스킬은 라이브 아티팩트이므로, `margin_inventory_trend` 및 `segment_geographic_revenue`와 같은 새로운 기능을 추가하여 스킬을 업데이트할 수 있습니다. 업데이트된 스킬은 즉시 새로운 세션에 적용됩니다.

## 인상적인 대목
- 프리얀카의 "모든 인프라, 호스팅, 하네스, 샌드박스 관리, 스케일링, 이벤트 로그 저장은 Anthropic이 관리하므로, 여러분은 제품 구축에 집중할 수 있습니다."라는 발언은 개발자에게 큰 이점으로 다가옵니다.
- 에이전트가 스스로 작업을 평가하고 개선하는 '그레이딩' 및 '드리밍' 기능은 AI 에이전트의 자율성과 지속적인 학습 능력을 보여주는 핵심적인 부분입니다.
- 에이전트가 복잡한 작업을 하위 에이전트에 위임하고 그 결과를 조정하는 다중 에이전트 협업 방식은 실제 비즈니스 문제 해결에 AI를 적용할 수 있는 강력한 가능성을 제시합니다.

## 실무 적용 포인트
- **신속한 AI 에이전트 프로토타이핑 및 배포:** Claude Console을 활용하여 인프라 설정 없이 빠르게 에이전트를 구축하고 테스트할 수 있습니다.
- **도메인 특화 에이전트 개발:** 맞춤형 도구와 스킬을 정의하여 에이전트가 특정 산업(예: 금융, 법률)의 전문 지식을 활용하도록 확장할 수 있습니다.
- **복잡한 워크플로우 자동화:** 다중 에이전트 아키텍처를 설계하여 복잡한 작업을 여러 전문 하위 에이전트에 분산시키고 조정하여 효율성을 높일 수 있습니다.
- **지속적인 에이전트 개선:** 영구 메모리 저장소와 '드리밍' 기능을 활용하여 에이전트가 과거 경험을 통해 학습하고 시간이 지남에 따라 성능을 자동으로 향상시키도록 구현할 수 있습니다.
- **보안 및 유연한 데이터 접근:** Credential Vault를 사용하여 민감한 API 키를 안전하게 관리하고, egress 제어를 통해 에이전트가 접근할 수 있는 외부 도메인을 제한하여 보안을 강화할 수 있습니다. 또한 API 기반이므로 데이터를 다른 시스템으로 쉽게 이동할 수 있습니다.
