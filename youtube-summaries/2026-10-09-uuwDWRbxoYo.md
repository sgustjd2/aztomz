# AI Writes More PRs. Who Validates Them? — Ali-Reza Adl-Tabatabai, Sonar

🔗 https://youtu.be/uuwDWRbxoYo · 📅 2026-10-09 · 🎙 AI Engineer

## 한 줄 요약
AI 엔지니어링 컨퍼런스에서 Sonar의 Ali-Reza Adl-Tabatabai는 AI가 생성하는 코드의 증가로 인해 더욱 중요해진 PR(Pull Request) 검증의 문제를 제기하고, 이를 해결하기 위한 에이전트 기반의 자동화된 PR 검증 솔루션인 Gitar(현재 Sonar의 일부)를 소개하며, AI와 프로그램 분석의 결합이 개발 생산성과 코드 품질을 향상시킬 수 있다고 주장했습니다.

## 발표자·소속
Ali-Reza Adl-Tabatabai, Sonar (Gitar.ai의 창립자이자 전 CEO, 현재 Sonar의 EVP Transformation)

## 핵심 주장
- AI가 생성하는 코드의 양이 증가하면서 PR 검증의 중요성이 커지고 있지만, 동시에 검증 과정에 마찰을 더하고 있습니다.
- 기존의 PR 검증(CI 및 코드 리뷰)은 품질 게이트를 강제하고 소프트웨어 전달의 핵심 경로에 있지만, 실패 시 피드백 루프가 길고 최적화 비용이 높으며 AI 시대에는 더욱 복잡해집니다.
- AI 코드 생성 에이전트는 더 많은 코드 리뷰와 더 많은 실패를 야기하여 개발 비용을 우측(롤아웃 단계)으로 이동시키는 문제를 심화시킵니다.
- Gitar는 에이전트 기반의 PR 검증을 통해 PR 생성부터 병합까지의 전 과정을 자동화하여, 개발자가 AI가 생성하는 코드의 속도에 맞춰 작업할 수 있도록 돕습니다.
- 에이전트 기반 검증과 전통적인 프로그램 분석 기법을 결합하면 코드 품질, 보안, 개발 생산성 및 플랫폼 팀의 효율성을 더욱 향상시킬 수 있습니다.

## 세부 내용
발표자는 AI 엔지니어링 시대에 코드 검증의 중요성을 강조하며, 특히 PR(Pull Request) 검증 단계에 초점을 맞췄습니다. 그는 소프트웨어 개발 팀에서 코딩(AI 지원) 후 PR 검증(CI 및 코드 리뷰), 그리고 롤아웃으로 이어지는 일반적인 흐름을 설명했습니다. PR 검증 단계는 중앙 품질 게이트(보안, 규정 준수, 코드 품질)를 강제하고 소프트웨어 전달의 핵심 경로에 있으며, 개발 인프라 비용이 많이 들고 플랫폼 최적화의 주요 대상이 된다고 언급했습니다.

하지만 이 PR 검증 단계에는 문제가 있다고 지적했습니다. 실패가 발생하면 피드백 루프가 길어져(몇 시간에서 며칠 소요, 30% 이상의 오류율) 개발 흐름이 중단되고, 이는 개발자 시간 손실과 같은 값비싼 실패로 이어집니다. 또한, 파편화된 시스템과 맞춤형 구성으로 인해 최적화가 어렵고, AI를 적용할 경우 복잡한 워크플로우 오케스트레이션, 비동기적 상호작용, 팀 워크플로우, 도구 통합 등으로 인해 더욱 복잡해진다고 설명했습니다.

특히 AI 코드 생성 에이전트의 등장으로 이 문제는 더욱 심화됩니다. AI가 더 많은 코드를 생성하면서 더 많은 PR이 발생하고, 이는 더 많은 코드 리뷰와 더 많은 잠재적 실패를 의미합니다. 결과적으로 개발 비용이 개발 수명 주기의 후반부로 이동하게 됩니다. 개발자들은 모든 PR을 신중하게 검토하거나, PR을 형식적으로 승인하고 프로덕션에서 발생할 수 있는 사고 위험을 감수해야 하는 어려운 선택에 직면합니다.

이에 대한 해결책으로 발표자는 "에이전트 기반 PR 검증"을 제시했습니다. Gitar(현재 Sonar의 일부)는 이 에이전트 기반 접근 방식을 통해 고품질의 "녹색 PR(Green PRs)"을 자동으로 생성하는 것을 목표로 합니다.

Gitar의 기능은 다음과 같습니다:
1.  **리뷰:** PR을 검토하고 인라인 댓글과 함께 문제를 게시합니다. 목표는 실제적이고 중요한 이슈에 집중하여 노이즈 없는 경험을 제공하는 것입니다.
2.  **맞춤형 규칙:** 사용자가 자체 규칙을 정의하고, 맞춤형 검사를 추가하며, 맞춤형 워크플로우 자동화를 트리거할 수 있습니다.
3.  **차단:** 미해결 코드 리뷰 문제가 있을 경우 PR 병합을 차단하도록 시스템을 구성할 수 있습니다.
4.  **CI 실패 분석:** CI 실패를 분석하고 근본 원인 요약을 게시합니다. 특히 불안정한 테스트(flaky tests)를 잡아내는 데 능하며, 불안정한 테스트를 자동으로 재시도하는 규칙을 설정할 수 있습니다.
5.  **수정:** 코드 리뷰 문제나 CI 실패를 자동으로 수정할 수 있습니다. 특정 문제를 수정하도록 요청하거나, 모든 문제가 해결되어 PR이 병합 준비가 될 때까지 자동으로 수정 작업을 반복하도록 설정할 수 있습니다.
6.  **승인 및 병합:** 녹색 PR을 자동으로 승인하고 병합할 수 있습니다. 에이전트가 PR을 자동으로 승인하고 병합하는 규칙과 조건을 정의할 수 있습니다.

발표자는 사용자들이 시스템에 대한 신뢰를 쌓으면서 "완전한 PR 자동화"로 나아가는 궤적을 보여주는 그래프를 제시했습니다. 초기에는 리뷰에 집중하다가, 점차 차단, 수정, 승인, 병합 단계까지 자동화 수준을 높여간다는 것입니다. 자동화가 증가하고 신뢰가 쌓일수록 얻는 가치도 증가합니다.

Gitar는 모든 PR을 AI로 처리하여 새로운 유형의 통찰력을 제공합니다. 예를 들어, 플랫폼 팀에게는 상위 CI 실패 유형(불안정성, 인프라 문제 등)에 대한 분류를, 리더십 팀에게는 PR 유형(기능 개발, 버그 수정, 리팩토링, 문서 등)별 분포를 제공하여 엔지니어링 팀의 활동을 파악하는 데 유용합니다.

Gitar의 아키텍처는 웹 앱(관리 인터페이스, 구성, 감사 로그, 보고서, 통찰력), 제어 플레인(워크플로우 오케스트레이션, 이벤트 처리, 상태 관리, GitHub/GitLab UX), 에이전트 런타임(다중 에이전트 실행, 컨텍스트 및 메모리 관리, 도구 호출, 통합), LLM 프록시(다양한 모델 간 라우팅, 페일오버, 텔레메트리, 가드레일)로 구성됩니다. Sonar에 인수된 후 SonarQube와의 통합을 통해 에이전트 기반 검증과 프로그램 분석(taint analysis, control flow analysis, data flow analysis, software composition analysis 등)을 결합하여 더 나은 정밀도, 커버리지, 그리고 비용 효율성을 제공할 수 있게 되었습니다.

결과적으로 이러한 접근 방식은 더 나은 품질과 보안, 더 빠른 배포, 더 높은 개발자 생산성과 만족도, 그리고 플랫폼 팀을 위한 더 큰 레버리지를 가져온다고 강조했습니다.

## 실무 적용 포인트
- **PR 검증 자동화 도입:** AI 기반 코드 생성 도구를 사용한다면, PR 검증 단계에서 발생하는 마찰과 비용을 줄이기 위해 Gitar와 같은 에이전트 기반 자동화 솔루션 도입을 고려해야 합니다.
- **맞춤형 검증 규칙 설정:** 팀의 특정 보안, 규정 준수, 코드 품질 표준에 맞춰 맞춤형 검증 규칙을 설정하여 자동화된 검증의 효율성을 높일 수 있습니다.
- **CI 실패 분석 및 자동 수정 활용:** CI/CD 파이프라인에서 발생하는 실패를 자동으로 분석하고, 특히 불안정한 테스트(flaky tests)를 식별하여 자동으로 재시도하거나 수정하는 기능을 활용하여 개발 시간을 단축할 수 있습니다.
- **AI와 프로그램 분석의 결합:** 에이전트 기반의 AI 검증과 전통적인 정적/동적 프로그램 분석(taint analysis, control flow analysis 등)을 결합하여 코드 품질과 보안 검증의 정밀도와 커버리지를 극대화하는 전략을 수립할 수 있습니다.
