# Your LLM Judge Is a Confident Liar: Building Better Verifiers — Browserbase

발표자들은 LLM 기반 에이전트의 웹 작업 검증에서 기존 평가 방식의 문제점을 지적하고, 인간 전문가의 판단과 유사한 높은 신뢰도를 가진 새로운 '범용 검증기(Universal Verifier)'를 제안하며, 이 검증기가 더 나은 에이전트 모델 학습에 기여함을 입증했습니다.

## 핵심 주장
*   **기존 LLM 기반 평가의 신뢰성 부족:** 웹 환경에서 에이전트의 작업을 평가하는 기존 LLM 기반 검증기들은 종종 잘못된 성공을 보고하며, 이는 에이전트 학습에 있어 "자신감 있는 거짓말쟁이"를 양성하는 결과를 초래합니다.
*   **범용 검증기의 필요성:** 웹 환경의 개방성, 동적인 변화, 예측 불가능한 오류 등으로 인해 결정론적 검증 방식은 확장성이 떨어지므로, 인간의 판단과 유사하게 에이전트의 작업을 정확하게 평가할 수 있는 새로운 검증기가 필요합니다.
*   **범용 검증기의 4가지 설계 원칙:** 제안된 범용 검증기는 '요구된 것만 평가', '오류의 비연쇄성', '두 번 평가하고 픽셀을 신뢰', '제어 가능한 것과 불가능한 것 분리'라는 4가지 원칙을 통해 높은 정확도와 신뢰도를 달성합니다.
*   **더 나은 검증기는 더 나은 모델로 이어짐:** 범용 검증기를 통해 필터링된 고품질 데이터로 에이전트 모델을 학습시켰을 때, 기존 검증기로 필터링한 데이터보다 더 높은 성능을 보이는 모델을 얻을 수 있음을 실험으로 증명했습니다.

## 세부 내용

발표자 Miguel과 Corby는 AI 엔지니어링 월드 페어에서 "LLM 심사관은 자신감 있는 거짓말쟁이입니다: 더 나은 검증기 구축"이라는 주제로 발표했습니다.

발표는 웹 환경에서 에이전트의 작업을 평가하는 기존 방식의 문제점을 지적하는 것으로 시작했습니다. 이들은 자신들이 1년 반 동안 오픈 소스 프레임워크인 StateChain(스테이트체인)을 개발하면서, 에이전트의 성능을 평가하기 위한 결정론적 환경 구축에 어려움을 겪었다고 설명했습니다. 웹 환경은 '개방형 작업(Open-ended tasks)'이 많아 성공에 이르는 경로가 다양하고, '정답이 없으며(No ground truth)' 웹 페이지가 수시로 변경되어 어제 예상했던 답변이 오늘은 404 오류일 수 있습니다. 또한, CAPTCHA, 로그인 대기, 품절 등 '적대적인 환경(Hostile env.)' 요소가 많아 에이전트가 완벽하게 실행되어도 실패할 수 있습니다. 이러한 문제들로 인해 기존의 결정론적 검증 방식은 확장성이 떨어졌고, 결국 LLM 심사관(LLM Judge)에 의존하게 되었지만, 이 LLM 심사관들은 "지속적으로 틀린" 판단을 내렸습니다.

발표자들은 기존 LLM 기반 평가의 신뢰성 문제를 지적했습니다. WebVoyager(웹보이저)와 WebJudge(웹저지) 같은 선도적인 벤치마크에서 LLM 심사관이 실제 실패 사례의 45%와 22%를 각각 성공으로 평가하는 경향이 있음을 보여주었습니다. 이는 LLM 심사관이 "자신감 있는 거짓말쟁이"가 되어, 에이전트가 실제로는 실패했음에도 성공했다고 믿게 만들고, 결과적으로 더 나은 에이전트가 아닌 "더 자신감 있는 거짓말쟁이"를 훈련하게 된다는 의미입니다. 동일한 에이전트와 작업을 인간이 평가했을 때 WebVoyager의 성공률은 74.6%에서 37.9%로 크게 떨어졌습니다. 이는 기존 검증기들이 불완전하거나 부정확하다는 것을 의미합니다.

이러한 문제 해결을 위해 발표자들은 '범용 검증기(Universal Verifier)'를 제안했습니다. 이 검증기는 4가지 핵심 원칙을 기반으로 합니다.
1.  **요구된 것만 평가(Grade what was asked. Nothing else.):** 과제에서 명시적으로 요구된 기준만으로 평가하며, 에이전트가 수행하지 않은 불필요한 기준에 대해 점수를 깎지 않습니다. 예를 들어, 호텔 주소를 이용해 커피숍을 찾는 과제에서 "호텔 숙박 비용"을 묻는 것은 불필요한 기준입니다.
2.  **오류의 비연쇄성(Errors don't cascade. Don't punish twice.):** 한 단계에서 발생한 오류가 다음 단계의 평가에 영향을 미쳐 이중으로 페널티를 받지 않도록 합니다. 예를 들어, N'Sync와 Backstreet Boys 멤버 중 가장 긴 성을 가진 사람의 순자산을 찾는 과제에서, 에이전트가 성을 잘못 식별했더라도 그 잘못된 인물에 대한 순자산을 정확히 찾았다면, 순자산 검색 능력에 대해서는 페널티를 주지 않습니다.
3.  **두 번 평가하고 픽셀을 신뢰(Score twice, trust the pixels.):** 에이전트의 주장과 실제 스크린샷 증거를 비교하여 환각(hallucination)을 탐지합니다. 에이전트가 성공했다고 주장하지만 픽셀 증거가 이를 뒷받침하지 않으면 환각으로 간주하고 페널티를 줍니다.
4.  **제어 가능한 것과 불가능한 것 분리(Separate controllable from uncontrollable.):** 에이전트가 제어할 수 없는 환경적 요인(예: CAPTCHA, 품절)으로 인한 실패와 에이전트의 잘못으로 인한 실패를 구분합니다. 에이전트가 최선을 다했지만 환경적 요인으로 목표를 달성하지 못했다면, '과정 점수(process score)'에서는 성공으로, '결과 레이블(outcome label)'에서는 실패로 평가하여 에이전트의 노력에 대한 보상을 제공합니다.

범용 검증기의 작동 방식은 다음과 같습니다. 먼저, 주어진 작업에 대해 LLM이 '루브릭(rubric)'을 생성합니다. 이 루브릭은 작업을 성공적으로 완료하기 위한 여러 기준을 포함합니다. 다음으로, 에이전트의 작업 궤적에서 가장 관련성 높은 스크린샷 증거를 각 기준별로 선별하여 '관련성 매트릭스(relevance matrix)'를 생성합니다. 마지막으로, '현실 확인(reality check)' 단계를 통해 에이전트의 주장과 시각적 증거를 비교하여 각 기준의 충족 여부를 판단하고, 최종적으로 '과정 점수'와 '결과 레이블'을 출력합니다.

이러한 범용 검증기를 평가하기 위해, 발표자들은 3400개의 인간 라벨링된 궤적 데이터셋을 구축했습니다. 이 데이터셋은 각 궤적에 대해 두 명의 인간 전문가가 독립적으로 과정 및 결과 라벨을 부여한 것입니다. 이 데이터를 통해 범용 검증기의 성능을 측정했으며, 그 결과 범용 검증기는 기존 LLM 기반 검증기들의 45%에 달했던 '오탐(False Positives)' 비율을 1%로 줄이는 데 성공했습니다. 또한, 범용 검증기는 인간 전문가들 간의 합의율(Cohen's Kappa 0.58)과 거의 동일한 수준으로 인간 전문가들과 일치하는 결과를 보였습니다.

더 나아가, 발표자들은 "더 나은 검증기는 더 나은 데이터로, 더 나은 모델로 이어진다"는 가설을 검증했습니다. 3000개 또는 9000개의 궤적 데이터를 범용 검증기로 필터링하여 에이전트 모델을 훈련했을 때, 기존 검증기로 필터링한 데이터보다 더 높은 모델 성능을 달성했습니다. 이는 범용 검증기가 에이전트 학습에 필요한 고품질 데이터를 제공하여 모델 성능 향상에 직접적으로 기여함을 보여줍니다.

마지막으로, 발표자들은 '오토 리서치(Auto-Research)'를 통해 범용 검증기를 구축할 수 있는지에 대한 실험 결과도 공유했습니다. 인간 전문가가 3주에 걸쳐 검증기를 구축한 것과 비교하여, 오토 리서치 루프는 약 1일 만에 동일한 수의 실험을 수행했으며, 인간 전문가가 달성한 합의율의 70% 수준에 도달했습니다. 이는 AI가 검증기 구축 프로세스를 가속화할 수 있음을 시사하지만, 여전히 인간 전문가의 통찰력이 필요함을 보여줍니다.

모든 연구 결과와 코드는 오픈 소스로 공개되었으며, 논문은 arXiv(아카이브)에 게재되었고, 코드는 GitHub(깃허브)에 있습니다.

## 실무 적용 포인트
*   **LLM 기반 에이전트 평가의 재고:** 현재 LLM 기반 에이전트의 성능 평가에 LLM 심사관을 사용하고 있다면, 그 결과의 신뢰도를 의심하고 범용 검증기와 같은 더 견고한 평가 시스템 도입을 고려해야 합니다.
*   **검증기 설계 원칙 적용:** 에이전트 평가 시스템을 구축할 때 '요구된 것만 평가', '오류의 비연쇄성', '두 번 평가하고 픽셀을 신뢰', '제어 가능한 것과 불가능한 것 분리'와 같은 범용 검증기의 4가지 원칙을 설계에 반영하여 평가의 정확도와 공정성을 높일 수 있습니다.
*   **고품질 데이터의 중요성:** 에이전트 모델 학습 시, 단순히 많은 양의 데이터보다는 범용 검증기와 같이 신뢰할 수 있는 방식으로 필터링된 고품질 데이터를 사용하는 것이 모델 성능 향상에 더 효과적입니다.
*   **오토 리서치 활용:** 검증기 구축과 같은 연구 개발 과정에서 오토 리서치 루프를 활용하여 실험 속도를 높이고 초기 단계의 검증기 설계를 자동화할 수 있습니다. 다만, 최종적인 성능 최적화와 원칙 발견에는 인간 전문가의 개입이 여전히 중요합니다.
