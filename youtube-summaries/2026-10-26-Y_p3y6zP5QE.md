# Build Your Own Team of Managed Agents - Jack Wotherspoon, Google DeepMind

## 핵심 주장
-   **안전한 샌드박스 환경:** 관리형 에이전트는 격리된 클라우드 샌드박스(Linux 컨테이너) 내에서 실행되어 로컬 머신에 영향을 주지 않고 코드 실행, 테스트 및 검증을 수행합니다. 이는 보안 위험을 줄이고 개발 환경의 안정성을 보장합니다.
-   **뛰어난 확장성:** 로컬 머신에서 에이전트를 실행할 때 발생하는 권한 문제나 리소스 제약을 해결합니다. 클라우드 기반으로 수천 명의 사용자에게 확장 가능하며, 여러 에이전트를 동시에 실행하여 복잡한 작업을 효율적으로 처리할 수 있습니다.
-   **간소화된 개발 및 통합:** 에이전트 설정, 컨테이너 오케스트레이션, 네트워크 및 보안 구성 등 복잡한 인프라 작업을 추상화하여 단일 API 호출로 에이전트를 생성하고 실행할 수 있습니다. 이를 통해 개발자는 핵심 로직에 집중할 수 있습니다.
-   **상태 유지 및 협업 워크플로우 지원:** 상호작용(대화 기록)과 환경(파일 시스템, 데이터, 설치된 패키지)이 서버 측에서 상태를 유지하여, 여러 에이전트가 동일한 샌드박스 환경을 공유하며 작업을 이어받아 처리하는 다중 에이전트 워크플로우를 가능하게 합니다.

## 세부 내용

발표자는 관리형(Managed) 또는 클라우드(Cloud) 에이전트의 개념과 이점, 그리고 구글 딥마인드의 Gemini Managed Agents를 소개합니다.

**관리형 에이전트의 필요성:**
1.  **컴퓨터가 중요한 이유 (Why a Computer Matters):** 에이전트는 샌드박스 내에서 자신의 작업을 검증합니다. 테스트되지 않은 코드를 직접 처리하는 대신, 에이전트가 자체 컴퓨터에서 스크립트를 실행하고, 트레이스백을 검사하며, 버그를 수정하고, 검증된 결과물을 반환합니다. 이 과정은 자율적으로 샌드박스 내에서 이루어지며, 사람의 프롬프트가 필요 없습니다.
2.  **노트북은 확장되지 않습니다 (Your Laptop Doesn't Scale):** 로컬에서 에이전트를 실행하면 셸 명령마다 승인해야 하거나 개인 머신이 노출될 위험이 있습니다. 권한 프롬프트에 막히고, 개인 파일, SSH 키, 활성 세션이 공유되며, 노트북을 닫으면 중단되고, 수천 명의 고객에게 확장할 수 없습니다. 반면 클라우드 샌드박스는 자율적으로 실행 및 검증하며, 격리된 Linux 컨테이너로 제로 로컬 블래스트 반경을 제공하고, 백그라운드에서 실행되며, 수천 명의 사용자에게 확장 가능합니다.
3.  **인프라 격차 (The Infrastructure Gap):** 에이전트를 직접 설정하는 데는 몇 달이 걸릴 수 있습니다. 컨테이너 오케스트레이션(빠른 마이크로 VM 스핀업, 런 간 파일 시스템 스냅샷, 유휴 환경 가비지 수집), 에이전트 루프(도구 실행, 파일 편집, 웹 그라운딩, 다단계 오류 복구), 네트워크 및 보안(제로 트러스트 이그레스, API 키 외부 주입) 등의 복잡한 작업이 필요합니다.

**Gemini Managed Agents:**
이제 단일 API 호출로 이 모든 것을 해결할 수 있습니다. Gemini Managed Agents는 구글 호스팅 Linux 샌드박스, 영구 파일 시스템, 안티그래비티 루프를 기본으로 제공합니다.
예시 코드는 `client.interactions.create()`를 호출하여 에이전트(`agent='antigravity-preview-01-2024'`)를 생성하고, `environment='remote'`로 설정하여 클라우드에서 실행하도록 지시합니다. 이후 프롬프트와 함께 `print(interaction.output_text)`로 결과를 받습니다.

**아키텍처 개요 (Architecture Overview):**
사용자가 프롬프트를 입력하면 Gemini API를 호출합니다. Gemini API는 코드 실행, 파일 시스템, MCP 도구 등 서버 측 도구를 활용하여 요청을 처리합니다. 이 모든 것은 격리된 Linux 컨테이너(vCPU, RAM, 제로 트러스트 이그레스)로 구성된 샌드박스 내에서 실행됩니다. 사용자는 샌드박스에 파일을 업로드하거나 다운로드할 수 있습니다.

**관리형 에이전트의 구성 요소 (Building Blocks of Managed Agents):**
-   **Harness (agent_config):** 작업 계획, 도구 호출, 결과 확인을 담당하는 안티그래비티 하네스. Gemini 4 Argon(복잡한 추론 및 금융 모델링) 또는 Gemini 1.5 Flash(빠른 일상 에이전트 작업) 등 기본 모델을 설정할 수 있습니다.
-   **Environment (environment):** 영구적인 Linux 컴퓨터로, 파일과 패키지를 유지합니다.
-   **Tools (tools + mcp):** 내장 셸, 파일 시스템, 웹 검색 도구와 원격 HTTP MCP 서버 연결을 지원합니다.
-   **Skills (agents.md, skill.md):** `AGENTS.md`, `SKILL.md`에 정의된 지침과 반복 가능한 워크플로우입니다.
-   **Credentials (credentials):** API 키는 샌드박스 외부에서 주입되어 안전하게 유지됩니다.
-   **Schedule (triggers):** 에이전트가 부재 중일 때 작동하는 일회성 스케줄 및 백그라운드 실행을 설정합니다.

**Harness:** 안티그래비티 하네스는 루프를 실행합니다. 안티그래비티 제품과 동일한 하네스 위에 구축되었습니다. 다단계 작업을 계획하고, 도구를 실행하며, 자체 출력을 검증하고, 기본 모델을 구성합니다.

**Gemini 4 Argon:** 가장 어려운 작업을 위해 구축되었습니다. Gemini API 및 Google AI Studio에서 사용 가능합니다. 심층 추론, 금융 분석, 다단계 에이전트 작업을 위해 특별히 제작되었습니다. 웹 인덱스에서 1위를 차지하며 금융, 코딩, 법률, 세금 분야의 프론티어 모델을 선도하고, 에이전트 코드 제출을 30% 향상시킵니다. 최대 100만 토큰의 긴 디코딩을 지원하며, 튜닝 가능한 사고 수준(낮음, 중간, 높음)으로 입력 + 사고 = 출력의 공유된 컨텍스트 창을 제공합니다. 비용과 속도를 위해 Gemini 1.5 Flash와 함께 사용하면 가장 어려운 추론 작업을 Argon으로, 빠르고 일상적인 작업을 Gemini 1.5 Flash로 처리할 수 있습니다.

**상호작용 및 환경은 상태를 유지합니다 (Interactions and Environments are stateful):**
대화 기록과 파일 시스템은 서버 측에서 별도로 상태를 유지합니다. 한 에이전트가 환경에 파일을 준비하면, 두 번째 에이전트가 새로운 대화로 바로 이어서 작업을 수행할 수 있습니다.
-   **Interactions:** `previous_interaction_id`를 통해 대화 메시지와 추론 턴을 유지합니다.
-   **Environments:** `environment` ID를 통해 샌드박스 파일, 데이터, 설치된 패키지를 유지합니다.
예시 코드는 `researcher` 에이전트가 데이터를 `workspace`에 저장하고, `quant-analyst` 에이전트가 동일한 환경 ID를 사용하여 해당 파일을 읽고 차트를 생성하는 다중 에이전트 워크플로우를 보여줍니다.

**도구 (Tools):** 내장 샌드박스 도구와 원격 MCP를 지원합니다. 모든 관리형 에이전트는 셸, 파일 시스템, 웹 검색 기능을 기본으로 제공하며, 몇 줄의 코드로 원격 HTTP MCP 서버에 연결할 수 있습니다.
-   `code_execution`: Bash, Python, Node.js를 샌드박스에서 캡처하여 실행합니다.
-   `filesystem`: 파일 읽기, 쓰기, 검색 및 편집을 수행합니다.
-   `google_search`: 웹 검색 및 API 컨텍스트 페이징을 통해 라이브 검색을 수행합니다.
-   `mcp_server`: 외부 모델 컨텍스트 프로토콜 서버를 HTTP를 통해 연결합니다.

**스킬 (Skills):** 플레이북으로 에이전트를 구성합니다. `AGENTS.md`, `SKILL.md`, Git 리포지토리 또는 클라우드 스토리지 버킷을 샌드박스에 직접 마운트한 다음, 설정을 저장된 에이전트로 승격시킵니다.

**자격 증명 (Credentials):** 비밀은 샌드박스에 절대 들어가지 않습니다. `client.credentials.create()`를 통해 토큰과 자격 증명을 한 번 저장합니다. 에이전트가 권한이 있는 도메인에서 호출할 때, 이그레스 프록시가 네트워크 상에서 비밀을 주입합니다. 샌드박스 컨테이너는 더미 토큰만 메모리에 가지고 있으며, 이그레스 프록시가 실제 비밀 토큰을 첨부하여 외부 API로 요청을 보냅니다. 이는 샌드박스가 비밀을 유출할 수 없도록 합니다.

**스케줄 (Schedule):** 백그라운드에서 스케줄에 따라 실행하거나 팬아웃(fan out)하여 실행합니다. `client.triggers.create()`로 반복 작업을 스케줄링하거나, `background=True`로 비블로킹 병렬 실행을 시작할 수 있습니다. 예를 들어, 매일 아침 시장 개장 전 위험 보고서를 가져오는 에이전트를 스케줄링할 수 있습니다.

**라이브 빌드 데모 (Live Build Demo):**
에이전트가 작업을 이어받을 수 있도록 환경을 재사용하는 데모입니다.
-   **Step 1: Research (SEC Filing Researcher):** NVIDIA에 대한 분기별 수익 및 세그먼트를 조사하고 작성합니다. (결과: `metrics.json` 파일 생성)
-   **Step 2: Quant Model (Quant DCF Modeler):** `metrics.json` 파일을 기반으로 Python DCF(할인 현금 흐름) 모델을 실행하여 NVIDIA의 가치 평가를 수행합니다. (결과: `valuation.png` 생성)
-   **Step 3: Briefing (Exec Report Writer):** `metrics.json`과 `valuation.png`를 읽어 브리핑 보고서를 작성합니다. (결과: `exec_report.pdf` 생성)
이 데모는 각 에이전트가 이전 에이전트가 생성한 파일을 재사용하여 작업을 이어받는 과정을 보여줍니다.

**Finance Story 데모:**
영수증과 재무 원장을 대화형 재무 요약으로 변환하는 데모입니다. 관리형 에이전트를 사용하여 구글 드라이브에 업로드된 회사 데이터를 분석하고, 연간 지출, 분기별 현금 흐름, 자본 지출, 자본 배분 등 다양한 재무 지표를 시각화된 대시보드로 보여줍니다.

**Tickr 데모:**
지능형 재무 문서 분석기입니다. 주식 또는 ETF 티커 심볼을 입력하면, 관리형 에이전트가 SEC 공시 및 공개 정보를 자동으로 찾아 분석하고, 주요 통찰력을 식별하며, 경영진 논평을 요약하고, 여러 재무 보고서를 종합하여 상세한 보고서를 생성합니다.

**시작하기 (Get Started Today):**
-   Google AI Studio (`ai.studio`)에서 Gemini API의 관리형 에이전트로 시작할 수 있습니다.
-   `ai.studio/managed-agents`에서 문서, 빠른 시작 가이드, 다중 에이전트 아키텍처를 확인할 수 있습니다.

## 인상적인 대목
-   "Now it's a single API call." (이제 단일 API 호출입니다.) - 복잡한 AI 에이전트 시스템을 단순화하여 개발자가 쉽게 접근하고 통합할 수 있도록 만든 점이 매우 인상적입니다.
-   "Secrets never enter the sandbox." (비밀은 샌드박스에 절대 들어가지 않습니다.) - 에이전트의 보안을 최우선으로 고려하여 민감한 자격 증명을 안전하게 관리하는 아키텍처는 실제 서비스 적용에 있어 매우 중요한 요소입니다.

## 실무 적용 포인트
-   **다중 에이전트 워크플로우 구축:** `environment` ID를 사용하여 여러 관리형 에이전트가 동일한 파일 시스템과 데이터를 공유하며 순차적 또는 병렬적으로 작업을 수행하는 복잡한 워크플로우를 설계할 수 있습니다. 예를 들어, 데이터 수집 에이전트, 분석 에이전트, 보고서 작성 에이전트를 연동할 수 있습니다.
-   **에이전트 스케줄링:** `client.triggers.create()`를 활용하여 특정 시간(예: 매일 아침 시장 개장 전)에 에이전트를 자동으로 실행하도록 설정하여, 정기적인 데이터 분석, 보고서 생성, 알림 발송 등의 작업을 자동화할 수 있습니다.
-   **보안 자격 증명 관리:** `client.credentials.create()`를 통해 API 키나 기타 민감한 정보를 샌드박스 외부에서 안전하게 관리하고, 필요할 때만 이그레스 프록시를 통해 에이전트에 주입하여 보안 위험을 최소화합니다.
-   **커스텀 도구 및 스킬 통합:** `AGENTS.md` 또는 `SKILL.md` 파일을 샌드박스에 마운트하거나 원격 HTTP MCP 서버를 연결하여, 특정 비즈니스 로직이나 기존 시스템과 연동되는 맞춤형 도구 및 스킬을 에이전트에 부여할 수 있습니다.
