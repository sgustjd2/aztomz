Reactor는 실시간 월드 모델을 위한 플랫폼을 구축하여 이 기술에 대한 접근성을 민주화하는 시리즈 A 기업입니다.

## 핵심 주장
- **비디오의 패러다임 전환:** 기존의 비디오는 수동적인 기록이었으나, 실시간으로 픽셀을 생성하고 상호작용할 수 있게 되면서 소프트웨어처럼 프로그래밍 가능한 새로운 미디어가 됩니다.
- **실시간 기술의 역사적 선례:** 지도(기록)가 GPS(실시간)로 발전하여 Uber와 같은 온디맨드 서비스를 가능하게 했고, 필름 카메라(기록)가 디지털 뷰파인더(실시간)로 발전하여 TikTok과 Instagram 같은 창작 플랫폼을 탄생시킨 것처럼, 실시간성은 새로운 카테고리를 창출합니다.
- **세 가지 핵심 모델 유형:** 실시간 상호작용 비디오는 크게 세 가지 유형의 모델로 나눌 수 있습니다: 무한하고 상호작용적인 비디오 생성(Veo/Sora와 유사), 사용자가 걸어 들어갈 수 있는 가상 세계 생성(Genie-style과 유사), 그리고 현실적인 아바타 생성입니다.
- **새로운 애플리케이션 영역:** 이러한 실시간 비디오 모델은 게임을 넘어 새로운 대화형 경험, 로봇 공학 시뮬레이션을 위한 훈련 데이터 생성, 몰입형 교육, 실시간 광고, 그리고 대화형 라이브스트림 및 비디오 편집과 같은 다양한 분야에서 혁신적인 적용 가능성을 제시합니다.
- **인프라의 중요성:** 실시간 월드 모델을 서비스하는 것은 일반적인 모델 추론과 달리, 끊임없이 연결을 유지하고 상태를 관리하며 낮은 지연 시간을 보장해야 하는 복잡한 인프라 과제를 수반합니다. Reactor는 이러한 복잡성을 API 뒤에 숨겨 개발자들이 쉽게 접근할 수 있도록 합니다.

## 세부 내용

발표는 비디오의 본질에 대한 질문으로 시작합니다. 과거의 비디오는 항상 수동적인 기록이었으며, VEO3나 C-DENSE2와 같은 최신 AI 모델도 프롬프트를 입력하면 결과물 파일이 나오는 "슬롯 머신" 방식에 불과하다고 지적합니다. 발표자는 비디오가 소프트웨어처럼 프로그래밍 가능해지고 픽셀이 실시간으로 생성될 때 어떤 일이 일어날지에 대한 질문을 던지며, 이것이 콘텐츠 생산과 소비 방식을 완전히 바꿀 것이라고 강조합니다.

역사적 선례로 두 가지를 제시합니다. 첫째, 종이 지도(기록)는 GPS(실시간)로 발전하여 사용자의 실시간 위치를 반영하고, 이를 통해 Uber, 배달 서비스, 실시간 내비게이션과 같은 "온디맨드" 카테고리를 창출했습니다. 둘째, 필름 카메라(기록)는 디지털 뷰파인더(실시간)로 발전하여 촬영자가 실시간으로 결과물을 확인하고 조정할 수 있게 함으로써 TikTok과 Instagram 같은 사용자 생성 콘텐츠 플랫폼의 기반을 마련했습니다. 발표자는 실시간성이 단순히 속도를 빠르게 하는 것을 넘어, 미디어의 본질을 변화시키고 새로운 카테고리를 잠금 해제한다고 주장합니다.

이러한 "더 깊은 변화"는 비디오가 프로그래밍 가능해질 때 발생합니다. 픽셀이 실시간으로 생성되면, 비디오는 더 이상 고정된 자산이 아니라 소프트웨어처럼 동작하게 됩니다. API를 통해 비디오의 내용을 주소 지정하고, 조건을 부여하고, 변경할 수 있게 됩니다.

발표자는 현재 등장하고 있는 세 가지 유형의 실시간 월드 모델을 소개합니다.
1.  **유형 01: 실시간 상호작용 비디오 (Veo 및 Sora와 유사)**: 무한하고, 상호작용적이며, 실시간으로 작동합니다. 사용자가 프롬프트를 통해 비디오 내용을 변경할 수 있으며, 예를 들어 강아지 영상에 "고양이 등장"을 프롬프트하면 실시간으로 고양이가 나타나는 데모를 보여줍니다. 이는 콘텐츠 제작자에게 즉각적인 피드백과 통제권을 제공하여 "슬롯 머신" 방식의 종말을 가져옵니다. 또한, 실시간 광고 삽입과 같이 미리 제작되지 않은 광고를 비디오에 동적으로 배치하는 새로운 광고 모델을 가능하게 합니다.
2.  **유형 02: 걸어 들어갈 수 있는 세계 (Genie-style과 유사)**: 사용자가 캐릭터를 조작하여 생성된 세계를 탐색할 수 있는 모델입니다. 이는 게임을 넘어 새로운 대화형 경험(예: Netflix의 Bandersnatch와 같은 선택형 스토리), 로봇 공학 시뮬레이션을 위한 무한한 훈련 데이터 생성, 그리고 역사적 순간을 직접 체험하는 것과 같은 몰입형 교육 경험을 가능하게 합니다.
3.  **유형 03: 현실적인 아바타**: 실시간으로 상호작용하는 아바타로, 고객 지원, 교육, 영업, 게임, 스트리밍 서비스 등 다양한 분야에서 활용될 수 있습니다. 발표자는 현재 아바타들이 아직 "불쾌한 골짜기"에 있지만, 실시간 상호작용 기술이 이 문제를 해결하고 실제와 같은 대화를 가능하게 할 것이라고 믿습니다.

Reactor의 프라이빗 베타 사용자들은 이미 이러한 모델들을 활용하여 다양한 애플리케이션을 구축하고 있습니다.
- **대화형 라이브스트림:** 사용자가 이미지로 세계를 생성하고, 프롬프트를 통해 다음 장면을 투표하여 실시간으로 스토리를 진행합니다.
- **의료 시뮬레이션:** 의료진을 위한 대화형 훈련 시뮬레이션을 구축하여 절차를 시각화하고 연습합니다.
- **요리 시뮬레이션:** 사용자가 가상 주방에서 요리 과정을 단계별로 따르며 실시간으로 재료 추가 등의 반응을 확인합니다.
- **비디오 편집:** 푸티지를 사용하여 실시간으로 비디오를 생성하고, 프롬프트나 클릭을 통해 시각 효과를 추가하거나 배경을 변경하는 등 편집 작업을 수행합니다.

이러한 실시간 월드 모델을 구축하기 위한 인프라는 일반적인 모델 추론과 근본적으로 다릅니다. 일반 추론은 요청-응답 방식이지만, 실시간 월드는 끊임없이 열려 있고 상태를 유지하는 "세션"으로 작동합니다. 연결이 유지되고, 입력이 지속적으로 스트리밍되며, 모든 프레임은 지연 시간이라는 마감 기한 내에 렌더링되어야 합니다. 지연 시간 자체가 제품의 핵심 요소가 됩니다. 또한, 각 세계는 메모리를 가지며 단일 GPU에 고정되어야 하므로, 세션이 끊어져도 세계가 초기화되지 않고 재개될 수 있도록 메모리 관리가 중요합니다. 마지막으로, 실시간 경험은 사용자가 어디에 있든 100밀리초 미만의 지연 시간을 제공해야 하므로, 전 세계에 GPU 컴퓨팅 자원을 분산 배치하고 사용자를 가장 가까운 GPU로 지오-라우팅하는 글로벌 스케일 인프라가 필수적입니다.

Reactor는 이러한 복잡한 인프라를 API 뒤에 숨겨 개발자들이 쉽게 실시간 월드 모델을 제품에 통합할 수 있도록 합니다. 발표자는 몇 줄의 코드로 LingBot과 같은 실시간 모델을 통합하는 JavaScript/TypeScript 코드 스니펫을 보여주며, 개발자들이 이 새로운 프론티어에서 빌딩을 시작하도록 독려합니다.

## 인상적인 대목
- "Video has always been passive." (비디오는 항상 수동적이었습니다.)
- "What happens when it becomes programmable, like software?" (비디오가 소프트웨어처럼 프로그래밍 가능해지면 어떻게 될까요?)
- "When pixels can be generated in real time." (픽셀이 실시간으로 생성될 때.)
- "A map is a recording. GPS is alive." (지도는 기록입니다. GPS는 살아있습니다.)
- "You can't create what you can't see in real time." (실시간으로 볼 수 없는 것은 만들 수 없습니다.)
- "The end of the slot machine." (슬롯 머신의 종말.)
- "Instant feedback is the ultimate level of control." (즉각적인 피드백은 궁극적인 통제 수준입니다.)
- "Serving a world is not like serving a model." (세계를 서비스하는 것은 모델을 서비스하는 것과 다릅니다.)
- "Latency is not a number you optimize, it is the product itself." (지연 시간은 최적화하는 숫자가 아니라, 그 자체로 제품입니다.)
- "Evaluation for these real-time models is an unsolved problem." (이러한 실시간 모델에 대한 평가는 아직 해결되지 않은 문제입니다.)

## 실무 적용 포인트
- **실시간 비디오 API 활용:** Reactor와 같은 플랫폼의 API를 사용하여 텍스트-투-비디오, 이미지-투-비디오, 가상 세계 탐색, 실시간 비디오 편집 등 다양한 실시간 비디오 기능을 기존 애플리케이션에 쉽게 통합할 수 있습니다.
- **새로운 사용자 경험 설계:** 실시간 상호작용 비디오의 특성(무한성, 상호작용성, 즉각성)을 활용하여 기존에는 불가능했던 새로운 유형의 사용자 경험(예: 대화형 라이브스트림, 몰입형 교육 시뮬레이션, 동적 광고)을 기획하고 개발할 수 있습니다.
- **로봇 공학 및 시뮬레이션 데이터 생성:** 실시간 월드 모델을 활용하여 로봇 훈련을 위한 무한한 양의 시뮬레이션 데이터를 생성하고, 다양한 물리적 시나리오를 테스트하여 로봇의 행동을 최적화할 수 있습니다.
- **모델 경량화 및 분산 처리:** 실시간 모델의 낮은 지연 시간 요구사항을 충족하기 위해 모델 가중치 최적화, 양자화 기술, 멀티 GPU 활용, 그리고 전 세계에 분산된 GPU 인프라를 통한 지오-라우팅 전략을 고려해야 합니다.
