# Beyond Static Intelligence: Evaluating Continual Learning — Parth Asawa, UC Berkeley

## 한 줄 요약
발표자는 현재 AI 모델 평가 방식이 정적 지능에 초점을 맞춰 지속적 학습 능력을 제대로 측정하지 못하고 있으며, 실제 학습 능력을 평가하기 위한 새로운 벤치마크 설계 기준과 지표가 필요하다고 주장합니다.

## 발표자·소속

## 핵심 주장
*   **현재 AI 모델 평가는 정적 지능에 치우쳐 있습니다.** 기존 벤치마크는 모델이 각 작업을 독립적으로 수행하고 이전 경험을 잊어버리는 것을 가정하여, 모델이 시간이 지남에 따라 학습하고 개선되는 능력을 측정하지 못합니다.
*   **지속적 학습은 샘플 효율적이며 장기적으로 안정적인 온라인 학습입니다.** 이는 이전 정보를 잊지 않으면서 새로운 정보에 적응하고 지식을 업데이트하는 모델의 능력을 의미하며, 현재의 '훈련 후 고정 체크포인트 배포' 패러다임을 넘어서야 합니다.
*   **지속적 학습 벤치마크는 학습을 유도하도록 설계되어야 합니다.** 기존 벤치마크를 단순히 연결하는 것만으로는 부족하며, 헤드룸(개선 여지), 공유 구조(이전 경험 활용), 학습 메커니즘(피드백을 통한 개선)이라는 세 가지 핵심 기준을 충족해야 합니다.
*   **'이득(Gain)' 지표를 통해 실제 학습 능력을 측정할 수 있습니다.** 모델의 상태 유지(Stateful) 성능과 상태 비유지(Stateless) 성능 간의 차이를 측정하는 '이득' 지표는 모델의 초기 능력과 인스턴스별 난이도에 관계없이 축적된 경험이 실제 성능 향상에 기여했는지 파악할 수 있게 합니다.

## 세부 내용

발표자는 AI 및 머신러닝 컨퍼런스에서 모델의 "스마트함"에만 초점을 맞추고 "학습 능력"에 대해서는 충분히 논의하지 않는다고 지적하며 발표를 시작합니다. 현재 언어 모델(LLM) 평가 방식은 새로운 모델이 출시될 때마다 다양한 벤치마크(예: Terminal Bench 2.0, FrontierMath, AIME 2025)에서 독립적인 작업 수행 능력을 측정하고 리더보드를 제시하는 방식입니다. 이는 마치 모델이 매번 "기억을 완전히 잊고 처음부터 다시 시작"하는 것과 같다고 비유합니다.

발표자는 진정한 학습 능력은 이전 경험을 통해 성능이 점진적으로 향상되는 형태로 나타나야 한다고 주장하며, 이를 **지속적 학습(Continual Learning)**이라고 정의합니다. 지속적 학습은 샘플 효율적이고 온라인 학습이며 장기적으로 안정적이어야 합니다. 이는 이전 정보를 잊지 않고(안정성) 새로운 정보에 따라 지식을 업데이트하는(가소성) 능력을 포함합니다. 현재 LLM 훈련은 대규모 데이터로 오프라인 사전 훈련 후 고정된 체크포인트를 배포하는 방식이므로, 지속적 학습을 위한 메커니즘이 부족합니다.

기존 지속적 학습 연구는 인컨텍스트 학습(In-Context Learning), 외부 메모리(노트패드, 키-값 저장소), 또는 파라미터 업데이트 방식 등을 탐구해왔습니다. 그러나 발표자는 현재의 평가 방식으로는 이러한 지속적 학습 능력을 제대로 측정할 수 없다고 강조합니다. 기존 평가는 모델이 이전 경험을 통해 개선될 것이라는 기대를 담고 있지 않기 때문입니다.

**지속적 학습 벤치마크 설계 기준:**
발표자는 기존 벤치마크를 단순히 연결하는 방식의 한계를 지적하며, 새로운 지속적 학습 벤치마크는 다음 세 가지 기준을 충족해야 한다고 제시합니다.
1.  **헤드룸(Headroom):** 모델이 오프라인 훈련만으로 해결할 수 없는, 온라인 적응이나 학습이 필요한 작업이어야 합니다.
2.  **공유 구조(Shared Structure):** 연속된 작업 인스턴스 간에 모델이 활용할 수 있는 공유된 잠재 구조가 존재해야 합니다. 이를 통해 모델은 이전 경험을 바탕으로 미래 인스턴스에서 성능을 향상시킬 수 있습니다.
3.  **학습 메커니즘(Learning Mechanism):** 모델이 이전 경험을 통해 학습하고 개선될 수 있도록 환경에서 명확한 피드백(예: 스칼라 보상, 오류 메시지, 텍스트 피드백)을 제공해야 합니다.

**지속적 학습 측정 지표:**
발표자는 '보상(Reward)' 외에 **'이득(Gain)'**이라는 새로운 지표를 제안합니다.
*   **보상(Reward):** 각 작업 인스턴스에서 모델이 얻는 점수입니다.
*   **이득(Gain):** 상태 유지(Stateful) 모델의 보상에서 상태 비유지(Stateless) 모델의 보상을 뺀 값입니다. 이는 모델의 인스턴스별 난이도와 초기 모델 능력에 관계없이, 축적된 경험이 실제 성능 향상에 얼마나 기여했는지를 측정합니다.

**데이터베이스 탐색(Database Exploration) 예시:**
발표자는 데이터베이스 탐색 작업을 예시로 들어 설명합니다. 에이전트는 자연어 질문에 답하기 위해 SQL 쿼리를 수행해야 합니다.
*   **콜드 스타트(Cold Start):** 초기에는 데이터베이스 스키마나 데이터 특성에 대한 정보가 없어 많은 쿼리(탐색)가 필요합니다.
*   **경험 적용(Past Experience Applied):** 에이전트가 지속적으로 학습하는 시스템이라면, 이전 질문들을 통해 스키마와 데이터 특성을 학습하여 나중에는 더 적은 쿼리로 질문에 답할 수 있게 됩니다.
*   **개념 드리프트(Concept Drift):** 데이터베이스 마이그레이션 등으로 스키마가 변경되면, 에이전트는 이전 지식 중 무엇을 버리고 무엇을 업데이트해야 할지 판단해야 합니다. 이는 안정성-가소성 트레이드오프를 테스트합니다.

**Continual Learning Bench 1.0:**
발표자는 UC Berkeley, Snorkel AI, UW-Madison 등과의 협력을 통해 개발한 **Continual Learning Bench 1.0**을 소개합니다. 이 벤치마크는 6가지 도메인(Blind Spectrum Monitoring, Codebase Adaptation, Cohort Studies, Exploitable Poker, Database Exploration, Sales Prediction)에서 총 300개 이상의 개별 작업 인스턴스로 구성됩니다. 각 도메인은 점진적으로 해결해야 하는 작업 시퀀스를 포함하며, 위에 언급된 설계 기준을 만족합니다.

**초기 결과 및 실패 모드:**
초기 평가 결과, 인컨텍스트 학습(ICL) 시스템이 리더보드에서 높은 순위를 차지했습니다. 이는 보상 및 이득 대 비용(Cost)의 파레토 프론티어에서도 확인됩니다. 발표자는 대부분의 실패 모드가 **안정성-가소성 트레이드오프(Stability-Plasticity Trade-off)**의 한쪽 측면에 치우쳐 있다고 설명합니다.
*   **안정성 실패(Stability Failure):** 모델이 이전 정보를 유지하지 못하고 새로운 정보에 과도하게 적응하여 과거 지식을 잊어버리는 경우 (예: Sales Prediction에서 이전 피드백을 잊고 다시 과대 예측하는 경우).
*   **가소성 실패(Plasticity Failure):** 모델이 새로운 정보에 적응하지 못하고 기존 지식에만 의존하는 경우 (예: Epidemiology에서 새로운 스키마 정보를 인식하지 못하고 이전 스키마에 대한 잘못된 추론을 하는 경우).

**더 넓은 관점:**
발표자는 현재 LLM 훈련 스택(사전 훈련 -> 지도 미세 조정 -> RLHF)이 복잡해졌지만, 지속적 학습은 여전히 사후적으로 추가되는 경향이 있다고 지적합니다. 그는 우리가 "매몰 비용 오류(sunk cost fallacy)"에 빠져 현재의 훈련 방식에 얽매여 있다고 주장하며, 지속적 학습을 시스템 설계의 "첫 번째 원칙(first-order principle)"으로 삼아 훈련 및 배포 단계를 재고해야 한다고 제안합니다. 더 나아가, AI 연구 전반의 오픈 사이언스, 권력 집중, 안전성, 학계의 역할 등 광범위한 질문에 대해 재고할 기회가 있다고 강조합니다.

## 인상적인 대목
*   "지속적 학습은 점 능력(point capabilities)처럼 보이지 않습니다. 우리는 분야로서 올바른 목표를 최적화하기 위해 올바른 방식으로 측정해야 합니다."
*   "벤치마크 인스턴스는 독립적으로 설계되어 있으며, 작업 간에 공유된 구조가 없습니다." (기존 벤치마크의 한계 지적)
*   "이득(Gain) = 상태 유지 보상 - 상태 비유지 보상" (지속적 학습의 핵심 지표 제안)
*   "대부분의 실패 모드는 지속적 학습의 핵심 과제인 안정성-가소성 트레이드오프의 한쪽 측면에 치우쳐 있습니다."

## 실무 적용 포인트
*   **모델 평가 시 '이득(Gain)' 지표 고려:** 단순히 총 보상(Aggregate Reward)만 볼 것이 아니라, '상태 유지 모델의 보상 - 상태 비유지 모델의 보상'을 계산하여 모델이 실제 경험을 통해 얼마나 학습하고 개선되었는지 측정합니다.
*   **지속적 학습을 위한 태스크 설계 원칙 적용:** 새로운 AI 에이전트나 모델을 개발할 때, 헤드룸(개선 여지), 공유 구조(이전 경험 활용), 학습 메커니즘(명확한 피드백)을 고려하여 작업 환경을 설계합니다.
*   **안정성-가소성 트레이드오프에 대한 이해:** 모델이 이전 지식을 잊지 않으면서(안정성) 새로운 정보에 효과적으로 적응하는(가소성) 균형을 찾는 것이 지속적 학습의 핵심임을 인지하고, 이 두 가지 측면에서 모델의 성능을 분석합니다.
*   **온라인 학습 및 적응 메커니즘 통합:** 모델이 배포 후에도 지속적으로 환경과 상호작용하며 데이터를 통해 스스로 업데이트하고 개선될 수 있는 아키텍처 및 알고리즘을 탐구합니다.
