# Realtime Voice Agents with Frontier Intelligence — Bohan Li, EliseAI

🔗 https://youtu.be/MBHOH1NmDqc · 📅 2026-09-15 · 🎙 AI Engineer

## 한 줄 요약
EliseAI는 실시간 음성 에이전트의 지능을 유지하면서 응답 속도를 획기적으로 개선하기 위해 계층형 아키텍처와 스트리밍, 비동기 캐싱 기술을 활용한 혁신적인 접근 방식을 제시합니다.

## 발표자·소속
보한 리 (Bohan Li), EliseAI

## 핵심 주장
-   **계층형 아키텍처**: 음성 에이전트를 인지(Perception), 계획(Planning), 제어(Controls)의 세 가지 계층으로 나누어 각 단계에서 최적화된 AI 모델과 기술을 적용합니다.
-   **스트리밍 추측 전사기 (Streaming Speculative Transcriber)**: 빠르고 스트리밍 방식의 전사기(Flux)와 정확하지만 느린 배치 전사기(Scribe V2)를 결합하여 실시간성과 정확성을 동시에 확보합니다.
-   **비동기 백그라운드 도구 주입 (Async Background Tool Injection)**: 언어 모델의 도구 호출(tool calling)로 인한 지연을 줄이기 위해 백그라운드 에이전트가 도구 호출을 미리 수행하고 그 결과를 메인 에이전트의 컨텍스트에 주입하여 응답 시간을 단축합니다.
-   **오디오 프리픽스 캐시 (Audio Prefix Cache)**: 텍스트-음성 변환(TTS) 과정에서 에이전트의 발화 초반 부분을 캐싱하여 재사용하고, 나머지 부분은 실시간으로 생성하여 사용자에게 끊김 없는 자연스러운 음성 경험을 제공합니다.

## 세부 내용
발표자는 실시간 음성 에이전트 개발의 복잡성을 자율주행차 개발에 비유하며, 인지, 계획, 제어의 세 가지 계층으로 시스템을 설명했습니다.

**1. 인지 (Perception) 계층 - 스트리밍 추측 전사기:**
음성 에이전트의 인지 계층은 사용자의 음성을 텍스트로 변환하는 전사(transcription)를 담당합니다. EliseAI는 이를 위해 "스트리밍 추측 전사기"라는 개념을 도입했습니다. 이는 빠른 스트리밍 전사기(예: Flux)와 정확하지만 지연이 있는 배치 전사기(예: Scribe V2)를 결합한 방식입니다. 스트리밍 전사기는 즉각적인 텍스트를 제공하여 빠른 응답을 가능하게 하고, 배치 전사기는 더 많은 컨텍스트를 기반으로 정확한 최종 텍스트를 제공합니다. 만약 스트리밍 전사기의 결과가 배치 전사기의 결과와 다르면, 배치 전사기의 더 정확한 결과로 수정됩니다. 발표자는 이 과정을 통해 실시간으로 텍스트를 얻으면서도 높은 정확도를 유지할 수 있다고 설명했습니다.

**2. 계획 (Planning) 계층 - 비동기 백그라운드 도구 주입:**
계획 계층에서는 언어 모델(LLM)이 인지 계층에서 얻은 텍스트를 바탕으로 답변을 생성하고 필요한 경우 외부 도구를 호출합니다. LLM의 추론 및 도구 호출은 지연을 유발할 수 있습니다. EliseAI는 이 지연을 줄이기 위해 "비동기 백그라운드 도구 주입"을 사용합니다. 이는 메인 에이전트가 도구 호출을 직접 수행하는 대신, 백그라운드 에이전트가 비동기적으로 도구 호출을 처리하고 그 결과를 메인 에이전트의 컨텍스트에 주입하는 방식입니다. 이로 인해 메인 에이전트는 마치 자신이 도구 호출을 수행한 것처럼 인식하며, 불필요한 추론 라운드 트립을 줄여 전체적인 응답 속도를 향상시킵니다.

**3. 제어 (Controls) 계층 - 오디오 프리픽스 캐시:**
제어 계층은 언어 모델이 생성한 텍스트를 음성으로 변환하여 사용자에게 전달하는 텍스트-음성 변환(TTS)을 담당합니다. 실시간 대화를 위해 TTS 지연을 최소화하는 것이 중요합니다. EliseAI는 "오디오 프리픽스 캐시"를 활용하여 이를 해결합니다. 에이전트가 텍스트를 스트리밍 방식으로 생성할 때, 이미 생성된 텍스트의 앞부분(prefix)에 해당하는 오디오가 캐시에 있는지 확인합니다. 캐시에 있는 오디오는 즉시 재생하고, 캐시에 없는 새로운 부분만 TTS 엔진(예: Cartesia)에 전달하여 실시간으로 생성합니다. 이 과정을 통해 에이전트의 전체 발화가 완료되기 전에 오디오 재생을 시작하여 사용자에게 더 빠르고 자연스러운 대화 경험을 제공합니다.

**데모 시연:**
발표자는 실제 통화 기록을 재생하여 이러한 기술들이 어떻게 작동하는지 시연했습니다. 사용자가 임신 여부 확인을 위해 초음파 예약을 요청하고, 에이전트가 이름과 생년월일을 묻는 대화가 진행됩니다.
-   사용자가 "Elise Trial, 2003년 9월 2일"이라고 말하자, 에이전트는 `lookup_name_and_dob` 도구 호출을 시도하고 성공합니다.
-   에이전트는 보험 정보 업로드 링크를 텍스트로 보내겠다고 제안하고, `send_insurance_link` 도구 호출이 성공합니다.
-   에이전트는 가장 빠른 예약 가능 시간을 제시하고, 사용자가 "2 PM"을 선택하자 예약이 완료됩니다.
이 과정에서 화면에는 실시간으로 전사된 텍스트, 에이전트의 내부 상태 변화(도구 호출 성공/실패, 캐시 히트/미스), 그리고 TTS 엔진(Cartesia)으로 전달되는 텍스트가 표시되어 복잡한 백그라운드 작업들이 사용자에게는 매끄러운 대화로 느껴지도록 하는 과정을 보여주었습니다.
