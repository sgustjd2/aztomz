# Teaching LLMs to Speak Spotify — Yves Raimond & Jacqueline Wood, Spotify

🔗 https://youtu.be/2LRIAfng7eA · 📅 2026-09-25 · 🎙 AI Engineer

## 한 줄 요약
Spotify는 오픈 소스 대규모 언어 모델(LLM)을 Spotify 카탈로그에 대한 지식으로 미세 조정하여 개인화된 추천 시스템을 '생성적 개인화' 시대로 전환하고, 사용자가 자연어로 콘텐츠를 제어하고 설명할 수 있도록 합니다.

## 발표자·소속
- Yves Raimond, Spotify
- Jacqueline Wood, Spotify

## 핵심 주장
- **개인화 패러다임의 전환**: Spotify는 큐레이션과 추천을 넘어, 사용자가 자연어로 경험을 상호작용하고 동적으로 형성할 수 있는 '생성적 개인화' 시대로 진입하고 있습니다.
- **LLM의 카탈로그 인식**: Spotify는 기존 콘텐츠 임베딩을 이산 토큰(Semantic ID)으로 변환하고, 이를 오픈 소스 LLM의 어휘에 추가하여 LLM이 Spotify 카탈로그를 이해하고 생성할 수 있도록 합니다.
- **NEO 훈련 프레임워크**: Spotify는 Semantic ID 생성, 도메인 그라운딩, 역량 유도, 작업별 후처리 등 4단계로 구성된 NEO라는 독점적인 훈련 프레임워크를 개발하여 LLM을 카탈로그에 기반한 생성기로 만듭니다.
- **성능 및 활용**: 이 모델은 Spotify DJ, 프롬프트 재생 목록, 취향 프로필, 개인 팟캐스트와 같은 새로운 사용자 경험을 가능하게 하며, 기존 추천 표면에서도 상당한 개선(예: 비습관적 팟캐스트 스트리밍 +5.4%, 신규 쇼 발견 +14.3%)을 가져왔습니다.
- **LLM 기반 평가의 중요성**: 생성적이고 설명 가능한 추천의 복잡성으로 인해 기존의 오프라인 평가 지표는 불충분하며, LLM 심사위원을 의미 있는 데이터로 그라운딩하는 것이 인간의 선호도와 일치하는 신뢰할 수 있는 평가를 위해 필수적입니다.

## 세부 내용

발표는 Spotify의 개인화 여정을 설명하며 시작되었습니다. 현재 Spotify는 월간 활성 사용자 7억 6천 1백만 명 이상, 184개 시장, 1억 개 이상의 음악 트랙, 70만 개 이상의 오디오북, 7백만 개 이상의 팟캐스트 타이틀, 53만 개 이상의 비디오 팟캐스트를 보유하고 있습니다. 이처럼 방대하고 다양한 카탈로그에서 사용자에게 적합한 콘텐츠를 매칭하는 것은 매우 복잡한 문제입니다.

Spotify의 개인화는 세 가지 시대로 구분됩니다. 첫째, **큐레이션** 시대에는 사용자들이 직접 100억 개 이상의 재생 목록을 만들어 취향을 정리했습니다. 둘째, **추천** 시대에는 이러한 큐레이션 신호를 활용하여 Discover Weekly(2014년 출시)와 같은 개인화된 추천 서비스를 대규모로 제공했습니다. 셋째, 현재 진입하고 있는 **생성** 시대에는 사용자의 상호작용과 동적인 피드백을 통해 맞춤형 경험을 제공하는 것을 목표로 합니다.

생성적 개인화는 몇 가지 큰 변화를 수반합니다. 첫째, 개인화가 '추측'에서 '추론'으로 바뀝니다. LLM은 추천 결과를 분석하고 특정 맥락에서 사용자에게 가장 적합한 매치인지 이해할 수 있습니다. 둘째, '블랙박스 알고리즘'에서 '투명하고 조종 가능한 개인화'로 전환됩니다. LLM이 자연어를 이해하고 말할 수 있게 되면서 사용자는 추천 시스템을 완전히 제어할 수 있습니다. 셋째, 단순히 '추천'하는 것을 넘어 '생성하고 설명'하는 개인화가 가능해집니다.

발표에서는 이러한 생성적 개인화의 실제 사례들이 시연되었습니다.
- **Spotify DJ**: 사용자가 "오늘 하루를 시작할 잔잔한 음악"과 같은 자연어 프롬프트를 입력하면, DJ가 개인화된 음악을 재생하고 세션을 사용자의 지시에 따라 조종합니다.
- **프롬프트 재생 목록**: 사용자는 "오늘 밤 샌프란시스코에서 공연하는 밴드들의 재생 목록을 만들어 줘" 또는 "8분 페이스로 30분 달리기 위한 재생 목록을 만들어 줘"와 같이 구체적인 프롬프트를 통해 재생 목록을 생성할 수 있습니다. 시스템은 요청에 따라 동적으로 경험을 구성합니다.
- **취향 프로필**: 뉴질랜드에서 출시된 이 기능은 사용자가 Spotify 알고리즘이 자신에 대해 이해한 내용을 자연어로 확인하고 수정할 수 있도록 합니다. 예를 들어, "모든 디즈니 음악은 우리 아이들 취향이니 나에게는 추천하지 말아달라"고 요청하거나, 새로운 장르 탐색과 같은 목표를 공유할 수 있습니다.
- **개인 팟캐스트 (출시 예정)**: 사용자의 커뮤니티 이벤트, 콘서트, 날씨, 헤드라인 등 개인화된 일일 브리핑 팟캐스트를 생성하는 기능입니다.

이러한 모든 애플리케이션을 제어하는 핵심 시스템은 Spotify 내부에서 '대규모 취향 모델(The Large Taste Model)'이라고 불립니다. 이 모델은 Spotify의 모든 과거 상호작용과 콘텐츠를 이해하고, 예측과 추론을 결합하며, 사용자가 자연어로 실시간 경험을 형성하고 생성할 수 있도록 합니다. 현재 미국 프리미엄 구독자의 4명 중 1명이 이 경험을 사용하고 있으며, 자동 재생 곡 저장 9% 증가, 팟캐스트 발견 9% 증가, DJ 메시지 상호작용 사용자 20% 증가와 같은 긍정적인 결과를 보였습니다.

Jacqueline Wood는 모델 훈련 방식을 자세히 설명했습니다. 그들은 오픈 소스 LLM을 단일의 종단 간 카탈로그 기반 생성기로 변환하기 위한 NEO 프레임워크를 사용합니다.
- **Semantic ID 생성**: 기존 콘텐츠 임베딩(예: 팟캐스트 에피소드 임베딩)에 양자화 알고리즘을 적용하여 이산 토큰(Semantic ID) 세트로 변환합니다.
- **LLM 미세 조정**: Qwen과 같은 오픈 소스 LLM의 어휘를 수정하여 새로운 Semantic ID 토큰을 추가하고, 모델이 자연어와 Semantic ID 토큰을 모두 이해하도록 미세 조정합니다.
- **NEO 훈련 단계**:
    1.  **Semantic Foundation**: 의미 있는 Semantic ID 토큰을 구성하고 LLM의 어휘에 추가합니다.
    2.  **Domain-Grounding**: 새로운 Semantic ID 토큰 임베딩을 원래 언어 임베딩 공간에 정렬합니다. 이 단계에서는 LLM 백본을 고정하고 새로운 Semantic ID 임베딩만 훈련하여 사전 훈련된 LLM의 핵심 언어 능력을 잊어버리는 '재앙적 망각'을 완화합니다.
    3.  **Capability Induction**: Spotify 관련 작업(다음 아이템 추천, 사용자 이해, 텍스트 기반 검색, 그라운딩된 혼합 생성)에 대한 다중 작업 지시 튜닝을 수행합니다. 이 단계에서는 전체 모델의 가중치와 임베딩을 고정 해제하고 전체 파라미터 미세 조정 또는 LoRA 미세 조정을 실행합니다.
    4.  **Task-Specific Post-training**: RL 미세 조정과 같은 선택적 후처리 단계입니다.

모델 성능 분석 결과, 다중 작업 훈련(NEO + multi)은 단일 작업 모델과 비교하여 에피소드, 쇼, 오디오북 추천 전반에 걸쳐 일관되게 유사하거나 더 나은 성능을 보였습니다. 이는 특히 오디오북과 같은 콜드 스타트 엔티티에 대한 긍정적인 교차 학습 효과를 나타냅니다. 훈련 레시피에 대한 어블레이션 연구에서는 도메인 그라운딩 단계가 성능에 매우 중요하며, 이를 제거하면 성능이 크게 저하됨을 보여주었습니다. 또한, Beam Search가 Top-p 샘플링보다 정확도 면에서 더 효과적이며, 제약 없는 디코딩으로도 98%의 유효한 Semantic ID를 생성할 수 있음을 확인했습니다.

NEO는 그라운딩된 카탈로그 아이템, 자연어 제어, 검색+추천+설명, 산업 규모에서의 저지연 도구 없는 추론을 결합한 최초의 단일 모델입니다. 이 모델은 현재 GLIDE(팟캐스트 발견을 위한 생성적 추천기)와 같은 프로덕션 시스템에 사용되어 비습관적 팟캐스트 스트리밍을 5.4% 증가시키고 새로운 쇼 발견을 14.3% 증가시키는 등 사용자들을 기존의 습관적인 패턴에서 벗어나 새로운 콘텐츠를 탐색하도록 유도하는 데 성공했습니다.

마지막으로, 생성적이고 설명 가능한 추천의 복잡성 때문에 기존의 오프라인 평가 지표만으로는 충분하지 않다는 점이 강조되었습니다. LLM 심사위원이 중요하지만, 신뢰할 수 있고 인간의 선호도와 일치하는 평가를 위해서는 의미 있는 데이터로 LLM 심사위원을 그라운딩하는 것이 필수적입니다. Spotify는 텍스트 사용자 프로필, 행동 신호, Cranfield-Style 컬렉션과 같은 방법을 사용하여 LLM 심사위원을 그라운딩했으며, 이를 통해 인간의 판단과 75%의 에피소드 수준 일치도를 달성하고 모호한 경우에 대한 상대적 개선율이 91%에 달했습니다.

## 인상적인 대목
- "From personalization as *guessing*, to personalization as *reasoning*." (개인화가 '추측'에서 '추론'으로 바뀐다는 점)
- "From *black-box algorithms* to *transparent and steerable personalization*, where the user is fully in control." (블랙박스 알고리즘에서 사용자가 완전히 제어할 수 있는 투명하고 조종 가능한 개인화로의 전환)
- "NEO is the first single model to combine grounded catalog items, natural-language control, search + recommendation + explanation, and low-latency tool-free inference at industrial scale." (NEO가 여러 기능을 단일 모델로 통합한 최초의 사례라는 점)

## 실무 적용 포인트
- **Semantic ID 활용**: 대규모 카탈로그를 가진 서비스의 경우, 콘텐츠 임베딩을 이산 토큰(Semantic ID)으로 변환하여 LLM의 어휘에 통합하는 방식은 LLM이 카탈로그를 인식하고 제어할 수 있도록 하는 효과적인 방법입니다.
- **다단계 훈련 전략**: NEO 프레임워크와 같이 도메인 그라운딩을 통해 LLM의 핵심 언어 능력을 보존하면서 특정 도메인 지식을 주입하고, 이후 다중 작업 튜닝으로 다양한 기능을 학습시키는 다단계 훈련 전략은 LLM을 특정 서비스에 최적화하는 데 유용합니다.
- **LLM 심사위원 그라운딩**: 생성형 AI 모델의 평가 시, LLM 심사위원을 텍스트 사용자 프로필, 행동 신호, Cranfield-Style 컬렉션과 같은 의미 있는 데이터로 그라운딩하는 것은 평가의 신뢰성과 인간 선호도와의 일치도를 높이는 데 필수적입니다.
- **콜드 스타트 문제 해결**: 다중 작업 훈련이 오디오북과 같은 콜드 스타트 엔티티 추천에서 긍정적인 교차 학습 효과를 보였다는 점은, 데이터가 부족한 신규 콘텐츠나 사용자에게도 효과적인 추천을 제공할 수 있는 가능성을 시사합니다.
