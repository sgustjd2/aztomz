# How We Mapped a 35-Million-Line Mainframe in 4 Days - Stephen Chin, Neo4j & Neeraj Deshmukh, Blitzy

🔗 https://youtu.be/oWqsBuhRRZ4 · 📅 2026-11-06 · 🎙 AI Engineer

## 한 줄 요약
Blitzy는 AI와 지식 그래프를 활용하여 수천만 줄의 레거시 메인프레임 코드를 며칠 만에 현대화하고, 행동 패리티를 100% 보장하며, 기업 규모의 생산성 안전 변경을 가능하게 하는 엔터프라이즈 컴파일러입니다.

## 발표자·소속
- Stephen Chin: Neo4j 개발자 관계 부사장 (VP of Developer Relations)
- Neeraj Deshmukh: Blitzy 현장 CTO (Field CTO)

## 핵심 주장
- **레거시 시스템 현대화의 어려움**: 현대 금융 인프라는 수십 년 된 COBOL 시스템에 의존하며, 작은 코드 변경도 전체 시스템을 망가뜨릴 수 있는 위험이 있습니다. COBOL 엔지니어의 은퇴율이 높고, 생성형 AI 프로젝트의 40% 이상이 취소될 것으로 예상되는 상황에서, 기존 방식의 현대화는 비효율적이고 실패율이 높습니다.
- **AI의 한계와 관계의 중요성**: AI는 코드 생성 능력보다는 전체 시스템의 맥락(context)을 이해하는 데 어려움을 겪습니다. 벡터 데이터베이스는 유사성만 찾고, 관계형 데이터베이스는 깊은 탐색에서 성능 문제가 발생합니다. AI 모델의 유효 컨텍스트 길이가 광고된 것보다 훨씬 짧아, 정확한 결과를 위해서는 정밀하고 정확한 맥락 제공이 필수적입니다.
- **코드를 지식 그래프로 변환**: Blitzy는 코드를 그래프로 변환하여 모든 코드 요소(프로그램, 작업, 데이터 등)와 그 관계를 매핑합니다. 각 관계는 출처(저장소, 버전), 증거(소스 위치, 추출 방법), 최신성(병합 시 재추출) 정보를 유지하여, 코드 변경 시 그래프가 실시간으로 업데이트됩니다.
- **에이전트를 위한 컨텍스트 패킷**: 각 AI 에이전트는 작업 설명, 소스 슬라이스, 제약 조건, 증거, 미해결 질문을 포함하는 '컨텍스트 패킷'을 받습니다. 이는 무한한 컨텍스트 창이 아닌, 필요에 따라 전체 시스템에 대한 관리된 접근을 제공하여 에이전트가 정확한 정보를 적시에 활용하도록 돕습니다.
- **인간 중심의 생산 안전 변경 프로세스**: Blitzy는 역공학, 요구사항/규칙 추출, 에이전트 실행 계획 수립, 인간 승인, 코드 생성 및 검증 에이전트 실행, 풀 리퀘스트 및 프로젝트 가이드 생성의 워크플로를 따릅니다. 특히 '인간 승인' 단계는 모든 주요 결정이 AI가 아닌 사람에 의해 이루어지도록 보장하여, 규제 산업에서 필수적인 안전성을 확보합니다.
- **행동 패리티 검증**: Blitzy는 COBOL 기준선과 현대화된 Java 코드 간의 100% 행동 패리티를 보장합니다. 반환 값, 영구 상태, 트랜잭션 출력, 오류 결과 등 모든 측면에서 바이트 단위로 동일한지 지속적으로 검증하여, 현대화된 시스템이 기존 시스템과 동일하게 작동함을 증명합니다.

## 세부 내용

발표는 현대 금융 시스템의 기반이 되는 소프트웨어의 복잡성과 오래된 특성에서 시작됩니다. 발표자는 모바일 앱이나 웹 API와 같은 현대적인 경험 뒤에는 수십 년 된 COBOL 코드, 비즈니스 규칙, 배치 작업, 데이터 계약 등이 존재하며, 이들은 현대화가 시급하지만 변경하기 매우 어렵다고 설명합니다. COBOL 코드 라인이 2200억 개에 달하고, COBOL 엔지니어의 10%가 매년 은퇴하며, 생성형 AI 프로젝트의 40% 이상이 2027년까지 취소될 것으로 예상되는 상황은 이러한 현대화의 어려움을 더욱 부각시킵니다.

발표자는 과거 Java 개발자로서 메인프레임 COBOL 코드를 현대화했던 경험을 공유하며, 당시의 프로젝트들이 매우 도전적이었고 종종 실패했다고 말합니다. 이는 AI가 코드를 작성하는 능력의 문제가 아니라, AI가 해당 로직이 사용되는 다른 14개 이상의 장소에 대한 맥락을 알지 못하기 때문에 발생하는 문제라고 지적합니다. 벡터 데이터베이스는 유사성만 찾고, 관계형 데이터베이스는 깊은 탐색 시 성능 문제가 발생하여 충분한 맥락을 제공하지 못합니다. 실제 AI 모델의 유효 컨텍스트 길이는 광고된 것보다 훨씬 짧아, 정확한 결과를 위해서는 정밀하고 정확한 맥락이 필요합니다.

Blitzy는 이 문제를 해결하기 위해 코드를 지식 그래프로 변환하는 접근 방식을 사용합니다. 이 그래프는 프로그램, 작업, 카피북, 데이터 저장소, 필드, 트랜잭션 출력 등 모든 코드 요소를 노드로, 이들 간의 관계를 엣지로 표현합니다. 각 엣지는 해당 정보의 출처(저장소, 버전, 심볼), 증거(파일, 소스 스팬, 추출 방법), 최신성(병합 시 재추출)을 기록하여, 코드 변경 시 그래프가 자동으로 업데이트됩니다.

AI 에이전트는 이러한 지식 그래프를 활용하여 '컨텍스트 패킷'을 받습니다. 이 패킷은 작업 설명, 소스 슬라이스, 제약 조건, 증거, 미해결 질문을 포함하며, 에이전트가 필요한 정보에만 관리된 방식으로 접근하도록 합니다. 이는 무한히 큰 컨텍스트 창이 아니라, 필요한 정보를 적시에 제공하는 방식입니다.

Blitzy의 작업 방식은 엔터프라이즈 컴파일러와 유사합니다.
1. **역공학**: 전체 소프트웨어 자산을 역공학하여 비즈니스 로직, 종속성, 데이터 아키텍처, 운영 워크플로를 추출합니다.
2. **요구사항 및 규칙**: 사용자로부터 변경에 대한 요구사항과 규칙을 입력받습니다.
3. **에이전트 실행 계획**: 이를 실행 가능한 에이전트 실행 계획으로 변환합니다.
4. **인간 승인**: 이 계획은 반드시 인간의 승인을 거쳐야 합니다. AI는 결정을 내리지 않고, 인간이 모든 주요 지점에서 승인합니다.
5. **코드 생성 및 검증**: 승인된 계획에 따라 에이전트가 코드를 생성하고, 동시에 지속적인 검증을 수행합니다.
6. **풀 리퀘스트 및 프로젝트 가이드**: 최종적으로 테스트되고 검증된 코드가 풀 리퀘스트 형태로 제공되며, 변경 사항에 대한 증거 문서가 포함된 프로젝트 가이드가 생성됩니다.

이 과정에서 지식 그래프는 '진실의 원천' 역할을 하며, 하이퍼스케일 오케스트레이션은 수천 개의 에이전트가 효과적인 컨텍스트 내에서 작업하도록 합니다. '극단적인 검증'은 코드 생성보다 더 많은 컴퓨팅 자원을 테스트에 할애하여, 패리티, 테스트, 보안 체크포인트 등 모든 측면에서 변경 전후의 행동이 동일함을 증명합니다.

발표자는 실제 사례를 통해 Blitzy의 효과를 입증합니다.
- **티어 1 은행의 투자 회계 시스템 현대화**: 모놀리스, 저장 프로시저, 교차 데이터베이스 쓰기를 포함하는 시스템을 PostgreSQL, Java, TypeScript, Python 기반의 6개 모듈로 현대화했습니다. 18주가 걸릴 것으로 예상되었던 프로젝트를 18일 만에 완료했으며, 4,022개의 테스트를 통해 100% 행동 패리티를 달성했습니다.
- **포춘 100대 보험사의 3,500만 라인 메인프레임 매핑**: Blitzy는 3,500만 라인의 메인프레임 코드를 4일 만에 지식 그래프로 매핑했습니다. 이는 일반적인 시스템 통합(SI) 업체가 8~12개월 걸리는 작업입니다. 고객은 "연필 불빛으로 어두운 방에서 각 모듈을 검사하는 것 같았는데, Blitzy는 마치 천장 조명을 켜서 방 전체를 한 번에 보는 것 같다"고 평가했습니다.
- **글로벌 보험사의 2,500만 라인 모놀리스 현대화**: 평균 프로젝트 가속도 9배, 자율 완료율 약 85%, 프로덕션 파이프라인에 수용된 코드의 약 90%를 달성했습니다.

이러한 성공은 현대화가 단지 시작점일 뿐, 궁극적인 목표는 비즈니스 혁신임을 보여줍니다. 지식 그래프는 규제 준수, 비즈니스 규칙 카탈로그, 프로세스 수준 영향 분석, 에이전트 간 공유 컨텍스트 등 다양한 활용 사례를 가능하게 합니다.

## 실무 적용 포인트
- **지식 그래프 구축**: 레거시 시스템의 비즈니스 로직, 종속성, 데이터 아키텍처, 운영 워크플로를 추출하여 지식 그래프 형태로 관리하면, 시스템 전체에 대한 가시성을 확보하고 변경의 영향을 예측할 수 있습니다.
- **지속적인 행동 패리티 검증**: 현대화 과정에서 COBOL 기준선과 현대화된 코드 간의 바이트 단위 패리티 테스트를 자동화하여, 변경으로 인한 잠재적 오류를 조기에 발견하고 비즈니스 연속성을 보장해야 합니다.
- **인간 중심의 AI 활용**: AI 에이전트가 생성하는 모든 주요 변경 계획에 대해 인간의 검토 및 승인 단계를 포함하여, AI의 자율성을 통제하고 규제 및 거버넌스 요구사항을 충족시키도록 설계해야 합니다.
- **다계층 테스트 및 검증**: 소스 코드 분석, 컴파일러 검증, 런타임 통합 테스트, 데이터베이스 패리티 검증, API를 통한 엔드투엔드 행동 패리티 등 다계층의 테스트 전략을 구현하여 코드 품질과 정확성을 확보해야 합니다.
