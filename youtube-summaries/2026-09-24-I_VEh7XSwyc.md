# Physical AI's Next Bottleneck Is Finding the Right Video — Rafael Levi, Bright Data

## 핵심 주장
- **AI 훈련의 새로운 병목 현상은 데이터 공급입니다.** AI 모델 자체를 구축하는 방법은 많이 발전했지만, AI가 보고, 이해하고, 행동할 수 있도록 적절한 데이터를 공급하는 것이 현재 가장 어려운 과제입니다.
- **로봇 훈련 데이터는 텍스트나 이미지 데이터에 비해 매우 희소합니다.** LLM 훈련에는 수조 개의 텍스트 단어가, 이미지 생성에는 수십억 개의 라벨링된 이미지가 사용되지만, 로봇 시연 데이터는 약 100만 개에 불과하며, 이는 수작업으로 기록되어 확장성이 떨어집니다.
- **"지시된" 동작이 아닌 "직관적인" 동작 데이터가 로봇 훈련에 필수적입니다.** 카메라 앞에서 의도적으로 수행된 지시된 동작은 자연스러운 움직임과 다르기 때문에 로봇이 실제 세계에서 효과적으로 작동하는 데 필요한 직관적인 움직임을 학습하기 어렵습니다.
- **웹 비디오는 로봇 훈련을 위한 방대한 실세계 데이터 소스입니다.** YouTube와 같은 플랫폼에는 중력, 움직임, 인과 관계, 사물 조작 방식 등 세계가 어떻게 작동하는지에 대한 수십억 시간의 비디오가 존재하며, 이는 로봇의 기초 훈련에 매우 유용합니다.
- **기존의 비디오 데이터 수집 방식은 비효율적입니다.** Stable Video Diffusion 프로젝트는 수집된 비디오의 74%를, NVIDIA의 Cosmos 로봇 데이터 파이프라인은 96%를 버리는데, 이는 다운로드, 저장, 처리, 검토에 드는 막대한 비용과 시간을 낭비하는 것입니다.
- **Bright Data의 Visual Index는 필요한 비디오 클립만 검색하고 추출하여 훈련 데이터 수집을 최적화합니다.** 사용자가 원하는 장면을 자연어로 정의하면, 플랫폼은 10억 개 이상의 웹 비디오에서 의미 기반으로 검색하여 훈련에 바로 사용할 수 있는, 다듬고 라벨링된 클립을 제공합니다.

## 세부 내용
발표자는 AI 개발의 다음 단계는 AI 자체를 만드는 것이 아니라, AI에 적절한 데이터를 공급하는 것이라고 강조하며 강연을 시작합니다. 특히 로봇 공학 분야에서는 텍스트나 이미지 데이터와 달리 로봇 훈련을 위한 실세계 데이터가 매우 부족하다고 지적합니다. LLM은 수조 개의 텍스트 단어로, 이미지 생성 AI는 수십억 개의 라벨링된 이미지로 훈련되지만, 로봇 시연 데이터는 약 100만 개에 불과하며, 이마저도 수작업으로 기록되어 확장성이 낮고 비용이 많이 듭니다.

또한, 발표자는 카메라 앞에서 "지시된" 방식으로 기록된 동작은 사람들이 자연스럽게 행동하는 "직관적인" 동작과 다르기 때문에 로봇 훈련에 편향된 데이터를 제공할 수 있다고 설명합니다. 예를 들어, 문을 여는 동작을 카메라 앞에서 보여주는 것과 일상생활에서 무심코 문을 여는 것은 움직임의 속도와 방식에서 차이가 발생합니다. 이러한 지시된 데이터는 로봇이 실제 세계의 복잡성을 이해하고 적응하는 데 방해가 됩니다.

기존 데이터 소스의 한계점도 언급됩니다. 시뮬레이션은 저렴하지만, 가상 세계에서 학습된 기술은 실제 세계에서 제대로 작동하지 않는 경우가 많습니다. 수동 제어 방식은 사람이 로봇을 직접 조작하여 데이터를 기록하는 것으로, 느리고 피로하며 확장성이 없습니다. 기성 데이터 세트는 깨끗하지만, 실제 생활의 극히 일부만을 다룹니다.

발표자는 이러한 문제에 대한 해결책으로 웹 비디오를 제시합니다. YouTube와 같은 플랫폼에는 중력, 움직임, 인과 관계, 사물 조작 방식 등 세계가 어떻게 작동하는지에 대한 수십억 시간의 비디오가 존재하며, 이는 로봇의 기초 훈련에 매우 유용합니다. Meta의 한 AI 모델은 100만 시간 이상의 웹 비디오를 통해 세계 작동 방식을 학습한 후, 단 62시간의 로봇 영상만으로 실제 로봇을 제어할 수 있었다는 사례를 언급합니다.

"온라인 비디오는 로봇이 어떻게 움직이는지 보여주지 않는다"는 반론에 대해, 발표자는 AI가 두 프레임을 비교하여 어떤 움직임이 있었는지 추측하고, 누락된 제어 정보를 채워 넣을 수 있다고 설명합니다. 즉, 비디오 자체가 로봇의 제어 신호를 직접 제공하지 않더라도, AI는 비디오에서 움직임의 패턴과 물리학적 원리를 학습할 수 있다는 것입니다.

현재 데이터 수집 방식의 비효율성도 지적됩니다. Stable Video Diffusion 프로젝트는 수집된 비디오의 74%를, NVIDIA의 Cosmos 로봇 데이터 파이프라인은 96%를 버리는데, 이는 불필요한 다운로드, 저장, 처리, 검토에 막대한 자원을 낭비하는 결과를 초래합니다.

Bright Data는 이러한 문제를 해결하기 위해 "먼저 검색하고, 나중에 수집하는(Search first, collect second)" 접근 방식을 제안합니다. Visual Index 플랫폼을 통해 사용자는 "싱크대에서 손으로 설거지하는 사람, 스펀지와 비누로 접시의 기름때를 제거하고 헹군 후 건조대에 접시를 놓는 모습, 손의 상호작용 클로즈업"과 같이 원하는 장면을 자연어로 상세하게 묘사할 수 있습니다. 플랫폼은 이 설명을 바탕으로 10억 개 이상의 웹 비디오를 의미 기반으로 검색하여, 해당 장면에 정확히 일치하는 비디오 클립만을 추출합니다.

데모에서는 "설거지하는 사람"과 "옷을 접는 사람"이라는 쿼리를 입력했을 때, Visual Index가 관련 비디오 클립들을 빠르게 찾아 보여주는 과정을 시연합니다. 이 클립들은 이미 훈련에 적합하도록 다듬어지고 라벨링되어 제공됩니다. 모든 기능은 API를 통해 제공되므로 수동 작업 없이 자동화가 가능합니다. 검색 결과는 매칭 정확도에 따라 순위가 매겨지고, 정확한 순간으로 타임스탬프가 찍히며, 원본 비디오 링크와 함께 스트리밍 방식으로 제공됩니다.

이러한 방식은 데이터 수집, 처리, 저장, 검토에 드는 낭비를 줄이고, 로봇, 자율주행, 세계 모델 훈련을 위한 맞춤형 훈련 세트를 모든 국가와 언어에서 구축할 수 있게 합니다. 또한, 전체 공개 비디오 웹을 하나의 소스로 활용하여 광범위한 실세계 비디오 데이터를 제공합니다. 발표자는 이 기술이 브랜드가 자사 제품이 사용되는 비디오를 찾거나, 게이머가 특정 게임 레벨을 깨는 방법을 학습하는 등 다양한 분야에 적용될 수 있다고 강조하며 강연을 마무리합니다.

## 실무 적용 포인트
- **의미 기반 비디오 검색 활용:** 키워드 검색의 한계를 넘어 자연어 설명을 통해 원하는 특정 동작이나 장면이 담긴 비디오 클립을 정확하게 찾아 로봇 훈련 데이터로 활용할 수 있습니다.
- **데이터 수집 효율성 증대:** 불필요한 비디오를 대량으로 다운로드하고 필터링하는 대신, 필요한 클립만 선별적으로 추출하여 스토리지, 컴퓨팅 자원, 시간 낭비를 최소화할 수 있습니다.
- **로봇 및 자율주행 모델의 실세계 적응력 향상:** 웹상의 방대한 "직관적인" 실세계 비디오 데이터를 활용하여 로봇이 중력, 움직임, 인과 관계 등 실제 세계의 물리적 법칙과 인간의 자연스러운 행동을 보다 효과적으로 학습하도록 할 수 있습니다.
- **API를 통한 데이터 파이프라인 자동화:** Visual Index와 같은 플랫폼의 API를 활용하여 비디오 검색 및 클립 추출 과정을 기존 훈련 파이프라인에 통합하고 자동화하여 데이터 준비 시간을 단축할 수 있습니다.
