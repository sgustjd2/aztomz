- **늦은 문제 발견의 비용**: AI 에이전트가 도입한 코드 품질 및 보안 문제가 풀 리퀘스트(PR) 단계에서 발견되면, 이는 재작업, 추가 토큰 소비, 시간 낭비, 그리고 개발자들의 좌절로 이어져 개발 주기를 늦춥니다.
- **SonarVortex의 솔루션**: SonarVortex는 AI 코딩 에이전트에게 프로젝트 관련 컨텍스트를 미리 제공하여 효율성을 높이고, 코드를 작성하는 동안 결정론적 분석을 통해 실시간으로 변경 사항을 검증하여 새로운 문제가 도입되는 것을 방지합니다.
- **신뢰할 수 있는 코드 품질**: SonarVortex는 SonarQube의 강력한 코드 인텔리전스를 기반으로 하여, AI 에이전트가 생성한 코드가 보안, 유지보수성, 데이터 흐름 측면에서 높은 표준을 준수하도록 보장하며, 이는 생산성 향상과 장애 감소로 이어집니다.

## 세부 내용
발표자는 Sonar를 독립적인 코드 검증 플랫폼으로 소개하며, AI 에이전트가 코드를 작성하는 방식의 문제점을 지적합니다. AI 에이전트는 마치 신입 사원처럼 프로젝트의 기존 컨텍스트(코딩 규칙, 아키텍처, 라이브러리 등)를 알지 못해, 새로운 기능을 구현할 때마다 코드베이스를 탐색하며 많은 시간과 토큰을 소비합니다. 이러한 탐색 과정은 비효율적이며, 기존 코드의 문제 패턴을 복제하거나 새로운 보안 및 품질 문제를 도입할 위험이 있습니다. 이러한 문제들이 풀 리퀘스트(PR) 단계에서 발견되면, 재작업이 필요해 개발 주기가 지연되고 비용이 증가하며 개발자들의 불만을 초래합니다.

SonarVortex는 이러한 문제를 해결하기 위한 플러그인으로, AI 에이전트의 코딩 루프 내에서 가이드 및 검증 기능을 제공합니다.
1.  **가이드 (Guide)**: 코딩 에이전트가 첫 줄을 작성하기 전에 프로젝트의 올바른 컨텍스트를 제공합니다. 여기에는 승인된 라이브러리, 코딩 표준, 팀 컨벤션, 보안 표준, 아키텍처 규칙, 저장소 컨텍스트, 의미론적 내비게이션 등이 포함됩니다. 이를 통해 에이전트는 불필요한 탐색 없이 관련 파일로 바로 이동하여 토큰 소비를 줄이고 효율적으로 작업할 수 있습니다.
2.  **검증 (Verify)**: AI 에이전트가 코드를 작성하는 동안 모든 변경 사항을 실시간으로 검증합니다. SonarVortex는 에이전트의 도구 사용 시마다 빠른 검사를 트리거하고, 턴이 끝날 때마다 더 깊은 보안 및 교차 파일 데이터 흐름 분석을 수행합니다. 이는 AI가 AI를 검증하는 것이 아니라, SonarQube의 결정론적 코드 인텔리전스를 활용하여 신뢰할 수 있는 결과를 제공합니다.
3.  **해결 (Solve)**: 발견된 문제는 PR 단계 이전에 코딩 루프 내에서 수정됩니다. 에이전트는 SonarVortex의 피드백을 받아 코드를 수정하고, 수정된 코드는 다시 검증됩니다. 이 연속적인 루프를 통해 코드는 PR에 도달하기 전에 이미 검증된 상태가 됩니다.

발표자는 SonarVortex 적용 결과, 리팩토링에 사용되는 토큰이 36% 감소하고, 프로덕션 장애가 44% 감소했으며, 오탐율(false-positive rate)이 3.2%에 불과하다고 강조합니다. 이는 더 나은 코드, 더 적은 토큰 사용, 그리고 더 적은 재작업으로 이어집니다.

데모에서는 VS Code 환경에서 Claude Code 에이전트가 Java 로그 파일 압축 해제 기능을 구현하는 과정을 보여줍니다. 에이전트는 SonarQube 플러그인이 활성화된 상태에서 작업을 시작하며, SonarVortex는 자동으로 프로젝트 컨텍스트와 Java 코딩 가이드라인을 에이전트에게 제공합니다. 에이전트가 코드를 작성하고 테스트 스위트를 추가한 후, SonarVortex는 코드를 분석하여 임시 파일 생성 시 소유자만 읽을 수 있는 권한을 명시적으로 설정하지 않아 발생하는 보안 취약점을 발견합니다. 에이전트는 이 피드백을 받아 코드를 수정하고, SonarVortex는 수정된 코드를 다시 검증하여 문제가 해결되었음을 확인합니다. 발표자는 SonarVortex가 AI 에이전트의 성능을 향상시키고, 개발자들이 자동화된 에이전트 워크플로우를 신뢰할 수 있도록 돕는다고 결론짓습니다.
