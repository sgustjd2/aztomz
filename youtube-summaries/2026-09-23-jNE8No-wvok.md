## 핵심 주장
-   **짧은 형식 비디오 데이터의 복잡성:** 짧은 형식 비디오(SFV) 데이터는 방대한 규모, 높은 역동성, 다국어 화면 텍스트, 적대적 콘텐츠, 그리고 명확한 정답(ground truth)의 부재 등 여러 가지 도전 과제를 안고 있습니다.
-   **모달리티 불일치 및 원본성 귀속 문제 해결:** 발표는 오디오, 비주얼, 화면 텍스트가 서로 다른 이야기를 하는 '모달리티 불일치'와 원본 콘텐츠의 복사 및 변형된 재업로드를 식별하는 '원본성 귀속'이라는 두 가지 핵심 문제를 다룹니다.
-   **다중 에이전트 시스템 아키텍처:** 이 문제들을 해결하기 위해 Perceive(인지), Retrieve(검색), Review(검토)의 세 가지 전문 에이전트로 구성된 다중 에이전트 시스템 아키텍처를 제안합니다. 각 에이전트는 특정 작업을 수행하며, Reviewer 에이전트가 전체 워크플로우를 조율합니다.
-   **특화된 SLM과 최적화 기법:** 각 에이전트는 사전 학습, 지시어 미세 조정(Instruction SFT), 그리고 프로덕션에서 수집된 어려운 사례를 통한 직접 선호도 최적화(DPO)의 3단계로 구축된 특화된 소규모 시각-언어 모델(SLM)에 의해 구동됩니다. 또한, 시공간 토큰 감소(STORM), 의미론적 캐싱, 메타데이터 가지치기 등의 최적화 기법을 통해 효율성과 비용 효율성을 높입니다.
-   **다차원적 평가의 중요성:** 시스템 평가는 단순한 정확도 지표를 넘어, 작업 성공, 검색 성능, 추론 품질, 시스템 견고성, 효율성, 그리고 LLM-as-judge(LLM을 심사관으로 활용)의 인간 판단과의 상관관계 등 6가지 차원에서 이루어져야 함을 강조합니다.

## 세부 내용

발표는 짧은 형식 비디오(SFV)의 특성부터 시작하여, 데이터가 "지구적 규모(100M+), 활발하고 재사용이 많으며, 적대적이고, 화면 텍스트가 다국어이며, 역동적이고, 약한 정답(ground truth)을 가진다"고 설명합니다.

두 가지 주요 문제 정의가 제시됩니다:
1.  **모달리티 불일치 (Modality Misalignment):** 오디오, 비주얼, 화면 텍스트가 다른 이야기를 전달하는 경우입니다.
    *   **Inter-modality (쉬움):** 한 모달리티가 다른 모달리티와 모순되는 경우 (예: 정치적 비주얼 + 자연 캡션). 이는 교차 모달 임베딩 거리를 통해 해결할 수 있습니다.
    *   **Intra-modality (어려움):** 하나의 스트림 내에서 조작이 숨겨진 경우 (예: 비디오 중간에 삽입된 광고 또는 정치적 선전). 이는 세분화된 시간적 이해를 필요로 합니다.
2.  **원본성 귀속 (Originality Attribution):** 원본 클립, 즉 다른 사람의 작업의 정확한 복사본 및 변형된 재업로드를 찾는 핵심 문제입니다.
    *   원본 비디오가 복사되고, 변형(미러링, 속도 조절, 자르기/확대, 필터, 재인코딩, 부분 스플라인 등)된 후, "원본"으로 재게시되는 과정을 보여줍니다.
    *   이로 인해 귀속 상실, 생태계 불균형, 반복적인 비원본 콘텐츠, 사용자 및 크리에이터 피로 등의 문제가 발생합니다.

이러한 문제 해결을 위해 **다중 에이전트 시스템 아키텍처**가 제안됩니다. 이 시스템은 Perceive(인지), Retrieve(검색), Review(검토)의 세 가지 에이전트로 구성됩니다.
*   **Reviewer Agent (심사관 에이전트):** 중앙 오케스트레이터 역할을 하며, 비디오 ID를 받아 Perceive 에이전트에 요청을 보냅니다.
*   **Perceive Agent (인지 에이전트):** 비디오를 시간적으로 분해하고, 전체 비디오 임베딩 및 서브 클립 임베딩, 태그, NLP 설명, 객체 등을 추출합니다. 이는 비디오 추출, 전처리, 미세 조정된 VLM(Vision-Language Model)을 통해 이루어집니다. 추출된 정보는 벡터, 그래프 DB, 역색인 등의 저장소에 저장됩니다.
*   **Retriever Agent (검색 에이전트):** Perceive 에이전트의 결과를 바탕으로 유사한 클립, 작성자, 타임스탬프 등의 데이터를 검색합니다. 오프라인에서는 전체 비디오 및 클립 신호를 처리하여 벡터 DB, 역색인, 키-비디오, 지식 그래프를 구축합니다. 온라인에서는 쿼리와 파라미터를 받아 저장소를 검색하고, 경량 미세 조정 LLM(Lightweight FT LLM)을 사용하여 전통적인 ML 점수와 함께 상위 K개 후보를 선정합니다.
*   **Reviewer Agent (심사관 에이전트):** Perceive 에이전트의 시간적 신호와 Retriever 에이전트의 유사 클립, 분류기 점수, 사용자 피드백, 크리에이터 메타데이터 등을 종합하여 추론(Reasoning)을 수행하고, 모달리티 불일치 결정, 원본성/중복 제거 판정, 신뢰도 및 추론 과정을 출력합니다. 필요한 경우 React 루프를 통해 Retriever 및 도구를 다시 호출하여 추가 증거를 찾습니다.

**특화된 SLM(Specialized SLM)**은 각 에이전트를 구동하는 핵심 모델로, 세 단계로 구축됩니다.
1.  **사전 학습 (Pre-training):** 웹 스케일 데이터(광범위하고 정제된 데이터)와 사내 SFV 데이터(인간이 큐레이션하고 노이즈가 많으며 실제 사용 사례)를 모두 사용하여 비전 어댑터를 사전 학습합니다. 목표는 인코더가 실제 SFV에 놀라지 않도록 기본 데이터를 이해하는 것입니다.
2.  **지시어 미세 조정 (Instruction SFT):** 비디오 클립을 비전 인코더, 프로젝터, 언어 모델을 통해 미세 조정합니다. 이는 특정 지침, 정책, 도구 사용법, 접지(grounding) 및 구조화된 출력(JSON 스키마)을 모델에 학습시킵니다. 학습은 고정된 레이블 SFV 코퍼스(인간 + ML)를 사용하여 오프라인으로 이루어지며, 추론 시에는 라이브 신호가 추가됩니다. 각 예시는 단순한 프롬프트가 아닌, 역할, 정책, 도구, 접지, 추가 메타데이터, 출력 스키마를 포함하는 "엔지니어링된 컨텍스트"로 구성됩니다.
3.  **사후 학습 (Post-training) - DPO:** 프로덕션에서 수집된 어려운 사례(모델이 잘못 판단한 경우)를 대상으로 DPO(Direct Preference Optimization)를 수행합니다. 이는 모델이 올바른 판단과 거의 올바른 판단 사이의 미묘한 차이를 학습하게 하여 지속적인 모델 개선을 가능하게 합니다.

**최적화 (Optimization)** 기법은 확장성과 ROI(투자 수익률)를 가능하게 합니다.
*   **STORM (Spatiotemporal Token Reduction):** Perceive 에이전트에서 연속적인 프레임의 높은 중복성을 줄여, 풍부한 토큰만 LLM에 도달하도록 합니다. 이는 LLM에 도달하는 토큰 수를 최대 80%까지 줄여 지연 시간, 비용, GPU 메모리를 절약합니다.
*   **의미론적 캐싱 (Semantic caching):** Retriever 에이전트에서 바이럴 재업로드의 즉각적인 중복 제거를 위해 유사도 점수가 높은 경우 Reviewer 에이전트의 추론 단계를 건너뛰어 예산을 절약합니다.
*   **메타데이터 가지치기 (Metadata pruning):** 업스트림에서 수백만 개의 후보에서 검색 공간을 수백 개로 줄여 가장 저렴한 모델 호출을 가능하게 합니다. 이는 주제, 객체, 크리에이터 인덱스를 활용하고, 신뢰할 수 있는 크리에이터를 주기적으로 오프라인으로 식별하여 검색 공간을 효과적으로 줄입니다.

**평가 (Evaluation)**는 단일 점수가 아닌 6가지 차원에서 이루어집니다.
1.  **작업 성공:** 정밀도, 재현율, F1 점수
2.  **검색:** 소스별 재현율 및 지연 시간
3.  **추론:** CoT(Chain-of-Thought) 및 계획 품질(TAC)
4.  **견고성:** 오류율 및 원인
5.  **시스템 효율성:** 토큰 사용량, 도구 사용량, 지연 시간
6.  **LLM-as-judge:** 인간 라벨링과의 상관관계

발표자는 "단일 숫자로 충분하지 않다"며, "작업 성공, 검색, 추론, 견고성, 비용 및 인간 합의가 모두 일류이다"라고 강조합니다.

## 인상적인 대목

-   "Decomposition is key — but only when necessary" (분해는 핵심이다 — 하지만 필요할 때만)
-   "Good evaluation is paramount — everything depends on it" (좋은 평가는 가장 중요하다 — 모든 것이 그것에 달려있다)

## 실무 적용 포인트
-   **다중 에이전트 시스템 설계:** 복잡한 AI 문제를 해결할 때, 단일 대규모 모델에 의존하기보다 문제를 Perceive, Retrieve, Review와 같은 전문 에이전트로 분해하여 시스템을 설계하는 것을 고려할 수 있습니다. 각 에이전트가 특정 기능에 집중함으로써 효율성과 관리 용이성을 높일 수 있습니다.
-   **도메인 특화 SLM 구축:** 일반적인 대규모 모델을 그대로 사용하기보다, 특정 도메인(예: 짧은 형식 비디오)의 데이터 특성에 맞춰 사전 학습, 지시어 미세 조정, DPO를 통해 소규모 시각-언어 모델(SLM)을 특화시키는 것이 성능과 비용 효율성 면에서 유리할 수 있습니다.
-   **지속적인 모델 개선을 위한 DPO 활용:** 프로덕션 환경에서 발생하는 모델의 어려운 사례(hard cases)를 지속적으로 수집하고, 이를 인간 검토 큐를 통해 선호도 쌍으로 변환하여 DPO를 통해 모델을 재학습시키는 "인간-피드백 루프"를 구축하여 모델 성능을 꾸준히 향상시킬 수 있습니다.
-   **최적화 기법 적용:** 대규모 비디오 데이터 처리 시, 시공간 토큰 감소(STORM)를 통해 LLM 입력 토큰 수를 줄이거나, 의미론적 캐싱을 통해 반복적인 콘텐츠의 처리 비용을 절감하고, 메타데이터 가지치기를 통해 검색 공간을 축소하는 등 다양한 최적화 기법을 적용하여 시스템의 효율성과 비용 효율성을 극대화할 수 있습니다.
