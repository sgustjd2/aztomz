# I Turned Coding Agents Into a Strategy Game — Ido Salomon, AgentCraft

🔗 https://youtu.be/YIVkERhy8xo · 📅 2026-09-27 · 🎙 AI Engineer

## 한 줄 요약

## 핵심 주장
- **인간은 에이전트 활용의 병목 현상입니다:** 에이전트가 아무리 뛰어나도, 수많은 에이전트를 동시에 관리하고 지시하며 검토하는 것은 인간에게 엄청난 피로감을 주어 생산성을 저해합니다.
- **게임에서 영감을 받은 인터페이스가 해결책이 될 수 있습니다:** 워크래프트나 심즈와 같은 전략 게임에서 여러 유닛을 관리하는 방식은 에이전트를 감독하고 조율하는 데 필요한 기술과 유사하며, 이를 활용하여 에이전트 오케스트레이션의 복잡성을 줄일 수 있습니다.
- **에이전트크래프트는 가시성, 자율성, 협업을 제공합니다:** 이 플랫폼은 에이전트의 활동을 시각적으로 보여주고(가시성), 에이전트가 스스로 작업을 계획하고 실행하게 하며(자율성), 여러 사용자와 에이전트가 함께 작업할 수 있는 환경을 제공하여(협업) 인간의 부담을 덜어줍니다.
- **에이전트 활용의 상한선을 높이고 하한선을 낮춥니다:** 에이전트크래프트는 숙련된 사용자가 더 복잡한 작업을 수행할 수 있도록 지원하는 동시에, 비기술적인 사용자도 에이전트를 쉽게 활용할 수 있도록 직관적인 인터페이스와 프로젝트 기반 접근 방식을 제공합니다.

## 세부 내용
발표자는 에이전트가 밈 생성부터 B2B SaaS 앱 개발까지 다양한 작업을 수행할 수 있는 "마법"과 같다고 말하며 강연을 시작합니다. 그러나 현실에서는 에이전트를 대규모로 활용하기 어렵다는 점을 지적합니다. 25개의 클로드 코드 에이전트를 동시에 실행하는 트윗 이미지를 보여주며, 각 에이전트를 일일이 지시하고 검토하는 것이 "지치고 소모적"이라고 설명합니다. 결국 에이전트 활용의 병목 현상은 인간 자신이라고 주장합니다.

발표자는 이러한 문제를 해결하기 위해 게임에서 영감을 받은 오케스트레이터인 '에이전트크래프트(AgentCraft)'를 소개합니다. 에이전트크래프트는 워크래프트와 같은 실시간 전략 게임(RTS)의 인터페이스를 차용하여 에이전트 관리를 더 직관적이고 즐겁게 만듭니다.

**데모 시연:**
1.  **에이전트 스폰 및 프롬프트:** 발표자는 게임 맵에 클로드 코드(Claude Code) 에이전트를 스폰하고, 사이드 패널의 채팅창을 통해 "add capilot cli support"와 같은 명령을 내립니다. 에이전트는 "At your command"라고 응답하며 작업을 시작합니다.
2.  **가시성 (Visibility):**
    *   왼쪽 사이드 패널에는 현재 활성화된 에이전트 목록과 각 에이전트의 미션, 상태, 컨텍스트 사용량, 마지막 활동 시간 등이 표시됩니다.
    *   맵에는 파일 시스템이 투영되어 디렉토리와 파일이 룬(rune) 형태로 표시됩니다. 에이전트가 작업 중인 파일이나 디렉토리에는 해당 에이전트의 아이콘이 표시되어 시각적으로 어떤 에이전트가 어디서 무엇을 하는지 쉽게 파악할 수 있습니다.
    *   히트맵 기능을 통해 에이전트 활동이 집중된 영역을 시각적으로 확인할 수 있습니다.
    *   스페이스바를 누르면 다음으로 주의가 필요한 에이전트나 작업으로 화면이 이동하여 빠르게 대응할 수 있습니다.
3.  **자율성 (Autonomy):**
    *   에이전트가 코드베이스를 분석하여 개선할 수 있는 작업(예: 환경 및 API 페이로드 유효성 검사, 웹소켓 이벤트 속도 제한)을 퀘스트 형태로 제시합니다.
    *   사용자는 "Accept Quest" 버튼을 클릭하여 에이전트에게 작업을 위임할 수 있습니다. 에이전트는 로컬 컨테이너에서 작업을 자율적으로 수행하며, 사용자는 더 이상 "베이비시팅"할 필요가 없습니다.
    *   "Software Factories"라는 개념을 통해 에이전트가 일반적인 목표를 바탕으로 스스로 계획을 세우고 실행하며, 완료된 작업은 검토를 위해 제출됩니다.
4.  **협업 (Collaboration):**
    *   "Hall" 또는 "War Room"이라는 기능을 통해 여러 사용자가 동일한 에이전트 환경에 참여할 수 있습니다. 발표자는 자신의 아내(프로덕트 디자이너)를 초대하여 함께 작업하는 시나리오를 보여줍니다.
    *   사용자들은 공유된 작업 공간에서 에이전트의 활동을 함께 보고, 채팅을 통해 서로 소통하며, 에이전트와도 대화할 수 있습니다.
    *   다른 사용자가 진행 중인 작업을 "핸드오프(handoff)" 받거나 "포크(fork)"하여 이어서 작업할 수 있습니다.
    *   모바일 기기에서도 에이전트크래프트에 접속하여 에이전트를 관리하고 협업할 수 있음을 보여줍니다.

발표자는 에이전트크래프트가 가시성, 자율성, 협업을 통해 에이전트 활용의 "천장(ceiling)"을 높였다고 강조합니다. 또한, 에이전트와 생산성 작업에 익숙하지 않은 사람들도 게임과 같은 인터페이스를 통해 쉽게 접근할 수 있도록 "바닥(floor)"을 낮추는 것이 중요하다고 말합니다. 이를 위해 '루퍼스(Loopers)'라는 모바일 게임 스타일의 프로젝트 관리 인터페이스를 개발 중임을 보여줍니다. 이는 파일이나 도구의 세부 사항보다는 프로젝트 목표와 진행 상황에 초점을 맞춰 에이전트와의 상호작용을 단순화합니다.

결론적으로 발표자는 "우리가 병목 현상이다. 하지만 그럴 필요는 없다"고 말하며, 에이전트와 함께하는 미래를 위한 기술은 이미 우리 안에 있다고 역설합니다.

## 실무 적용 포인트
- **게임화된 UI/UX 도입:** 복잡한 에이전트 오케스트레이션 시스템에 RTS 게임과 같은 시각적이고 인터랙티브한 사용자 인터페이스를 적용하여 개발자 피로도를 줄이고 몰입도를 높일 수 있습니다.
- **에이전트 활동의 시각화:** 파일 시스템을 맵에 투영하거나 히트맵을 제공하는 등 에이전트의 작업 공간과 활동을 직관적으로 시각화하여 개발자가 에이전트의 상태와 진행 상황을 빠르게 이해하도록 돕습니다.
- **자율적인 퀘스트 시스템 구현:** 에이전트가 코드베이스를 분석하여 스스로 개선 과제를 식별하고, 사용자는 이를 퀘스트처럼 수락하여 에이전트가 자율적으로 작업을 수행하게 함으로써 반복적인 작업에 대한 인간의 개입을 최소화할 수 있습니다.
- **협업 및 다중 사용자 환경 지원:** 여러 개발자(및 에이전트)가 동일한 에이전트 환경에서 실시간으로 협업하고, 작업 핸드오프 및 공유된 커뮤니케이션 채널을 통해 효율적인 팀워크를 가능하게 하는 기능을 고려할 수 있습니다.
