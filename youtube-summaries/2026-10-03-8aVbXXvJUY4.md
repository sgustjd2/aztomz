# An Interaction Is All You Need — Ivan Leo, Google DeepMind

🔗 https://youtu.be/8aVbXXvJUY4 · 📅 2026-10-03 · 🎙 AI Engineer

## 한 줄 요약
구글 딥마인드의 이반 레오가 새로운 인터랙션 API와 관리형 에이전트를 소개하며, 모델과 에이전트의 복잡한 상호작용을 단순화하고 확장성을 높이는 방법을 설명합니다.

## 발표자·소속
이반 레오 (Ivan Leo), Google DeepMind 개발자 경험 팀

## 핵심 주장
- **통합된 인터랙션 API로 복잡성 감소**: 새로운 인터랙션 API는 모델과 에이전트의 추론을 지원하는 통합된 인터페이스를 제공하여, 복잡한 컨텍스트 관리, 장기 백그라운드 작업, 서버 측 상태 관리 등을 간소화합니다.
- **서버 측 상태 관리로 성능 향상**: `interaction_id`를 통해 서버 측에서 대화 컨텍스트를 유지함으로써, 개발자가 수동으로 상태를 관리할 필요 없이 모델 성능 저하 없이 다중 턴 상호작용을 지원합니다.
- **관리형 에이전트로 개발 간소화**: 안티그래비티(Antigravity)를 원격 에이전트(관리형 에이전트)로 활용하여 코드 실행, 파일 시스템 접근, 웹 검색 등 풍부한 도구 세트를 제공하며, 안전하고 격리된 샌드박스 환경에서 복잡한 에이전트를 단일 API 호출로 배포할 수 있습니다.
- **네트워크 프록시를 통한 보안 강화**: 에이전트가 외부 API를 호출할 때 중간자 프록시를 통해 민감한 네트워크 자격 증명(예: API 토큰)이 에이전트에 노출되지 않도록 보호하여 보안을 강화합니다.

## 세부 내용
발표는 AI 모델과의 상호작용 방식의 진화를 설명하며 시작됩니다. 초기에는 "농담해 줘"와 같은 단일 요청과 응답 방식의 '완성(Completions)'이 주를 이루었으나, 모델의 기능이 향상되면서 '지시 + 함수(Instructions + Functions)' 방식으로 발전했습니다. 이는 모델이 예측 가능한 JSON 객체를 생성하여 특정 도구를 호출하고 외부 데이터를 처리할 수 있게 함으로써, 사용자 정보 추출이나 데이터 파싱 같은 애플리케이션에 모델을 활용할 수 있게 했습니다. 현재는 '목표 + 사고 + 함수(Goals + Thinking + Functions)' 단계로, 모델이 여러 도구를 사용하고, 응답을 숙고하며, 환경과 상호작용하여 복잡한 작업을 수행할 수 있는 에이전트(Agents) 개념으로 확장되었습니다.

에이전트는 추론, 도구, 컨텍스트(기억), 환경을 결합한 것으로 정의됩니다. LLM은 사용자 요청을 이해하고, 함수나 외부 리소스는 세상과 상호작용하며, 단기 및 장기 기억은 과거 상호작용을 기억하는 데 사용됩니다. 환경은 함수를 실행하는 데 필수적입니다.

구글 AI 스튜디오(AI Studio)를 통해 모델을 쉽게 시작할 수 있으며, 발표자는 자신의 발표자 노트도 AI 스튜디오에서 2분 만에 작성했다고 언급했습니다. AI 스튜디오는 API 키 발급, 무료 티어 제공, 간소화된 UI 토글을 통한 파라미터 튜닝 등 모델 실험을 위한 편리한 환경을 제공합니다.

새로운 인터랙션 API는 모델과 에이전트의 추론을 지원하는 통합 API로 소개됩니다. 이는 복잡한 컨텍스트 관리, 장기 백그라운드 작업, 선택적 서버 측 상태 관리, 쉬운 해석 가능성 및 구성 가능성, 구글 검색 및 사용자 정의 함수를 포함한 결합된 도구 사용을 위해 설계되었습니다. 기존 API의 깊게 중첩된 객체 문제를 해결하기 위해, 인터랙션 API는 `interaction_id`를 통해 서버 측에서 상태를 유지하여 컨텍스트를 보존하고 성능 저하를 방지합니다.

데모에서는 단일 사진을 업로드하여 사용자의 다양한 여행지 사진을 생성하는 "anywhere" 애플리케이션이 시연되었습니다. 각 사진 생성은 단일 인터랙션이며, 동일한 `interaction_id`를 사용하여 생성된 이미지로부터 비디오를 만드는 것도 가능합니다. 이는 인터랙션 API와 새로운 옴니(Omni) 모델 덕분에 가능해진 복잡한 다중 모달 파이프라인의 예시입니다.

인터랙션 API는 오디오 및 이미지 생성과 같은 다양한 모달리티를 지원합니다. `response_modalities` 및 `generation_config` 매개변수를 통해 오디오 또는 이미지 출력을 쉽게 지정할 수 있습니다. 또한, `google_search`와 같은 내장 도구와 사용자 정의 `file_incident` 도구를 결합하여 에이전트가 인터넷을 검색하고 보안 보고서를 생성하는 등 복잡한 작업을 자율적으로 수행할 수 있게 합니다.

'스텝스 데이터 모델(Steps Data Model)'은 모델이 수행한 모든 작업의 유형화된 타임라인을 제공하여, 모델 출력, 사고 과정, 함수 호출 등을 명확하게 구분합니다. 이는 비동기 도구 호출이나 모델 간 협업과 같은 복잡한 시나리오를 지원하기 위한 강력한 데이터 구조입니다.

안티그래비티(Antigravity)는 구글의 관리형 에이전트로서, 코드 실행, 파일 시스템 접근, 웹 검색, URL 컨텍스트, 에이전트 스킬 등 풍부한 도구 세트를 갖춘 범용 에이전트입니다. 이는 안전하고 격리된 샌드박스에서 실행되며, 개발자는 복잡한 오케스트레이션 없이 단일 API 호출로 에이전트를 배포할 수 있습니다. 데모에서는 안티그래비티 에이전트가 GitHub 저장소를 분석하고 보고서를 생성하는 과정이 시연되었습니다.

'영구 환경(Persistent Environments)' 기능을 통해 `environment_id`를 사용하여 여러 상호작용에 걸쳐 에이전트의 상태를 유지할 수 있습니다. 이를 통해 사용자는 샌드박스를 개인적인 작업 공간처럼 활용할 수 있으며, 사용자 정의 종속성, 파일 등을 로드할 수 있습니다. 구글 클라우드 스토리지(GCS) 버킷, GitHub 저장소, 인라인 파일 등이 지원됩니다.

보안을 위해 '네트워크 프록시(Network Proxies)'가 구현되어 에이전트가 외부 API를 호출할 때 중간자 역할을 합니다. 이는 에이전트가 민감한 API 토큰을 직접 보지 못하도록 하여, 프롬프트 주입 등으로 인한 자격 증명 유출 위험을 방지합니다.

사용자는 소스 코드에서 직접 에이전트를 생성하거나, 대화형으로 환경을 설정한 후 스냅샷을 찍어 '명명된 에이전트(named agent)'로 저장할 수 있습니다. 이 명명된 에이전트는 저장 공간이나 샌드박스 비용 없이 모델 사용량에 대해서만 비용을 지불합니다.

마지막으로, '제미나이 API CLI(Gemini API CLI)'가 오픈소스로 공개되어 개발자들이 명령줄에서 제미나이 모델과 에이전트를 쉽게 테스트하고 배포할 수 있도록 지원합니다. 또한, 기존 코딩 에이전트 사용자들이 인터랙션 API로 쉽게 전환할 수 있도록 '인터랙션 API 스킬(Interactions API Skill)'도 제공됩니다.

- **상태 유지 및 컨텍스트 관리**: `interaction_id`를 사용하여 다중 턴 대화에서 모델의 컨텍스트를 서버 측에서 자동으로 유지할 수 있으므로, 복잡한 대화형 에이전트를 개발할 때 캐시 버스팅이나 컨텍스트 손실 문제를 방지할 수 있습니다.
- **보안 강화된 외부 API 연동**: 에이전트가 외부 서비스(예: GitHub API)와 연동해야 할 경우, 네트워크 프록시 기능을 활용하여 API 토큰과 같은 민감한 정보를 에이전트로부터 격리하고 안전하게 관리할 수 있습니다.
- **다중 모달리티 지원 활용**: 오디오, 이미지, 비디오 등 다양한 모달리티를 생성하고 처리하는 애플리케이션을 개발할 때, 인터랙션 API의 통합된 접근 방식을 통해 여러 모달리티를 유연하게 조합하고 제어할 수 있습니다.
