# Your Voice Agent is Just a Walkie Talkie — Neil Zeghidour, Gradium

🔗 https://youtu.be/a8EcVumh71E · 📅 2026-09-15 · 🎙 AI Engineer

## 한 줄 요약
발표자는 음성 AI 에이전트의 진화 과정을 설명하고, 자연스러움과 지능 사이의 균형을 맞추기 위해 단일 종단간(end-to-end) 모델 대신 자연스러운 음성 인터페이스와 스마트한 백엔드를 결합한 하이브리드 접근 방식이 비용 효율성과 제어 측면에서 더 유리하다고 주장합니다.

## 발표자·소속
닐 제기도르(Neil Zeghidour), Gradium 공동 창립자 겸 CEO

## 핵심 주장
- **음성 에이전트 기술의 진화**: Siri와 같은 초기 음성 에이전트는 복잡한 파이프라인과 제한된 사용 사례를 가졌으며, LLM 기반 대화형 AI는 개방형 대화를 가능하게 했지만 에이전트 기능과 자연스러움에 한계가 있었습니다.
- **음성 에이전트의 현재와 한계**: 현재 음성 에이전트는 LLM 에이전트와 도구 호출(tool calls)을 통해 지능적인 행동을 할 수 있지만, 텍스트 변환 과정에서 자연스러움(음색, 감정 등)을 잃고 여전히 높은 지연 시간을 가집니다.
- **음성-음성 LLM의 등장**: OpenAI의 GPT Realtime과 같은 음성-음성 LLM은 ASR, LLM, TTS 단계를 하나의 모델로 통합하여 낮은 지연 시간과 높은 자연스러움을 제공하지만, 텍스트 모델에 비해 지능이 제한적입니다.
- **턴-테이킹(Turn-taking)의 문제**: 기존 음성-음성 모델은 여전히 턴-테이킹 방식(화자가 번갈아 말하는 방식)에 기반하여 실제 인간 대화의 자연스러운 오버랩을 모델링하지 못하며, 이는 대화의 흐름을 방해하고 비자연스럽게 만듭니다.
- **자연스러움과 지능 간의 긴장**: 음성 에이전트 개발에는 자연스러움(낮은 지연 시간, 풀-듀플렉스, 오버랩)과 지능(강력한 추론, 도구 사용) 사이의 본질적인 상충 관계가 존재하며, 한쪽을 개선하면 다른 쪽에서 손실이 발생합니다.
- **하이브리드 접근 방식의 우위**: 단일 종단간 모델을 확장하는 것보다, 빠르고 자연스러운 음성 인터페이스(작은 음성 LLM)와 지능적인 백엔드(큰 텍스트 LLM)를 분리하여 결합하는 하이브리드 접근 방식이 비용 효율적이고 제어 가능하며, 자연스러움과 지능을 동시에 최적화할 수 있습니다.

## 세부 내용

발표자는 Gradium의 공동 창립자 겸 CEO인 닐 제기도르입니다. Gradium은 파리에 본사를 둔 스타트업으로, 주로 연구 분야에서 신경 코덱, 오디오 LLM, 음성-음성 모델 등을 개발해왔습니다. Kyutai라는 비영리 연구소를 통해 Moshi(최초의 풀-듀플렉스 음성-음성 모델), Hibiki(최초의 실시간 음성-음성 번역 시스템), Pocket-TTS(스마트폰에서 실행 가능한 TTS 모델)를 출시했으며, Gradium은 이러한 연구를 상용화하는 데 중점을 둡니다. Gradium은 TTS API, 온디바이스 TTS, STT API, 음성-음성 번역 API 등 다양한 음성 모델을 제공합니다.

발표자는 음성 에이전트가 고객 지원, 게임, 로봇 공학, 언어 학습, 헬스케어 등 다양한 분야에서 확산되고 있다고 언급하며, 음성 에이전트 기술의 역사와 미래를 다룹니다.

**1. LLM 이전: Siri (2011년)**
Siri는 음성 입력, STT, 자연어 이해(NLU), 대화 관리자, 스킬/서비스, 응답 생성, TTS, 음성 출력의 8단계로 구성된 복잡한 파이프라인을 가졌습니다. 이는 특정 사용 사례에 맞춰진 폐쇄형 대화 시스템이었고, 지연 시간이 길고 자연스러움이 낮았습니다.

**2. LLM 기반 대화형 AI (OpenAI 음성 모드)**
LLM의 등장으로 NLU, 대화 관리, 스킬/서비스, 응답 생성 단계가 하나의 LLM으로 통합되었습니다. 이는 개방형 대화를 가능하게 했지만, 에이전트 기능이 없고 지연 시간이 여전히 길었습니다.

**3. 음성 에이전트의 발전**
현재의 음성 에이전트는 LLM 에이전트가 추론, 계획, 도구 호출, 기억, 검색 등의 기능을 수행하여 더 복잡한 작업을 처리할 수 있습니다. 발표자는 드라이브스루 봇 데모를 통해 음성 에이전트가 주문을 받고 메뉴를 안내하며 총액을 계산하는 과정을 시연했습니다. 이 에이전트는 실제 행동을 취하고 주문을 추적하며 결제를 처리하는 등 지능적인 기능을 보여주었습니다. 그러나 여전히 텍스트 기반 변환으로 인해 음성 톤이나 감정과 같은 비언어적 정보가 손실되어 자연스러움에 한계가 있고 지연 시간도 존재합니다.

**4. 음성-음성 LLM의 등장**
OpenAI의 최신 음성 모드(Spring Update)는 음성-음성 LLM을 사용하여 ASR, LLM, TTS의 전체 캐스케이드를 하나의 모델로 대체합니다. 이는 지연 시간을 크게 줄이고 자연스러움을 높였지만, 텍스트 모델에 비해 지능이 제한적이라는 단점이 있습니다.

**5. 턴-테이킹의 문제점과 풀-듀플렉스**
기존의 음성-음성 모델은 턴-테이킹(반이중 통신) 방식에 기반하여, 사용자와 AI가 번갈아 말해야 합니다. 이는 인간 대화의 자연스러운 오버랩(동시 발화)을 모델링하지 못해 대화를 비자연스럽게 만듭니다. 발표자는 ChatGPT 음성 모드에서 사용자가 "음"과 같은 백채널링(backchanneling)을 시도할 때 AI가 이를 방해로 인식하고 말을 멈추는 데모를 보여주며 이 문제를 강조했습니다.

Gradium은 이 문제를 해결하기 위해 풀-듀플렉스(전이중 통신) 모델을 개발했습니다. 풀-듀플렉스 모델은 사용자와 AI가 동시에 말할 수 있도록 하여 인간 대화와 유사한 유연한 역동성을 제공합니다. 이를 위해 Gradium은 신경 코덱(neural codec)을 사용하여 24kHz 오디오를 12.5Hz의 37개 토큰으로 압축하고, GAN 디코더로 고품질 오디오를 재구성합니다. 이 압축된 오디오 토큰을 사용하여 LLM을 훈련함으로써, 텍스트 LLM과 유사한 방식으로 오디오 LLM을 훈련할 수 있습니다. Gradium의 풀-듀플렉스 데모는 사용자와 AI가 자연스럽게 대화하며 서로의 말을 끊거나 동시에 말하는 상황에서도 대화 흐름이 유지되는 것을 보여주었습니다.

**6. 자연스러움 vs 지능의 긴장과 두 가지 접근 방식**
음성 에이전트 개발에는 자연스러움(낮은 지연 시간, 풀-듀플렉스, 오버랩)과 지능(강력한 추론, 도구 사용) 사이의 본질적인 상충 관계가 있습니다. 자연스러움을 높이면 지능이 떨어지고, 그 반대도 마찬가지입니다. 발표자는 이 문제를 해결하기 위한 두 가지 경로를 제시합니다.

-   **경로 1: 하나의 종단간 모델 확장 (OpenAI의 GPT Realtime)**
    프론티어 텍스트 LLM에 오디오 지시 튜닝과 강화 학습(RL) 후처리 훈련을 통해 자연스럽고 지능적이며 풀-듀플렉스 오디오와 도구 호출 신뢰성을 갖춘 단일 음성-음성 모델을 만드는 방식입니다. 이는 모델 통합이 간단하지만, 텍스트 모델의 지능을 유지하면서 오디오 모달리티를 추가하는 과정이 매우 복잡하고 비용이 많이 듭니다.

-   **경로 2: 모델 분리 (Gradium의 MoshiRAG, Sakana AI의 KAME, Thinking Machines의 Interaction Models)**
    빠르고 자연스러운 풀-듀플렉스 음성 LLM이 대화를 진행하고, 이 모델이 이해하지 못하거나 복잡한 추론이 필요한 경우 대규모 텍스트 LLM 백엔드에 비동기적으로 작업을 위임하는 방식입니다. 작은 음성 LLM은 대화의 흐름을 유지하고, 큰 텍스트 LLM은 검색, 브라우징, 기억, 활성화 등 무거운 작업을 처리합니다.

**7. 어떤 접근 방식이 승리할 것인가? (하이브리드 접근 방식에 대한 Gradium의 베팅)**
발표자는 Gradium이 하이브리드 접근 방식에 베팅하는 이유로 **비용(Cost)**과 **제어(Control)**를 꼽습니다.
-   **비용**: 대부분의 대화는 복잡한 추론을 필요로 하지 않으므로, 작은 음성 LLM이 대부분의 턴을 처리하고, 대규모 텍스트 LLM은 필요할 때만 실행되어 수백에서 수천 개의 에이전트를 비동기적으로 대규모 배치로 서비스할 수 있어 비용 효율적입니다.
-   **제어**: 백엔드를 언제든지 교체할 수 있고, 텍스트 데이터만을 사용하여 특정 도구 호출에 대해 미세 조정할 수 있으며, 오디오 데이터가 필요하지 않아 유연성이 높습니다.

결론적으로, Gradium은 하이브리드 접근 방식이 경제적이고 제어 가능하며, 자연스러운 실시간 음성을 포기하지 않고도 지능적인 음성 에이전트를 구현할 수 있는 최적의 방법이라고 믿습니다.

## 실무 적용 포인트
- **음성 에이전트 아키텍처 선택**: 지능과 자연스러움 사이의 트레이드오프를 고려하여, 단일 종단간 모델(OpenAI 방식)과 하이브리드 모델(Gradium 방식) 중 프로젝트의 요구사항(비용, 제어, 지연 시간, 지능 수준)에 맞는 아키텍처를 선택해야 합니다.
- **신경 코덱(Neural Codec) 활용**: 오디오 LLM 훈련 시 원시 오디오의 높은 차원 문제를 해결하기 위해 신경 코덱(예: Encodex)을 사용하여 오디오를 압축된 토큰으로 변환하는 기술을 고려할 수 있습니다.
- **풀-듀플렉스 대화 구현**: 인간과 유사한 자연스러운 대화 경험을 위해 턴-테이킹 방식의 한계를 넘어 풀-듀플렉스(동시 발화)를 지원하는 멀티스트림 모델링(Multistream modeling) 기술을 적용하는 것을 검토할 수 있습니다.
- **백엔드 분리 및 비동기 처리**: 복잡한 추론이나 도구 호출이 필요한 경우, 실시간 음성 인터페이스는 가볍게 유지하고 대규모 텍스트 LLM 백엔드에 비동기적으로 작업을 위임하여 비용을 절감하고 시스템의 유연성을 높일 수 있습니다.
