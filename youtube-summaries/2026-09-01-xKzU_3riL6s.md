# Why Your AI Agent Needs a Wallet: USDC and Nanopayments — Harshal Bhangale, Circle

## 한 줄 요약
Circle은 AI 에이전트가 지불 장벽에 막히지 않고 자율적으로 작업을 수행할 수 있도록 USDC 기반의 나노페이먼트(Nanopayments)를 통해 에이전트 경제를 위한 풀스택 플랫폼을 제공합니다.

## 발표자·소속
Harshal Bhangale, Circle의 Staff Software Engineer

## 핵심 주장
- **AI 에이전트의 지불 장벽**: 현재 AI 에이전트는 계정 생성, 비밀번호 관리, API 키 처리, 신용카드 결제 승인 등 인간의 개입이 필요한 결제 과정에서 막히는 경우가 많습니다. 이는 에이전트의 자율적인 작업 수행을 방해하는 주요 병목 현상입니다.
- **기존 결제 시스템의 한계**: 지난 30년간 인간 고객을 위해 구축된 기존 인터넷 결제 시스템은 에이전트가 필요로 하는 실시간, 저비용, 프로그래밍 가능, 상시 작동의 특성을 충족하지 못합니다. 특히, API 호출과 같은 초소액, 고빈도 거래에 신용카드 수수료는 비합리적입니다.
- **블록체인 기반 결제의 문제점**: 블록체인은 이론적으로 에이전트 결제를 가능하게 하지만, 가스 요금과 처리량 제한으로 인해 초소액 거래에는 비효율적입니다. 가스 요금이 거래 금액을 초과하는 경우가 많아 경제적으로 비합리적이며, 네트워크 혼잡으로 예측 불가능한 지연이 발생할 수 있습니다.
- **Circle Gateway 나노페이먼트 솔루션**: Circle은 이러한 문제를 해결하기 위해 Circle Gateway 나노페이먼트를 개발했습니다. 이 시스템은 1 마이크로센트(0.000001 달러)만큼 작은 거래를 지원하며, 판매자에게는 가스 수수료가 없고, 즉각적인 크로스체인(crosschain) 전송이 가능하며, 기존 x402 v2 통합과도 호환됩니다.

## 세부 내용
발표는 AI 엔지니어링 컨퍼런스에서 스테이블코인 회사가 발표하는 이유에 대한 질문으로 시작됩니다. Circle은 세계 최대의 규제 스테이블코인인 USDC를 발행하며, 결제를 더 간단하고 저렴하게 만드는 데 전문성을 가지고 있습니다. 발표자는 AI 에이전트의 가장 큰 병목 현상이 바로 결제라고 강조합니다.

에이전트 경제의 타임라인을 제시하며, 2023년에는 LLM과 RAG를 활용한 프롬프트 기반 에이전트가, 2024년에는 LangChain과 LangGraph를 이용한 워크플로우가, 2025년에는 MCP(Multi-Agent Collaboration Protocol)와 스킬을 통한 오케스트레이션이 발전했으며, 2026년에는 에이전트가 직접 서비스를 결제하는 트랜잭션 단계로 진입했다고 설명합니다.

에이전트 주도 거래의 초기 성과로, 2026년 6월 30일 기준 지난 30일 동안 x402 프로토콜을 통한 거래량이 2,400만 달러를 넘어섰고, 이 중 98.8%가 USDC로 결제되었습니다. 2030년까지 에이전트 상거래 규모는 5조 달러에 이를 것으로 예상됩니다. x402는 서버가 402(Payment Required) 헤더를 반환하면 에이전트가 암호화폐 지갑에서 결제를 승인하고 요청을 재시도하는 방식입니다.

에이전트가 작업을 수행할 수 있지만, 계정 생성, 비밀번호, API 키 관리, 신용카드 결제 승인 등 인간의 개입이 필요한 결제 단계에서 막히게 됩니다. 또한, 에이전트는 초소액(sub-cent)의 고빈도 거래를 수행하는데, 기존 신용카드 수수료(예: 0.002 달러 API 호출에 0.30 달러 수수료)는 이러한 모델을 비현실적으로 만듭니다.

에이전트 경제를 위해서는 결제가 인터넷처럼 실시간, 저비용, 프로그래밍 가능, 상시 작동해야 하지만, 기존 시스템은 이를 위해 구축되지 않았습니다. 블록체인도 가스 요금과 처리량 제한(블록 크기, 가스 시장, 네트워크 혼잡)으로 인해 에이전트에게는 예측 불가능한 지연과 성능 저하를 초래할 수 있습니다. 예를 들어, 0.000001 달러를 이더리움으로 전송하면 53,720,000%의 수수료가 발생합니다.

Circle은 이러한 문제를 해결하기 위해 Circle Agent Stack의 핵심 구성 요소인 나노페이먼트(Nanopayments)를 개발했습니다. 이는 USDC 전송에 가스 수수료가 없는 에이전트 경제 활동을 위한 금융 레일입니다. 나노페이먼트는 1 마이크로센트(0.000001 달러)만큼 작은 거래를 지원하며, 일반적인 크기의 결제도 가능합니다. 전송은 가스 프리(gas-free)이며, 가스 추상화(gas abstracted)가 아닙니다. 또한, 유동성을 Gateway 지원 EVM 체인으로 즉시 전송할 수 있는 크로스체인(crosschain) 기능을 제공하며, 기존 x402 v2 통합과 호환됩니다.

라이브 데모에서는 두 개의 클로드(Claude) 에이전트(하나는 일반 클로드, 다른 하나는 Circle 에이전트 지갑이 장착된 클로드)에게 FIFA 월드컵 결승전 여행 계획을 세우고, 이메일을 보내고, 전화 통화를 하도록 지시했습니다. 일반 클로드는 이메일을 초안으로 작성할 수 있었지만, 실제로 보내거나 전화 통화를 할 수는 없었습니다. 반면, Circle 에이전트 지갑이 장착된 클로드는 PolyMarket 데이터와 같은 프리미엄 콘텐츠를 결제하고, 지출에 대한 가드레일(최대 15센트)을 설정하며, 이메일을 보내고, 전화 통화를 성공적으로 수행했습니다. 전화 통화에서는 에이전트가 여행 계획의 주요 내용을 요약하여 전달했습니다.

나노페이먼트의 작동 방식은 사용자가 Circle의 온램프(on-ramp) 제공업체를 통해 USD를 USDC로 전환한 후, 스마트 컨트랙트에 자금을 예치합니다. 에이전트는 오프체인 승인(암호화 서명)을 통해 결제를 요청하고, 서버는 이를 Circle에 전달하여 수백 밀리초 내에 결제를 처리합니다. 이를 통해 판매자는 에이전트가 요청한 리소스를 즉시 제공할 수 있습니다.

- **초소액 결제 모델 활용**: API 호출당 1센트 미만의 초소액 결제가 필요한 AI 서비스 모델을 구축할 때, 기존 신용카드 시스템의 높은 수수료와 지연 문제를 피할 수 있는 가스 프리(gas-free) 블록체인 기반 나노페이먼트 솔루션을 검토합니다.
- **에이전트 지갑 및 가드레일 구현**: 에이전트에게 자율적인 결제 권한을 부여하되, 지갑에 최대 지출 금액이나 특정 유형의 거래 제한과 같은 가드레일을 설정하여 통제 가능한 에이전트 경제를 구축합니다.
- **크로스체인 유동성 활용**: 다양한 EVM 체인 간에 유동성을 즉시 전송할 수 있는 크로스체인 기능을 활용하여, 에이전트가 여러 블록체인 기반 서비스에 걸쳐 유연하게 결제하고 상호작용할 수 있도록 설계합니다.## 한 줄 요약

라이브 데모에서는 두 개의 클로드(Claude) 에이전트(하나는 일반 클로드, 다른 하나는 Circle 에이전트 지갑이 장착된 클로드)에게 FIFA 월드컵 결승전 여행 계획을 세우고, 이메일을 보내고, 전화 통화를 하도록 지시했습니다. 일반 클로드는 이메일을 초안으로 작성할 수 있었지만, 실제로 보내거나 전화 통화를 할 수는 없었습니다. 반면, Circle 에이전트 지갑이 장착된 클로드는 PolyMarket 데이터와 같은 프리미엄 콘텐츠를 결제하고, 지출에 대한 가드레일(최대 15센트)을 설정하며, 이메일을 보내고, 전화 통화를 성공적으로 수행했습니다. 전화 통화에서는 에이전트가 여행 계획의 주요 내용을 요약하여 전달했습니다.

나노페이먼트의 작동 방식은 사용자가 Circle의 온램프(on-ramp) 제공업체를 통해 USD를 USDC로 전환한 후, 스마트 컨트랙트에 자금을 예치합니다. 에이전트는 오프체인 승인(암호화 서명)을 통해 결제를 요청하고, 서버는 이를 Circle에 전달하여 수백 밀리초 내에 결제를 처리합니다. 이를 통해 판매자는 에이전트가 요청한 리소스를 즉시 제공할 수 있습니다.

- "Circle은 스테이블코인 회사인데 왜 AI 엔지니어링 컨퍼런스에 있나요? 답은 간단합니다. Circle은 세계 최대의 규제 스테이블코인인 USDC를 발행하며, 결제를 더 간단하고 저렴하게 만드는 데 전문성을 가지고 있습니다. 그리고 에이전트의 병목 현상 중 하나가 바로 이것입니다."
- "에이전트는 작업을 할 수 있습니다. 결제에서 막힙니다."
- "결제는 인터넷처럼 작동해야 합니다. 실시간, 저비용, 프로그래밍 가능, 상시 작동."
- 라이브 데모에서 에이전트가 실제로 전화 통화를 걸어 여행 계획을 요약해주는 장면은 AI 에이전트의 실질적인 활용 가능성을 보여주는 강력한 예시였습니다.

## 실무 적용 포인트
- **AI 에이전트 개발 시 결제 기능 고려**: 에이전트가 외부 서비스나 데이터에 접근할 때 발생하는 결제 문제를 해결하기 위해 Circle Gateway와 같은 나노페이먼트 솔루션을 통합하는 것을 고려해야 합니다.
- **초소액 결제 모델 활용**: API 호출당 1센트 미만의 초소액 결제가 필요한 AI 서비스 모델을 구축할 때, 기존 신용카드 시스템의 높은 수수료와 지연 문제를 피할 수 있는 가스 프리(gas-free) 블록체인 기반 나노페이먼트 솔루션을 검토합니다.
- **에이전트 지갑 및 가드레일 구현**: 에이전트에게 자율적인 결제 권한을 부여하되, 지갑에 최대 지출 금액이나 특정 유형의 거래 제한과 같은 가드레일을 설정하여 통제 가능한 에이전트 경제를 구축합니다.
- **크로스체인 유동성 활용**: 다양한 EVM 체인 간에 유동성을 즉시 전송할 수 있는 크로스체인 기능을 활용하여, 에이전트가 여러 블록체인 기반 서비스에 걸쳐 유연하게 결제하고 상호작용할 수 있도록 설계합니다.
