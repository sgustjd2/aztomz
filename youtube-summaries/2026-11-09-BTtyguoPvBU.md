# How One Founder Manages 20 AI Coding Agents at Once - Ryan Carson, Untangle

🔗 https://youtu.be/BTtyguoPvBU · 📅 2026-11-09 · 🎙 AI Engineer

## 한 줄 요약
Untangle의 CEO 라이언 카슨은 AI 에이전트를 활용하여 소프트웨어 개발 프로세스를 혁신하고 있으며, 인간 관리자 에이전트와 빌더 에이전트의 계층 구조를 통해 개발 속도와 품질을 높이고, 채용 과정에서도 에이전트의 역량을 중심으로 인간의 편견을 최소화하는 방법을 제시합니다.

## 발표자·소속
라이언 카슨 (Ryan Carson), Untangle 창립자 겸 CEO

## 핵심 주장
- AI 에이전트를 인간 조직처럼 계층적으로 관리하여 소프트웨어 개발의 효율성과 품질을 극대화할 수 있습니다. 인간은 우선순위 설정과 고객 소통에 집중하고, 에이전트는 코드 작성 및 기술적 문제 해결을 담당합니다.
- 인간-에이전트 상호작용에서 오디오 인터페이스를 적극 활용하면 정보 처리 속도를 높이고 더 자연스러운 관리 경험을 제공할 수 있습니다.
- 모든 코드 변경 사항에 대한 자동화된 비디오 기록은 인간이 에이전트의 작업을 검토하고 "출시 승인(ship it)" 결정을 내리는 데 필수적인 도구로, 품질 보증과 투명성을 확보합니다.
- 채용 과정에서 인간의 편견을 최소화하고 후보자의 실제 에이전트 운영 능력을 평가하기 위해, 초기 단계에서는 인간과의 직접적인 소통 없이 에이전트가 생성한 작업물(비디오)을 평가해야 합니다.
- 로컬 개발 환경 대신 클라우드 기반 에이전트 개발 환경을 사용해야 하며, 에이전트 간의 효율적인 협업을 통해 개발 병목 현상을 해소하고 더 나은 소프트웨어를 만들 수 있습니다.

## 세부 내용
라이언 카슨은 Untangle이라는 AI 법률 보조원 스타트업의 창립자 겸 CEO로서, 특히 이혼 관련 가족법 분야에 집중하고 있습니다. 그는 과거 4개의 회사를 창업하고 매각하며 사람 관리의 중요성을 깨달았는데, 이 경험이 AI 에이전트 관리에도 적용된다고 말합니다.

**AI 에이전트 조직 구조 (The Org Chart):**
Untangle의 개발 조직은 계층적인 에이전트 구조를 따릅니다.
1.  **인간 (Human)**: 최상위 계층으로, 주간 우선순위를 설정하고 고객과 소통하는 등 인간 고유의 역할을 수행합니다.
2.  **관리자 에이전트 (Manager agent)**: 인간 바로 아래에 위치하며, 코드를 직접 작성하지 않습니다. 이들은 Devin(클라우드 기반 AI 개발 환경)의 세션으로, 라이언은 주로 오디오를 통해 이 에이전트와 소통합니다. 관리자 에이전트는 인간으로부터 "무엇이 필요한가?"(질문 및 권장 사항)를 받아 티켓(Linear 사용)을 생성합니다. "티켓이 없으면 작업도 없다"는 원칙을 따르며, 각 티켓은 하나의 풀 리퀘스트(PR)에 해당합니다. 관리자 에이전트는 의존성을 기반으로 티켓을 가져옵니다.
3.  **빌더 에이전트 (Builder agents)**: 관리자 에이전트가 동시에 최대 20~25개의 빌더 에이전트를 관리합니다. 인간은 이 빌더 에이전트와 직접 소통하지 않으며, 모든 관리는 관리자 에이전트를 통해 이루어집니다. 관리자 에이전트는 15분마다 빌더 에이전트의 진행 상황을 확인하고, 기술적인 질문에 답하거나 작은 문제를 해결하여 작업을 원활하게 진행하도록 돕습니다. 이는 Devin의 자동화 스크립트를 통해 이루어집니다.
4.  **리뷰어 에이전트 (Reviewer agent)**: 각 빌더 에이전트는 코드 리뷰를 위해 리뷰어 에이전트를 호출합니다. Untangle은 최대 3번의 리뷰를 허용하며, 3번의 리뷰 후에도 중요한 버그가 해결되지 않으면 관리자 에이전트에게, 필요시 인간에게 보고됩니다.

**개발 프로세스:**
빌더 에이전트의 작업 흐름은 다음과 같습니다.
1.  **코드 + 테스트**: 테스트 주도 개발(TDD) 방식으로 코드를 작성합니다.
2.  **QA 에이전트**: 빌더 에이전트의 하위 에이전트가 QA를 실행하여 코드의 정확성을 검증합니다.
3.  **비디오 (Video)**: Devin의 내장 기능을 활용하여 개발 중인 기능이 작동하는 모습을 비디오로 기록합니다. 이 비디오는 테스트 통과 여부와 함께 제공되어, 인간이 시각적으로 기능의 작동 여부와 외관을 확인할 수 있게 합니다. 라이언은 이 비디오 검토가 "인간이 개입하는 루프(human in the loop)"의 핵심이며, 이 단계에서 절대 타협해서는 안 된다고 강조합니다.
4.  **출시 승인 (Ship it)**: 비디오를 통해 기능이 제대로 작동함을 확인한 후, 인간이 최종적으로 출시를 승인합니다.

**팀 협업 및 인프라:**
*   **에이전트 간 협업**: 관리자 에이전트들은 서로 소통하여 작업을 조율하고 서로의 진행 상황을 파악합니다. 이를 통해 병목 현상을 줄이고 효율적인 협업을 가능하게 합니다.
*   **병합 관리자 에이전트 (Merge manager agent)**: 모든 PR이 준비되면, 병합 관리자 에이전트가 GitHub 병합 큐를 관리하여 데이터베이스 마이그레이션 번호와 같은 충돌 요소를 조율하고 순서대로 병합을 진행합니다.
*   **클라우드 개발**: 라이언은 로컬 개발을 중단하고 클라우드 기반 에이전트 개발 환경(Devin)을 사용할 것을 강력히 권장합니다. 이는 에이전트 간의 원활한 협업과 효율적인 프로세스를 위해 필수적이라고 강조합니다.

**채용 방식 (How we hire):**
Untangle의 채용 방식은 AI 에이전트 시대에 맞춰 완전히 변화했습니다.
1.  **후보자 (Candidates)**: 초기에는 어떠한 사전 심사나 화상 통화도 하지 않습니다. 이는 인간의 편견(취미, 대화 방식 등)을 배제하기 위함입니다. 대신 후보자들에게 자신이 관리하는 앱에서 새로운 기능을 개발하는 45분짜리 전체 화면 비디오를 제출하도록 요청합니다.
2.  **랭킹 에이전트 (Ranking agent)**: 제출된 비디오는 Untangle의 랭킹 에이전트(Devin)로 전달됩니다. 이 에이전트는 모든 비디오를 시청하고 스크립트를 분석하여 후보자들의 에이전트 운영 능력을 기준으로 순위를 매깁니다. 라이언은 처음에 이 에이전트의 판단을 믿지 못했지만, 결과적으로 에이전트의 판단이 옳았음을 인정했습니다.
3.  **상위 5명 (Top 5)**: 랭킹 에이전트가 선정한 상위 5명의 후보자들은 유료 프로젝트에 초대됩니다. Untangle은 이들에게 고정된 수수료를 지급하고, 최대 16시간 동안 Untangle의 코드베이스에서 실제 PR을 병합할 준비를 하도록 요청합니다. 이 과정 또한 전체 화면으로 기록됩니다.
4.  **최종 후보 (Finalist)**: 이 프로젝트를 통해 최종 후보 1명을 선정합니다. 이 단계에서 비로소 최종 후보와 첫 번째 인간적인 통화(First call)를 진행합니다.

라이언은 이러한 채용 방식이 인간의 편견을 줄이고 후보자의 실제 역량을 평가하는 데 매우 효과적이라고 믿으며, 미래의 채용 표준이 될 것이라고 주장합니다.

## 실무 적용 포인트
- **에이전트 중심의 개발 워크플로우 구축**: 인간이 전략적 의사결정과 고객 피드백에 집중하고, AI 관리자 에이전트와 빌더 에이전트가 실제 개발 및 QA 작업을 수행하는 계층적 구조를 도입하여 개발 효율성을 높입니다.
- **오디오 기반 에이전트 관리 인터페이스 활용**: 에이전트에게 지시를 내리거나 피드백을 받을 때 텍스트보다 오디오 인터페이스를 우선적으로 고려하여, 인간 관리자의 정보 처리 속도와 편의성을 향상시킵니다.
- **자동화된 비디오 기록 및 검토 시스템 도입**: 모든 코드 변경 및 기능 개발 과정에 대한 전체 화면 비디오 기록을 의무화하고, 이를 통해 인간이 에이전트의 작업 결과를 시각적으로 검증하고 품질을 보증하는 "인간 개입 루프"를 강화합니다.
- **클라우드 기반 개발 환경으로 전환**: 로컬 개발 환경의 한계를 극복하고 에이전트 간의 원활한 협업 및 빠른 반복 작업을 위해 클라우드 기반의 개발 환경(예: Devin)으로 전환을 적극적으로 추진합니다.
- **AI 기반의 편견 없는 채용 프로세스 설계**: 채용 초기 단계에서 후보자의 실제 작업 능력(에이전트 운영 능력)을 평가하기 위해, 인간의 개입을 최소화하고 AI 에이전트가 생성한 비디오 작업물 및 스크립트를 활용한 객관적인 평가 시스템을 구축합니다.
