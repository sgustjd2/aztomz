# How to Test Your Agents on Real Tasks With Harbor - Xander Song, Arize AI

🔗 https://youtu.be/kRJjSOYqW0I · 📅 2026-10-26 · 🎙 AI Engineer

## 한 줄 요약
Harbor는 실제 데이터와 격리된 샌드박스 환경에서 에이전트의 작업을 평가하고, 그 결과를 기반으로 에이전트의 성능을 신뢰성 있게 개선할 수 있도록 돕는 오픈소스 프레임워크입니다.

## 발표자·소속
Xander Song, Arize AI

## 핵심 주장
*   **증거 기반 에이전트 개발:** Harbor는 '느낌'이 아닌 '증거'에 기반하여 에이전트를 개발하고 배포할 수 있도록 지원하며, 이를 통해 에이전트의 반복 개발 속도와 신뢰도를 높입니다.
*   **격리된 샌드박스 환경:** 에이전트는 실제 데이터가 포함된 신선한 샌드박스(Docker 컨테이너) 환경에서 실행되어, 실제 작업에 대한 정확하고 일관된 평가를 보장합니다.
*   **유연한 태스크 및 검증자 정의:** 사용자는 자연어 명령으로 실제와 같은 태스크를 정의하고, 에이전트의 성공 또는 실패를 정확하게 판단하는 맞춤형 검증자(스크립트)를 생성할 수 있습니다.
*   **수평적 확장성 및 통합:** Harbor는 각 태스크와 평가 실행을 독립적으로 처리하여 수평적 확장이 가능하며, Arize AI의 Phoenix와 같은 AI 옵저버빌리티 플랫폼과 통합되어 에이전트의 행동을 시각화하고 분석할 수 있습니다.

## 세부 내용

발표는 Harbor 프레임워크의 소개로 시작됩니다. Harbor는 실제 태스크에서 에이전트를 평가하기 위한 오픈소스 프레임워크로, 실제 데이터를 사용하여 격리된 샌드박스 환경에서 에이전트를 실행합니다. 발표의 핵심 주제는 '느낌'이 아닌 '증거'에 기반하여 에이전트를 배포하는 것입니다.

**Harbor의 개요:**
Harbor는 크게 네 가지 단계로 구성됩니다:
1.  **Task (태스크):** 에이전트가 완료해야 할 자연어 명령 형태의 지시사항입니다.
2.  **Agent (에이전트):** 태스크를 수행하기 위해 실제 데이터가 있는 새로운 샌드박스 환경에서 실행됩니다.
3.  **Verifier (검증자):** 에이전트가 환경에 남긴 결과(사이드 이펙트)를 확인하여 태스크의 성공 여부를 판단합니다.
4.  **Reward (보상):** 검증자가 0 또는 1(성공/실패)과 같은 이진 점수를 부여합니다.

이러한 파이프라인을 반복(iterate)함으로써 에이전트의 변화가 성능에 미치는 영향을 빠르고 효율적으로 확인할 수 있습니다.

**Harbor 아키텍처:**
Harbor의 태스크는 `task.toml` 파일로 정의되며, 여기에는 `instruction.md` (에이전트에게 전달할 자연어 명령), `environment/` (에이전트가 실행될 Docker 환경 정의 및 관련 데이터 포함), `solution/` (선택 사항으로, 태스크의 올바른 해결책 스크립트, 즉 '오라클' 역할을 함), `tests/` (검증자 스크립트)가 포함됩니다. 여러 태스크는 데이터셋으로 묶일 수 있습니다.

각 태스크에 대해 Harbor는 구성 가능한 수의 'Trial(시행)'을 실행합니다. 각 시행은 새로운 Docker 컨테이너 형태의 격리된 환경을 구축하고, 여기에 관련 데이터를 시드(seed)합니다. 에이전트(또는 오라클)가 이 환경에서 명령을 수행하고 사이드 이펙트를 생성하면, 검증자 스크립트가 실행되어 결과를 확인하고 보상을 생성합니다. 에이전트의 실행 경로는 ATIF(Agent Trajectory Interchange Format)라는 JSON 기반 형식으로 기록될 수 있으며, 이는 디버깅에 유용합니다. 이 전체 파이프라인을 'Job(작업)'이라고 부릅니다.

**검증자의 역할:**
검증자는 에이전트의 구현에 대해 알지 못하는(agnostic) 블랙박스 방식으로 작동합니다. 검증자는 오직 에이전트가 환경에 남긴 사이드 이펙트(예: 파일 시스템 변경, 데이터베이스 업데이트)만 확인합니다. 이는 통합 테스트와 유사하며, 에이전트의 내부 구현을 변경하더라도 검증자가 안정적으로 작동하게 하여 리팩토링 및 개선 작업을 용이하게 합니다.

**수평적 확장성:**
Harbor의 각 태스크와 시행은 독립적이기 때문에, 모든 작업을 병렬로 실행할 수 있습니다. 이는 Daytona, Modal과 같은 샌드박스 제공업체와 호환되어 대규모 테스트 스위트를 빠르게 처리할 수 있게 합니다. 발표자는 200개의 동시 워커로 테스트를 빠르게 실행하는 Arize AI의 경험을 언급했습니다.

**Phoenix Harbor 플러그인:**
Arize AI는 Harbor를 자사의 오픈소스 AI 옵저버빌리티 도구인 Phoenix와 통합하는 플러그인을 개발했습니다. Harbor의 데이터셋, 에이전트, 시행, 검증자, 보상, 트라젝토리 개념은 Phoenix의 데이터셋, 실험, 런, 평가, 트레이스 개념에 매핑됩니다. Harbor의 ATIF 트라젝토리는 OpenTelemetry 형식으로 변환되어 Phoenix로 수집되며, 이를 통해 에이전트의 복잡한 실행 과정을 시각화하고 분석할 수 있습니다.

**실무 적용 사례:**
Arize AI 팀은 Harbor를 사용하여 에이전트의 성능을 빠르게 반복하고 개선합니다.
*   **환경:** Docker 컨테이너에 SQLite 파일과 같은 실제 데이터를 시드하고, 에이전트(Claude Code, Codex)는 CLI, MCP 서버, 또는 자체 서버 측 에이전트(Pixie)를 통해 이 환경과 상호작용합니다.
*   **태스크:** 예를 들어, '지난주 가장 많은 트레이스를 기록한 날을 찾아라'와 같이 LLM 호출을 분석하는 질문이나, '실패한 마이그레이션을 수정하라'와 같은 코딩 에이전트 태스크를 정의합니다.
*   **검증자:** 에이전트가 올바른 SQL 쿼리를 실행했는지, 또는 파일 시스템에 의도한 변경을 가했는지 확인하는 스크립트를 사용합니다.
*   **데이터:** 실제 프로덕션 트레이스에서 발견된 '환각(hallucinated) LLM 호출'과 같은 실제 문제 사례를 데이터셋에 추가하여 에이전트의 성능을 평가합니다.

**데모 및 결과:**
발표자는 Phoenix UI에서 Harbor 실험 결과를 시연했습니다.
*   **데이터셋 버전 관리:** 태스크와 데이터셋의 변경 이력을 추적하여 특정 시점의 에이전트 성능을 재현하고 비교할 수 있습니다.
*   **메트릭 시각화:** 에이전트의 비용, 실행 시간, 보상(성공률), 툴 호출 횟수 등 다양한 메트릭을 그래프로 시각화하여 에이전트 개선 효과를 한눈에 파악합니다.
*   **트라젝토리 분석:** 특정 에이전트 실행(트라젝토리)을 클릭하여 각 단계별 LLM 호출, 툴 사용, 출력 등을 상세히 확인하고 디버깅할 수 있습니다.
*   **비용 최적화 사례:** 에이전트가 REST/GraphQL API를 통해 데이터를 페이지네이션하여 집계 쿼리를 수행하는 대신, SQL 툴을 사용하여 데이터베이스에서 직접 집계 쿼리를 실행하도록 프롬프트를 수정하는 사례를 보여주었습니다. 이 변경으로 GraphQL 툴 호출 횟수가 줄고 SQL 호출 횟수가 늘어났으며, 이는 에이전트가 더 효율적으로 작동함을 의미합니다.

## 인상적인 대목
"Ship on evidence, not vibes." (증거에 기반하여 배포하고, 느낌에 의존하지 마세요.) - 에이전트 개발의 신뢰성과 객관성을 강조하는 핵심 문구입니다.

## 실무 적용 포인트
*   **에이전트 평가 파이프라인 구축:** Harbor를 활용하여 에이전트의 성능을 체계적으로 평가하는 파이프라인을 구축하고, 에이전트의 변경 사항이 실제 작업에 미치는 영향을 정량적으로 측정합니다.
*   **실제 데이터 기반 테스트:** 프로덕션 환경에서 발생하는 실제 데이터를 활용하여 테스트 환경을 구성하고, 에이전트가 실제 시나리오에서 어떻게 작동하는지 검증합니다.
*   **검증자 스크립트 활용:** 에이전트의 내부 구현에 독립적인 검증자 스크립트를 작성하여, 에이전트의 리팩토링이나 모델 교체 시에도 평가의 일관성을 유지하고 테스트 유지보수 비용을 절감합니다.
*   **AI 옵저버빌리티 도구 연동:** Phoenix와 같은 AI 옵저버빌리티 플랫폼과 Harbor를 연동하여 에이전트의 실행 트라젝토리, 비용, 지연 시간 등 다양한 메트릭을 시각화하고, 에이전트의 행동을 심층적으로 분석하여 개선 포인트를 식별합니다.
