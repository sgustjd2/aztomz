# Stop Telling Agents How — Dan Barrett, Raymond Weitekamp & Jose Montes de Oca, OpenProse

🔗 https://youtu.be/7T-gldvgfpo · 📅 2026-10-18 · 🎙 AI Engineer

## 한 줄 요약
OpenProse는 마크다운 기반의 선언적 AI 워크플로우 프레임워크로, 에이전트가 '무엇을 할지'만 정의하면 '어떻게 할지'는 에이전트가 스스로 결정하여 복잡한 작업을 자동화하고 관리합니다.

## 핵심 주장
- **선언적 마크다운 기반 워크플로우**: OpenProse는 에이전트 프레임워크 전체가 마크다운으로 작성된 하나의 거대한 프롬프트이며, 사용자는 '무엇을 할지'를 선언적으로 정의하고 에이전트가 실행 방법을 결정합니다.
- **이벤트 기반 시스템**: 워크플로우는 채팅이 아닌 특정 이벤트(예: GitHub 이슈, 웹훅, 스케줄)에 의해 시작되며, 이는 자율적인 '상시 실행 작업(standing job)'을 가능하게 합니다.
- **계약(Contract) 개념 도입**: 원하는 결과(목표, 최종 상태)를 '계약'으로 정의하고, 이 계약들을 조합하여 복잡한 멀티 에이전트 워크플로우를 구성하며, 이는 고전적인 소프트웨어 공학의 원칙을 차용합니다.
- **조직 지식의 자동화**: OpenProse는 조직의 운영 지식(예: 표준 운영 절차, 규제 문서)을 실행 가능한 문서로 변환하여, 수동으로 처리하던 반복적이고 감사 가능한 화이트칼라 업무를 자동화합니다.
- **하네스(Harness) 독립성**: 프레임워크는 특정 LLM 하네스에 종속되지 않으며, 온프레미스 배포를 지원하여 기업이 데이터와 모델에 대한 통제권을 유지하면서 AI 워크플로우를 구축할 수 있게 합니다.

## 세부 내용
발표는 OpenProse의 창립자인 Dan Barrett이 AI 기술 발전의 맥락에서 OpenProse를 소개하며 시작됩니다. 그는 5년 전 '최고의 프롬프트 엔지니어'로 불렸던 경험을 언급하며, AI 기술이 빠르게 발전했지만 '의도를 전달하는' 근본적인 문제는 여전히 중요하다고 강조합니다. OpenProse는 이러한 문제에 대한 해결책으로, 언어가 창조의 강력한 힘이라는 믿음에 기반하여 개발되었습니다.

OpenProse의 핵심은 모든 것이 마크다운으로 작성된다는 점입니다. 에이전트의 커널(부트로더/해결 경로)과 프로그램 자체가 마크다운으로 작성된 거대한 프롬프트이며, LLM이 컴파일러/VM 역할을 합니다. 이는 전통적인 파서나 바이트코드가 필요 없음을 의미합니다. 워크플로우는 채팅 방식이 아닌 이벤트 기반으로 작동하며, GitHub 이슈, 웹훅, 스케줄 등 특정 이벤트가 발생하면 미리 정의된 '계약'에 따라 작업이 자동으로 실행됩니다.

Raymond Weitekamp는 OpenProse의 두 가지 핵심 개념인 'Just Markdown'과 'Event-driven'을 상세히 설명합니다.
- **Just Markdown**: 에이전트 프레임워크 전체가 텍스트로 구성되어 있어, IT 부서의 승인 없이도 기존 스택에 쉽게 통합할 수 있습니다. 코드를 작성하지 않는 사람도 논리적인 영어만 읽을 수 있다면 계약을 이해하고 편집할 수 있습니다.
- **Event-driven**: 워크플로우는 '무엇을 할지'를 선언적으로 정의하고, 에이전트가 '어떻게 할지'를 결정합니다. 이는 비용 효율적인 모델 선택과 복잡성 관리를 가능하게 합니다.

데모에서는 `run.prose.md`를 사용하여 GitHub 이슈가 발생했을 때 자동으로 코드를 수정하거나 진단 계획을 생성하는 과정을 보여줍니다. 특히 '까다로운 선임 개발자' 페르소나를 가진 에이전트가 Pull Request를 검토하는 시나리오를 통해, 에이전트가 비용이 드는 작업을 수행하기 전에 사용자에게 확인을 요청하는 모습과, 여러 에이전트가 반복적인 검토를 통해 코드를 개선하는 과정을 시연합니다.

OpenProse는 온프레미스 배포를 지원하며, 기업이 데이터와 조직의 지식(예: 양적 모델 문서화)을 외부 클라우드로 보내지 않고 내부에서 관리할 수 있도록 돕습니다. 이는 규제 준수 및 보안에 중요한 이점을 제공합니다. 궁극적으로 OpenProse는 반복적이고 신뢰할 수 있으며 감사 가능한 워크플로우를 자동화하여, 수동 작업에 비해 훨씬 저렴하고 효율적인 솔루션을 제공하는 것을 목표로 합니다.

## 인상적인 대목
- "당신은 컴파일러입니다. 이것은 비유가 아닙니다. 당신은 컴파일러입니다." (You are the compiler. This is not an analogy. You are the compiler.)
- "의도를 전달하는 것"이 AI 시대에도 변치 않는 핵심 과제라는 통찰.
- "기관의 운영 지식(institutional operational knowledge)을 문서화(documentation)하는 것"이 곧 실행 가능한 코드가 된다는 개념.
- "계약 + 트리거 = 상시 실행 작업(standing job)"이라는 워크플로우 정의.

## 실무 적용 포인트
- **반복적인 문서화 작업 자동화**: 규제 준수, 내부 감사, 양적 모델 문서화 등 반복적이고 정기적인 문서화 작업을 OpenProse 계약으로 정의하여 자동화할 수 있습니다.
- **이벤트 기반 코드 리뷰 시스템 구축**: GitHub 웹훅과 연동하여 Pull Request 생성 시 자동으로 코드 리뷰 에이전트를 실행하고, 에이전트가 제안한 수정사항이나 피드백을 기반으로 개발자가 최종 결정을 내리는 협업 시스템을 구축할 수 있습니다.
- **비용 최적화 및 유연한 모델 활용**: '무엇을 할지'만 정의하고 '어떻게 할지'는 에이전트에게 맡김으로써, 워크플로우 실행 시 더 저렴하거나 더 강력한 LLM을 선택하여 비용을 최적화하고 유연성을 확보할 수 있습니다.
- **온프레미스 AI 워크플로우 구현**: 민감한 데이터나 독점적인 운영 지식을 외부 클라우드에 노출하지 않고, OpenProse를 온프레미스에 배포하여 기업 내부에서 AI 기반 워크플로우를 개발하고 실행할 수 있습니다.
