# Your Coding Agent Is 6 Months Out of Date — Jakub Hojsan, Exa

## 핵심 주장
- **LLM의 지식 단절 문제 해결:** 현재 LLM은 훈련 데이터의 지식 단절로 인해 최신 정보(예: 최근 코드 변경사항)에 접근할 수 없으며, 이는 코딩 및 코드 리뷰 에이전트의 성능에 심각한 제약을 초래합니다.
- **토큰 효율적인 검색:** Exa는 전체 웹 페이지를 LLM에 전달하는 대신, 쿼리에 가장 관련성이 높은 부분만 약 700자 이내의 "하이라이트"로 추출하여 제공함으로써 토큰 사용을 최적화하고 비용을 절감합니다.
- **투명성과 표준화:** Exa는 검색 과정의 모든 단계(쿼리, 소스, 하이라이트)를 투명하게 제공하며, 모든 모델에 걸쳐 일관된 검색 계층을 제공하여 특정 모델 공급업체에 종속되지 않고 유연하게 사용할 수 있도록 합니다.
- **에이전트의 검색 활용 능력 향상:** 단순히 검색 도구를 제공하는 것을 넘어, Exa는 에이전트가 언제 검색 도구를 사용해야 하는지(예: 의존성 또는 버전 변경 시)에 대한 규칙을 학습하도록 지원하여, 에이전트가 자체적으로 외부 지식을 활용할 수 있도록 돕습니다.

## 세부 내용
발표자는 AI 엔지니어링 컨퍼런스에서 Exa의 검색 기술에 대해 설명했습니다. 발표의 핵심은 대규모 언어 모델(LLM)이 최신 정보에 대한 "지식 단절"을 겪고 있어, 특히 코딩 및 코드 리뷰 에이전트 분야에서 문제가 발생한다는 것입니다. 예를 들어, GPT-5.5의 지식 단절 시점이 2023년 12월인데, 2024년 4월에 발생한 `cuml #2015`와 같은 중요한 코드 변경사항은 모델의 "블라인드 스팟"에 해당하여 인식하지 못합니다. 인간 개발자는 스택 오버플로우나 관련 저장소를 직접 찾아 변경사항을 확인하지만, LLM은 이러한 최신 정보를 스스로 찾아서 적용하기 어렵습니다.

Exa는 이러한 문제를 해결하기 위해 시맨틱 검색 엔진을 개발했습니다. 이 엔진은 쿼리를 받으면 관련성 높은 "하이라이트"를 LLM에 전달합니다. 이 하이라이트는 전체 웹 페이지가 아닌, LLM이 질문에 답하는 데 필요한 핵심적인 정보만을 담고 있어 토큰 효율적입니다. 발표자는 `cuml #2015`의 예시를 통해, 일반적인 LLM이 해당 변경을 단순한 코드 정리로 오해할 수 있지만, Exa의 웹 검색을 통해 "C++ API의 파괴적 변경"임을 정확히 파악하고 마이그레이션 설명을 제공할 수 있다고 설명했습니다. Exa는 검색 결과로 전체 GitHub 저장소 페이지를 반환하는 대신, 변경 사항을 설명하는 약 500~700자 정도의 작은 코드 스니펫을 제공하여 LLM이 필요한 정보만 빠르게 처리할 수 있도록 합니다. 이는 LLM이 10만 자에 달하는 전체 페이지를 읽는 것보다 훨씬 효율적입니다.

발표자는 검색 도구를 에이전트에 단순히 추가하는 것만으로는 부족하며, 에이전트가 언제 검색 도구를 사용해야 하는지(예: 의존성 또는 버전이 변경될 때)에 대한 규칙을 제공해야 한다고 강조했습니다. Exa는 모델에 네 가지 주요 이점을 제공합니다. 첫째, **투명성**으로, 검색된 정확한 소스와 스팬을 제공하여 블랙박스 문제를 해결합니다. 둘째, **토큰 효율적인 하이라이트**로, 관련성 높은 부분만 컨텍스트 창에 넣어 전체 페이지를 덤프하지 않습니다. 셋째, **비용 효율성**으로, 웹 크롤링 및 재독해 비용 없이 신호에 대해서만 비용을 지불하여 네이티브 웹 검색보다 훨씬 효율적입니다. 넷째, **표준화**로, 모든 모델(OpenAI, Anthropic 등)에 걸쳐 일관된 검색 계층을 제공하여 모델 종속성을 줄입니다.

데모에서는 Exa의 검색 플레이그라운드를 통해 "Jakub Hojsan bio"를 검색하여 발표자의 취미(사진, 오토바이)에 대한 하이라이트를 얻고, "Jakub Hojsan phone number"를 검색하여 전화번호와 이메일을 정확히 추출하는 모습을 보여주었습니다. 이는 Exa가 특정 정보를 페이지에서 정확히 찾아내는 능력을 보여줍니다. 또한, Exa Agent는 코딩 외에도 웹 분석(Similarweb), 미디어 인텔리전스(Particle), 사모 시장(Crunchbase) 등 다양한 데이터 제공업체와 연동하여 정보를 검색하고 구조화된 JSON 형태로 반환할 수 있습니다. 예를 들어, "샌프란시스코에 있는 Exa.ai 스타트업 직원 찾기" 쿼리에 대해 직원들의 이름, 직책, 위치, LinkedIn 프로필을 목록으로 제공했습니다.

Exa는 `npx exa-mcp tools/web_search_advanced.exa` 명령어를 통해 다양한 MCP(Model Control Plane) 코딩 에이전트에 통합될 수 있으며, Cursor, Claude Code, Codey, Continue, Zed, VS Code, Warp, Mac Code, Kile, Opencode 등 여러 개발 환경을 지원합니다.

- "Agentic search = the tool + the instinct to use it." (에이전트 검색 = 도구 + 그것을 사용할 본능.)

- **토큰 효율성 극대화:** Exa의 하이라이트 기능을 통해 LLM에 불필요한 전체 웹 페이지 대신 핵심 정보만 전달하여, API 호출 비용을 절감하고 응답 속도를 높일 수 있습니다.
- **에이전트의 도구 사용 로직 강화:** 단순히 검색 API를 연결하는 것을 넘어, 에이전트가 특정 상황(예: 의존성 업데이트, 오류 발생)에서 검색 도구를 능동적으로 사용하도록 명확한 규칙과 프롬프트를 설계하여 에이전트의 자율성을 높일 수 있습니다.
- **다양한 데이터 소스 통합:** Exa Connect를 통해 웹뿐만 아니라 Similarweb, Particle, Crunchbase 등 다양한 외부 데이터 제공업체의 정보를 통합하여, 코딩 에이전트 외에도 시장 분석, 미디어 모니터링 등 광범위한 에이전트 애플리케이션을 구축할 수 있습니다.
