# Gadgets: Personal app vibe coding that is actually safe — Kenton Varda, Cloudflare

🔗 https://youtu.be/RmS5s6Wbin4 · 📅 2026-08-05 · 🎙 AI Engineer

## 한 줄 요약
발표자는 개인 AI 코드 생성(codegen)이 전통적인 클라우드 인프라의 한계를 극복하고, 사용자가 안전하게 개인화된 앱을 직접 만들고 실행할 수 있는 새로운 플랫폼을 제시한다고 주장합니다.

## 발표자·소속
Kenton Varda, Cloudflare Workers의 아키텍트 및 리드 엔지니어.

## 핵심 주장
- 전통적인 소프트웨어 개발 및 배포 모델은 개발자 중심적이고 중앙 집중화되어 있어 사용자 개개인의 요구를 충족시키기 어렵습니다. 이는 기능 요청의 지연과 코드베이스의 복잡성 증가로 이어집니다.
- 개인 AI 코드 생성은 사용자가 자신의 필요에 맞춰 앱 기능을 직접 생성하고 추가할 수 있게 하여, 개발자 의존성을 줄이고 소프트웨어 개인화를 가능하게 합니다.
- 발표자가 개발한 '가젯(Gadgets)' 플랫폼은 클라이언트와 서버 모두에서 강력한 샌드박스 환경을 제공하여, 사용자가 생성한 코드가 보안 문제를 일으킬 위험을 제거합니다.
- 이 플랫폼은 Cloudflare Workers의 오픈소스 런타임인 WorkerD를 기반으로 로컬에서 실행 가능하며, 외부 서비스와 안전하게 통합되어 중앙 집중식 클라우드 인프라의 제약에서 벗어납니다.

## 세부 내용
발표자는 먼저 전통적인 소프트웨어 개발의 문제점을 지적합니다. 개발자가 '상아탑'에서 앱을 만들고, 사용자들은 기능 요청을 하지만, 이 요청들은 종종 제품 관리자의 Jira에 묻히거나, 소수의 사용자만을 위한 기능으로 인해 코드베이스가 복잡해지고 지루한 작업이 됩니다. 결국 개발자들은 '재작성(rewrite)'을 통해 새로운 아키텍처(플러그인 시스템 등)를 도입하려 하지만, 이 과정에서 기능 구현은 더욱 지연되고 사용자들은 불만을 갖게 됩니다.

이러한 문제에 대한 AI의 대안으로, 발표자는 사용자가 AI 에이전트에게 직접 기능을 요청하여 앱에 추가하는 '개인 AI 코드 생성'의 미래를 제시합니다. 이는 개발자가 핵심 앱을 깨끗하게 유지하면서도 사용자들이 필요한 기능을 얻을 수 있게 합니다.

그러나 기존 클라우드 인프라는 이러한 개인화된 앱을 지원하기 어렵습니다. Apple이나 Google과 같은 앱 스토어는 서명되지 않은 소프트웨어 설치를 엄격히 제한하며, 웹 앱은 개발자의 서버에서 단일 버전으로 실행되어 사용자 정의가 불가능합니다.

발표자는 자신이 Cloudflare Workers의 아키텍트이자 리드 엔지니어임을 밝히며, Workers를 기반으로 개발한 '가젯'이라는 사이드 프로젝트를 시연합니다. '가젯'은 Google Docs와 유사하게 여러 개의 앱(가젯)을 관리할 수 있는 환경입니다. 그는 협업 화이트보드, 스페인어 이메일 필터, GitHub 리뷰 트래커 등 다양한 가젯을 보여줍니다.

특히 '가젯 슬라이드 빌더' 데모를 통해, AI 에이전트(Claude)에게 Google Docs 링크를 제공하여 슬라이드를 생성하도록 지시하는 과정을 보여줍니다. Claude는 슬라이드에 필요한 스트라이크스루(strike-through) 텍스트나 중앙 정렬과 같은 새로운 기능을 앱 코드에 직접 추가합니다.

발표자는 이 과정에서 발생할 수 있는 보안 문제(예: SVG에 포함된 JavaScript로 인한 XSS 공격)에 대해 설명하며, '가젯' 플랫폼의 강력한 보안 모델을 강조합니다. '가젯'의 클라이언트 UI는 'null origin iframe sandbox' 내에서 실행되며, CSP(Content Security Policy)를 통해 외부와의 통신을 차단하고 쿠키 접근을 막습니다. 서버 코드 또한 Cloudflare Workers의 '동적 워커 샌드박스' 내에서 실행되어 외부와 격리됩니다. 이로 인해 앱 코드에 보안 버그가 있더라도 데이터 유출이나 시스템 침해로 이어지지 않아 안전합니다.

발표자는 '가젯' 플랫폼의 모든 요소(LLM 제외)가 Cloudflare Workers의 오픈소스 런타임인 WorkerD를 기반으로 구축되었으며, 이를 통해 로컬에서 자체 호스팅이 가능하다고 설명합니다. 그는 Home Assistant나 Spotify와 같은 외부 서비스와 안전하게 연결될 수 있는 커넥터도 언급하며, 이를 통해 사용자가 자신의 기기에서 홈 자동화와 같은 개인화된 작업을 수행할 수 있음을 시사합니다.

마지막으로, 발표자는 '가젯' 플랫폼을 오픈소스화할 예정이었으나, CTO의 결정으로 인해 출시가 몇 주 연기되었다고 밝히며 아쉬움을 표합니다.

## 실무 적용 포인트
- **서버리스 및 엣지 컴퓨팅 활용:** Cloudflare Workers와 같은 서버리스 플랫폼을 활용하여 애플리케이션을 개발하면, 확장성, 성능, 그리고 동적 샌드박스를 통한 보안 이점을 얻을 수 있습니다.
- **강력한 샌드박스 보안 모델 구현:** 클라이언트(iframe + CSP) 및 서버(동적 워커 샌드박스) 양쪽에서 엄격한 격리 환경을 구축하여, 사용자 생성 코드나 외부 콘텐츠로 인한 보안 취약점을 원천적으로 방지하는 아키텍처를 고려할 수 있습니다.
- **모듈형/플러그인 기반 아키텍처 설계:** '가젯'과 같이 앱의 핵심 기능을 유지하면서도 사용자가 직접 기능을 추가하거나 수정할 수 있는 모듈형 구조를 도입하여, 개인화된 경험을 제공하고 개발자의 부담을 줄일 수 있습니다.
- **AI 에이전트 통합을 통한 코드 생성 자동화:** LLM을 활용하여 사용자의 자연어 요청을 기반으로 코드를 자동으로 생성하고 앱에 통합하는 시스템을 구축하여, 개발 생산성을 높이고 비전문가도 소프트웨어 개발에 참여할 수 있는 기회를 제공합니다.
