# Tell the Robot What You Want — Sandhya Subramani, AWS

🔗 https://youtu.be/S6aSoQ6_u5A · 📅 2026-08-29 · 🎙 AI Engineer

## 한 줄 요약
AWS의 샌디아 수브라마니는 Strands Agent 프레임워크를 사용하여 로봇에게 자연어 이해와 자율적인 의사결정 능력을 부여하는 방법을 시연하며, 이를 통해 로봇이 단순한 프로그래밍을 넘어 복잡한 작업을 수행하고 인간과 자연스럽게 상호작용하는 미래를 제시합니다.

## 발표자·소속
샌디아 수브라마니 (Sandhya Subramani), AWS GenAI 수석 개발자 옹호자 (Senior Developer Advocate, GenAI, Amazon Web Services)

## 핵심 주장
- 로봇에게 '두뇌'를 부여하여 자연어를 이해하고 자율적으로 행동하게 할 수 있습니다. Strands Agent는 로봇의 기존 기능(도구)에 언어 모델을 연결하여 복잡한 지시를 해석하고 실행할 수 있도록 합니다.
- Strands Agent는 '인지(Perceive)', '추론(Reason)', '행동(Act)'의 폐쇄 루프를 통해 작동하며, 에이전트가 환경을 관찰하고, 추론하며, 적절한 행동을 선택하도록 오케스트레이션합니다.
- 이러한 에이전트 기반 접근 방식은 기존의 로봇 프로그래밍 방식과 달리, 로봇이 새로운 작업을 학습하고 예상치 못한 상황에 적응할 수 있는 유연성을 제공합니다.
- 미래의 로봇은 물리적 AI를 통해 더욱 발전하여, 인간과의 협업 및 자연스러운 인간-로봇 상호작용이 가능해질 것이며, 이는 단순한 반복 작업을 넘어선 복잡한 역할 수행으로 이어질 것입니다.

## 세부 내용
발표자는 '스카우트(Scout)'라는 이름의 작은 로봇을 소개하며, 이 로봇이 자연어를 이해하고 스스로 생각할 수 있다고 설명합니다. 스카우트는 뉴욕시에 있는 라즈베리 파이에 4G 연결을 통해 연결되어 있으며, 발표자의 지시를 받아 동작합니다.

데모에서 발표자는 스카우트에게 "헤이 스카우트, 헤드라이트를 켜고 모두에게 인사해"라고 입력합니다. 스카우트는 잠시 생각한 후 헤드라이트를 켜고 "안녕하세요, 모두"라고 말합니다. 이어서 발표자가 "몇 명이나 보여?"라고 묻자, 스카우트는 카메라를 통해 주변을 인지하고 "앞 카메라에서 2명을 봅니다. 한 명은 무대 뒤 스피커 모니터 근처에 있고, 다른 한 명은 관중석 근처에 있습니다."라고 답합니다. 발표자가 "360도 돌아봐"라고 지시하자, 스카우트는 천천히 회전하며 주변 환경을 스캔합니다.

이러한 로봇의 지능적인 행동은 'Strands Agent'라는 AWS에서 개발한 오픈소스 프레임워크를 통해 구현됩니다. Strands Agent는 에이전트에게 '두뇌'를 부여하여, 기존의 소프트웨어 도구(계산기, 웹 검색, 파일 읽기 등)뿐만 아니라 로봇과 같은 하드웨어 도구에도 접근할 수 있도록 합니다. 에이전트는 어떤 도구를 호출할지, 그리고 어떻게 로봇이 원하는 작업을 수행하도록 할지 결정합니다.

발표자는 로봇을 제어하는 데 단 5줄의 파이썬 코드만 필요하다고 강조합니다. `from strands import Agent`와 `from strands_robots import Robot`을 임포트한 후, `robot = Robot("so100")`으로 로봇 객체를 생성하고, `Agent(tools=[robot])("pick up the red cube")`와 같이 자연어 명령을 에이전트에 전달하면 됩니다.

Strands 패키지는 23개의 팔, 18개의 휴머노이드, 10개의 모바일 로봇 등 8가지 카테고리에 걸쳐 40개 이상의 다양한 로봇을 지원합니다. Strands-robots의 아키텍처는 4개의 계층으로 구성됩니다: Strands Agent(최상위), 정책 제공자(Policy providers), 백엔드(Backends), 그리고 40개 이상의 로봇(최하위). 명령은 위에서 아래로(Actions), 관찰은 아래에서 위로(Observations) 양방향으로 흐릅니다.

내부적으로는 클라우드 서비스와 엣지 디바이스의 하이브리드 모델로 작동합니다. 클라우드에서는 AgentCore 메모리, Bedrock LLM, AgentCore 관찰성, SageMaker 시뮬레이터 및 훈련이 이루어지며, 엣지에서는 IoT, Strands Agents, 로봇, 엣지 VLA 모델, 엣지 LLM이 상호작용합니다. Strands는 언제 클라우드의 기능을 호출하고 언제 엣지에서 직접 실행할지 결정하여 효율성을 높입니다.

발표자는 "에이전트는 무엇을 할지 결정하고, 정책은 어떻게 할지 결정한다"는 핵심 원칙을 제시합니다. 스카우트는 Anthropic Claude Opus 4.8을 두뇌로 사용하며, OpenAI Realtime의 음성을 사용합니다. 발표자는 스카우트에게 규칙과 접근 가능한 도구들을 시스템 프롬프트로 제공하여, 스카우트가 자율적으로 행동하고 추론할 수 있도록 설정했습니다.

## 인상적인 대목
- 발표자가 로봇에게 "몇 명이나 보여?"라고 묻자, 로봇이 카메라를 통해 사람 수를 인지하고 위치까지 설명하는 모습은 매우 인상적이었습니다.
- "The agent decides what. The policy decides how." (에이전트는 무엇을 할지 결정하고, 정책은 어떻게 할지 결정한다.)라는 문장은 에이전트 기반 AI의 핵심 철학을 명확하게 보여줍니다.
- 로봇 제어에 단 5줄의 파이썬 코드만 필요하다는 점은 개발의 간소화와 접근성을 극명하게 보여줍니다.

## 실무 적용 포인트
- **자연어 기반 로봇 제어 시스템 구축:** Strands Agent 프레임워크를 활용하여 복잡한 로봇 작업을 자연어 명령으로 제어하는 시스템을 개발할 수 있습니다. 이는 로봇 운영의 편의성을 크게 향상시킬 것입니다.
- **하이브리드 클라우드-엣지 아키텍처 활용:** 로봇의 두뇌(LLM)를 클라우드에 두고, 실제 행동 실행은 엣지 디바이스에서 수행하는 하이브리드 모델을 통해 지연 시간을 줄이고 효율성을 극대화할 수 있습니다.
- **데이터셋 생성 및 정책 훈련 자동화:** 로봇의 자율적인 탐색 및 상호작용을 통해 훈련 에피소드와 데이터를 자동으로 수집하고, 이를 기반으로 VLA(Vision-Language Action) 모델을 훈련하여 로봇의 능력을 지속적으로 향상시킬 수 있습니다.
- **안전 및 가드레일 정책 통합:** 시스템 프롬프트에 안전 규칙과 가드레일을 명확히 정의하여, 로봇이 자율적으로 행동하더라도 예측 불가능하거나 위험한 상황을 방지하도록 설계할 수 있습니다.
